# 01 维度分类默认折叠方案

> **关联代码：** `src/components/DimensionPanel.vue:19`（`expandedKeys` 声明）· `DimensionPanel.vue:79-80`（`refresh()` 中初始化展开集）
> **目标：** 维度面板所有分类从默认展开改为默认折叠

---

## 一、现状分析

### 1.1 当前行为

`DimensionPanel.vue` 在 `onMounted` 时调用 `refresh()`，加载完维度数据后执行：

```js
// DimensionPanel.vue L79-80
expandedKeys.value = new Set(dims.map((d) => d.key))
```

这行代码将**所有维度的 key** 放入 `expandedKeys`，导致首次渲染时 14 个维度全部展开，用户看到的是一个很长的词条列表。

### 1.2 用户反馈

- 14 个维度全部展开时，左侧面板内容过长，需要大量滚动才能找到目标维度
- 用户实际使用时通常只关注 1-2 个维度，全部展开造成视觉噪音
- 期望行为：默认折叠，用户按需点击展开

### 3.3 影响分析

| 影响项 | 说明 |
|--------|------|
| 维度展开/折叠 | `toggleExpand(key)` 逻辑不变，点击维度头仍可正常切换 |
| 搜索过滤 | `filteredDimensions` 和 `filteredModules` 计算属性不变，搜索命中维度时仍会显示维度头 |
| 搜索后展开 | 当前搜索命中时维度头显示但内容不展开——这是正确行为，用户搜索后点击展开查看匹配词条 |
| 测试影响 | `Layout.test.ts` 中 "三栏与 sash/TopBar/StatusBar 占据布局" 测试不受影响（不验证展开状态）；如有测试断言展开状态需同步修改 |
| 已选状态 | 已选词条的 "已选" badge 不受影响，展开维度后仍可见 |
