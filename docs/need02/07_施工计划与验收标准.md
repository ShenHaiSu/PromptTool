## 3. 手工复测脚本（验收必跑）

```
A. 预览入口：画布选 outfit + top + bottom → 预览 badge=⚠ → 打开编辑器 → findings=2 条（rule_01a/01b）
   → 对 01a 点自动修复 → 预览“将移除 #top” → 确认 → findings=1 → 应用到画布 → 画布无 top 且 Toast 成功。
B. 锁定保护：锁定 top 后重进 → 01a 的 fix 反向移除 outfit 未锁定项；锁定双方 → fix 为空 + 提示解锁。
C. 赤脚：shoes 选 barefoot 项 + 普通鞋 → R02 转正 finding → 修复保留锁定侧。
D. 背景：studio + beach → excludes finding → 修复保留 studio。
E. 规则管理：新建 mutex（hat 维度↔helmet 条目）→ 即时在 findings 生效；禁用 → findings 消失；删除 → confirm → 软删。
F. 三出口：复制全文进剪贴板可用；导出 CSV 可开；另存方案进历史可见。
G. 脏关闭：改字后点 ✕ → confirm；确认关闭后画布未变。
H. 老快照：历史旧方案（无 findings）打开编辑器 → 正常求值，无解析报错。
```
