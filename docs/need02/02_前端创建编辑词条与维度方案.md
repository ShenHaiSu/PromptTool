#### 3.1.1 `db_create_dimension`

```rust
#[tauri::command]
pub fn db_create_dimension(
    app: AppHandle,
    key: String,
    name_cn: String,
    name_en: Option<String>,
    sort_order: Option<i64>,
    is_multi_select: Option<bool>,
) -> Result<DimensionDto, String> {
    let conn = open_conn(&app)?;

    // key 唯一性校验（仅未删除的）
    let count: i64 = conn
        .query_row(
            "SELECT COUNT(*) FROM dimensions WHERE key = ?1 AND is_deleted = 0",
            params![key],
            |r| r.get(0),
        )
        .map_err(|e| e.to_string())?;
    if count > 0 {
        return Err(format!("分类键名 '{}' 已存在，请使用其他键名", key));
    }

    let id = new_id();
    let ts = now_ts();
    let so = sort_order.unwrap_or(0);
    let ms = if is_multi_select.unwrap_or(false) { 1 } else { 0 };

    conn.execute(
        "INSERT INTO dimensions (id, key, name_cn, name_en, sort_order, is_multi_select, is_enabled, created_at, updated_at, is_deleted)
         VALUES (?1, ?2, ?3, ?4, ?5, ?6, 1, ?7, ?8, 0)",
        params![id, key, name_cn, name_en, so, ms, ts, ts],
    )
    .map_err(|e| e.to_string())?;

    Ok(DimensionDto {
        id,
        key,
        name_cn,
        name_en,
        sort_order: so,
        is_multi_select: is_multi_select.unwrap_or(false),
        is_enabled: true,
        icon: None,
        created_at: Some(ts),
        updated_at: Some(ts),
    })
}
```

**参数说明：**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `key` | String | 是 | 英文唯一键名，如 `outfit`，校验唯一性 |
| `nameCn` | String | 是 | 中文名称，如 `套装` |
| `nameEn` | Option\<String\> | 否 | 英文名称，如 `Outfit` |
| `sortOrder` | Option\<i64\> | 否 | 排序权重，默认 0 |
| `isMultiSelect` | Option\<bool\> | 否 | 是否允许多选，默认 false |

**错误场景：**
- `key` 已存在（未删除）→ 返回 `"分类键名 'xxx' 已存在，请使用其他键名"`

#### 3.1.2 `db_update_dimension`

```rust
#[tauri::command]
pub fn db_update_dimension(app: AppHandle, d: DimensionDto) -> Result<(), String> {
    let conn = open_conn(&app)?;
    let ts = now_ts();

    // key 不可修改，校验 id 存在
    let exists: i64 = conn
        .query_row(
            "SELECT COUNT(*) FROM dimensions WHERE id = ?1 AND is_deleted = 0",
            params![d.id],
            |r| r.get(0),
        )
        .map_err(|e| e.to_string())?;
    if exists == 0 {
        return Err(format!("维度 '{}' 不存在或已删除", d.id));
    }

    conn.execute(
        "UPDATE dimensions
         SET name_cn = ?1, name_en = ?2, sort_order = ?3,
             is_multi_select = ?4, is_enabled = ?5, updated_at = ?6
         WHERE id = ?7",
        params![
            d.name_cn,
            d.name_en,
            d.sort_order,
            i64_from_bool(d.is_multi_select),
            i64_from_bool(d.is_enabled),
            ts,
            d.id,
        ],
    )
    .map_err(|e| e.to_string())?;

    Ok(())
}
```

**注意：** `key` 字段不可修改（已在 DB 中唯一，修改会破坏词条关联），编辑弹窗中 key 字段只读。

#### 3.1.3 `db_soft_delete_dimension`

```rust
#[tauri::command]
pub fn db_soft_delete_dimension(app: AppHandle, id: String) -> Result<(), String> {
    let conn = open_conn(&app)?;

    // 检查是否存在未删除的词条
    let module_count: i64 = conn
        .query_row(
            "SELECT COUNT(*) FROM modules WHERE dimension_id = ?1 AND is_deleted = 0",
            params![id],
            |r| r.get(0),
        )
        .map_err(|e| e.to_string())?;
    if module_count > 0 {
        return Err(format!(
            "该维度下仍有 {} 个词条，请先删除所有词条后再删除维度",
            module_count
        ));
    }

    let ts = now_ts();
    conn.execute(
        "UPDATE dimensions SET is_deleted = 1, updated_at = ?1 WHERE id = ?2",
        params![ts, id],
    )
    .map_err(|e| e.to_string())?;

    Ok(())
}
```

**级联检查：** 维度下有未删除词条时拒绝删除，返回错误信息包含词条数量，引导用户先清理词条。

**交互逻辑：**

1. **打开时**：`watch(open)` 监听，打开时用 `initialDimension` 回填表单字段
2. **创建模式**：所有字段可编辑，key 字段必填

<script setup lang="ts">

import { Button } from '@/components/ui/button'
import { Input } from '@/components/ui/input'
import { Card } from '@/components/ui/card'

const emit = defineEmits<{

  (e: 'confirm', payload: {
    key: string; nameCn: string; nameEn: string;

const key = ref('')
const nameCn = ref('')
const nameEn = ref('')
const sortOrder = ref(0)
