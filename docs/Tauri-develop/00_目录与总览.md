## 二、重构背景一句话

Python tkinter 的 `Tcl 单线程 + CPU 软渲染 + 递归 pack` 导致 `resize` 时全树重排 `15fps`；Tauri 的 `WebView2 GPU 合成 + Flex/Grid + 虚拟化` 可稳定 `60fps` 且包体积 `8-15MB`，是根治方案。

## 五、文档使用说明

1.  **每份阶段文档固定包含 6 大区块**（按用户要求）：
    - `前置检查方案` — 进入本阶段前必须执行的命令/检查项
    - `前置检查结果期望值` — 每项检查的通过标准（精确到输出字符串/退出码）
    - `既定目标` — 本阶段交付物与量化目标
    - `实现方案` — 文件清单、关键代码、接口契约
    - `测试验收方式` — 自动化 + 手工验收步骤
    - `测试验收标准` — 通过/失败判定阈值

2.  **新工程独立**：所有代码在 `tauri-app/` 内，**不修改** `src/` 原 Python 工程，保证可回滚。

3.  **术语表**见 `01_现状诊断` 与 `02_总体架构`。
