## 四、实现方案

### 4.1 文件清单

| 文件 | 动作 | 说明 |
|------|------|------|
| `src/components/HistoryPanel.vue` | 重写(占位→完整) | 右下资产库（对标 `history_panel.py 399行`） |
| `src/stores/history.ts` | 修改 | `assemblies/favorites/templates`, `refresh(), toggleFavorite(), rename(), softDelete()` |
| `src/components/SaveDialog.vue` | 新增 | 保存方案/模板弹窗 |
| `src/App.vue` | 修改 | 接 `onSave/onSaveFavorite/onCreateTemplate/onRestore/onTemplateApply` |
| `src/lib/db.ts` | 修改 | 追加 `listFavorites/searchAssemblies` 等 invoke 封装 |

### 4.2 数据流（对标 P0-01）

```
中栏“保存方案” → history.save(title, ir, final, config, items) → invoke('db_save_assembly') → 事务 assemblies + assembly_items
                                │
右栏 Tabs 历史/收藏 ← invoke('db_list_recent'/'db_list_favorites') ← refresh()
        │ 双击/右键回填 → history.loadSelectedItems(id) → assembly.setItems(items) → reassemble() → TopBar 更新
        │ 右键 收藏/重命名/删除 → invoke('db_toggle_favorite'/'db_rename'/'db_soft_delete')
模板 存 → invoke('db_save_template', {name, config, enabledKeys, cover})
     用 → invoke('db_apply_template', id) → (config, enabledKeys) → assembly.applyConfig(config)
批量 Card ★ → invoke('db_save_assembly_from_ir', {ir, final, config}) → 收藏
批量 Card ↩ → assembly.setItems(fromIR) → reassemble()
```

### 4.3 关键设计

- **快照双写**：`assemblies.prompt_ir` JSON（含 `segments+warnings`）+ `assembly_items` 明细，与 Python `save()` 一致.
- **已删占位**：`db_load_selected_items` 若 `JOIN modules` 未命中或 `is_deleted=1`，用 `prompt_ir` 快照占位，`displayName="[已失效]..."`, `notes="[原条目已删除]"`（复用 `repository.py:418-469` 逻辑，Rust 侧实现）.
- **回填确认**：`if (assembly.selectedItems.length > 0) { if (!confirm(`当前 ${n} 项将被覆盖为 ${m} 项，是否继续？`)) return }`.
- **模板 config_json**：`{ assembly_config: {separator,useWeightBrackets,modelProfile,sortBy}, enabled_dimension_keys: string[], version:1 }`.

### 4.4 UI 细节

- **Tabs**：`shadcn Tabs` 三项 `历史/收藏/模板`，每项 `ScrollArea` + `Table` 或 `Card` 列表，含 `时间/标题/预览/收藏星` 列.
- **右键菜单**：`shadcn ContextMenu` — `收藏/取消收藏 / 重命名 / 删除 / 另存为模板`.
- **空状态**：居中 `◈` + `暂无历史 — 保存方案后显示` + 引导按钮.
