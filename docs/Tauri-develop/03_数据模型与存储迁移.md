## 二、Rust 存储设计

### 2.1 技术选型

- **rusqlite `bundled`**：自带 SQLite，无需系统 sqlite3，与 Python `sqlite3` 文件 100% 兼容。
- **WAL + foreign_keys**：`PRAGMA journal_mode=WAL; PRAGMA foreign_keys=ON;` 与原 `connection.py:39-40` 一致。
- **路径**：`tauri::api::path::app_data_dir()` → `pmf.db`（如 `%APPDATA%/com.pmf.tauri-app/pmf.db`），与原 `data/pmf.db` 分离，避免冲突。

### 2.3 迁移与种子（`migration.rs`）

1. **首次启动**：若 `pmf.db` 不存在 → 执行内嵌 `schema.sql`（`include_str!("../../src/db/schema.sql")` 拷贝或 Rust 内嵌）→ `ensure_dimensions` 插入 14 维 → 读 `resources/samplePrompt/` (Tauri resource 打包) 导入 311 条 → `mark_nsfw_modules` → `disable_deprecated_gender_modules`.
2. **存量升级**：PRAGMA `table_info` 检查 `is_nsfw` 列，不存在则 `ALTER TABLE modules ADD COLUMN is_nsfw INTEGER NOT NULL DEFAULT 0` + 补 P0-01 索引（与 `connection.py:_migrate` 一致，幂等）。
3. **旧库导入**：提供 UI 按钮“导入旧版数据”，Rust 读 `E:\ProgramFiles\PromptTool\data\pmf.db` 路径（或用户选择），`ATTACH DATABASE` + `INSERT OR IGNORE` 迁移 `dimensions/modules/assemblies/assemblies_items/templates/rules`，返回 `ImportReport { dimensions, modules, assemblies, skipped }`.

## 三、数据迁移路径（平滑，无破坏）

```
旧 Python data/pmf.db (WAL) ──→ 新 Tauri %APPDATA%/pmf.db
        │  ① 自动：首次启动检测旧路径存在 → 弹窗“发现旧版数据，是否导入？” 
        │  ② 手动：设置页“导入旧版数据” → 文件选择器选旧 db
        └─→ Rust ATTACH + 事务迁移 → 新库立即可用
```

**回滚**：新旧库文件物理隔离，旧库永不修改.

## 四、与原项目一致性保证

- **ID 生成**：`uuid v4`（Rust `uuid` crate）与 Python `uuid.uuid4()` 同为字符串主键.
- **时间戳**：`chrono::Utc::now().timestamp()` 秒级，与 Python `int(time.time())` 一致.
- **软删/收藏**：`is_deleted/is_favorite` 0/1 语义不变.
- **快照占位**：`load_selected_items` 对已删 module 用 `prompt_ir_json` 快照占位逻辑原样移植（见 `repository.py:388-469`）.
