## 一、技术栈全景

### 1.1 选型表

| 分层 | 选型 | 版本 | 作用 | 替代方案为何不选 |
|------|------|------|------|-----------------|
| 宿主 | **Tauri 2** | ^2.0 | Rust 壳 + 系统 WebView2 + 打包 | Electron 120MB 太大；Wails Go 生态弱 |
| 前端框架 | **Vue 3** | ^3.5 | 响应式 UI，SFC 单文件组件 | React 同分但国内 Vue 人才更多；Svelte 生态小 |
| 语言 | **TypeScript** | ~5.6 | 类型约束 PromptIR 等模型 | JS 无类型，易回归 |
| 构建 | **Vite 6** | ^6.0 | 极速 HMR | 无 |
| 样式 | **Tailwind CSS 3 + shadcn-vue** | latest | Token 驱动，暗色原生 | UnoCSS 可替但 Tailwind 生态更稳 |
| 状态 | **Pinia** | ^2 | 共享 assembly/config/history | Zustand(Vue 对应) 可替 |
| 拖拽 | **vue-draggable-plus / Pragmatic DnD** | latest | Chips 排序 60fps | Sortable.js 裸用亦可 |
| 虚拟化 | **TanStack Virtual (Vue)** | ^3 | 500 Card 虚拟滚动 | vue-virtual-scroller 可替 |
| 测试 | **Vitest + Vue Test Utils + @tauri-apps/api mocks** | latest | 单测 + 组件测试 | Jest 慢 |
| 后端 | **Rust + rusqlite + serde** | edition 2021 | SQLite WAL + Command | Python Sidecar 增加复杂度 |
| DB | **SQLite (rusqlite)** | bundled | 复用 schema.sql 7表 | tauri-plugin-sql 可替但 rusqlite 更可控 |

### 关键设计原则

1.  **前后端职责分离：** 拼装/规则/随机等计算在 **前端 TS engine**（零 IPC 延迟，拖拽实时），持久化在 **Rust Command**（事务安全）。
2.  **数据单向流：** `DimensionPanel --select--> Pinia assembly store --assemble()--> TopBar/Batch`，与原 `MainWindow._reassemble()` 同构但响应式。
3.  **零破坏迁移：** 新 DB 路径与旧 `data/pmf.db` 共存，首次启动提供“导入旧库”按钮（见 03）。

## 五、与原项目映射表

| 原 Python (src/) | 新 Tauri (tauri-app/src) | 迁移方式 |
|------------------|--------------------------|----------|
| `engine/models.py` | `engine/models.ts` | 1:1 翻译，dataclass→interface/type |
| `engine/assembly.py` | `engine/assembly.ts` | 同上，保留 sort_by_order 双模式 |
| `engine/rules.py` | `engine/rules.ts` | R01-R03 逻辑平移，id() 身份比较改为对象引用 |
| `engine/adapters.py` | `engine/adapters.ts` | SD/MJ/Flux 同步 |
| `engine/random_engine.py` | `engine/random.ts` | random.choices→TS 加权采样 |
| `db/schema.sql` | `src-tauri/src/commands/migration.rs` 内嵌 | 原样复用，PRAGMA WAL |
| `db/repository.py` | `src-tauri/src/commands/db.rs` + `src/lib/db.ts` | Rust rusqlite + TS invoke 封装 |
| `db/seed.py + sample_importer.py` | `src-tauri/src/commands/migration.rs` | Rust 读 `docs/samplePrompt/` (打包为 resource) |
| `ui/main_window.py` | `App.vue + stores/*` | 响应式重构 |
| `ui/styles.py` | `tailwind.config.js + src/assets/tokens` | Token 驱动 |
| `config.py` | `src/lib/config.ts` + `tauri.conf.json` | 窗口/权重常量 |
