### 4.2 AssemblyCanvas 设计

**Chip 结构**

```
┌─ Chip Row ─────────────────────────────────────┐
│ [dim pill bg=DIM_COLORS[key]] displayName w1.2 │ ← 点击 w1.2 弹 Popover
│                                  [🔒/🔓] [✕]  │
└───────────────────────────────────────────────┘
```

- **流式布局**：`flex flex-wrap gap-2 overflow-y-auto`，GPU 合成，无需 Canvas.
- **拖拽**：`vue-draggable-plus` 绑定 `v-model="assembly.selectedItems"`，`@end` 时 `assembly.reorder(oldIndex, newIndex)` + `assembly.reassemble()`（仅 drop 时计算，非每帧）.
- **权重 Popover**：`shadcn Popover` 内 `Slider 0.5-2.0 step 0.1` + `InputNumber` + 确定；`v-model` 本地，`@confirm` 才写回 `weightOverride`.
- **空状态**：居中 `◈` + `从左侧双击添加词条` + `试试随机生成` 按钮.
- **设置弹层**：中栏头部 `...设置` → `Dialog` 含 `分隔符 Select(", "/" BREAK "/" \n")`, `权重括号 Switch`, `排序 Select(维度顺序/自定义拖拽)`.

### 4.3 BatchFactory 设计

**顶部控制行**

```
[数量 InputNumber 1-500] [随机生成] [含NSFW Switch] [可控 Switch(?)Tooltip] [复制全部] [清空] [导出CSV]
```

- **随机**：`onRandom(count, allowNsfw, usePartial)` → `randomAssembly` 或 `partialRandomAssembly`（TS engine，零 IPC）→ `batch.updateBatch(results)`；`usePartial` 为 true 时以 `assembly.selectedItems` 为锚点.
- **虚拟化 Card 流**：`TanStack Virtual` 容器 `h-[400px] overflow-auto`，`estimateSize: 110px`，`overscan: 5`；`pageSize 50` 仅作逻辑分页，虚拟化已解决渲染瓶颈，无需手工“加载更多”.
- **BatchCard**：
  ```
  ┌─ Card #1  [复制][★收藏][↩回填]               │
  │ prompt 全文 ... (wraplength 自适应)            │
  │ chips: [face][top][pose]                      │
  └─────────────────────────────────────────────┘
  ```
  单击空白处复制全文（`navigator.clipboard.writeText` + 绿边 350ms + Toast），`chips` 用 `DIM_COLORS`.

**关键代码**

```vue
<!-- BatchFactory.vue 虚拟化 -->
<script setup lang="ts">
import { useVirtualizer } from '@tanstack/vue-virtual'
const parentRef = ref<HTMLElement | null>(null)
const virtualizer = useVirtualizer({ count: batch.results.length, getScrollElement: () => parentRef.value, estimateSize: () => 110, overscan: 5 })
</script>
<template>
  <div ref="parentRef" class="h-[400px] overflow-auto">
    <div :style="{ height: virtualizer.getTotalSize() + 'px' }">
      <div v-for="v in virtualizer.getVirtualItems()" :key="v.key" :style="{ transform: `translateY(${v.start}px)` }">
        <BatchCard :model="batch.results[v.index]" :index="v.index+1" />
      </div>
    </div>
  </div>
</template>
```
