## 四、实现方案

### 4.1 文件清单（本阶段新增/修改）

| 文件 | 动作 | 说明 |
|------|------|------|
| `package.json` | 修改 | 追加 `tailwindcss, autoprefixer, postcss, pinia, vitest, @vue/test-utils, jsdom, @types/node` |
| `vite.config.ts` | 修改 | 追加 Tailwind 插件、别名 `@`、Vitest `test:{environment:'jsdom', globals:true}` |
| `tailwind.config.js` + `postcss.config.js` | 新增 | 内容扫描 `src/**/*.{vue,ts}` |
| `src/assets/tokens.css` + `src/lib/utils.ts` | 新增 | CSS 变量 Token + `cn()` 合并 |
| `src/app.css` | 新增 | Tailwind 指令 + 全局样式 |
| `src/main.ts` | 修改 | `createApp + createPinia()` |
| `src/stores/theme.ts` | 新增 | `light/dark` 切换 + localStorage |
| `src/components/ui/*` | 新增 | shadcn-vue `Button/Card/Badge/Tabs/Input/ScrollArea` 按需引入 |
| `src-tauri/tauri.conf.json` | 修改 | `productName`, `identifier`, `width/height/minWidth/minHeight`, `resources: ["../docs/samplePrompt/**"]` |
| `src-tauri/Cargo.toml` | 修改 | 追加 `rusqlite(bundled), uuid, chrono`（先加依赖，不写逻辑） |
| `index.html` | 修改 | 标题 `Prompt Modular Factory — Tauri` |

### 4.2 关键代码

**Tailwind Token（对标 `src/ui/styles.py` TOKENS_LIGHT/DARK）**

```css
/* src/assets/tokens.css */
@tailwind base; @tailwind components; @tailwind utilities;
@layer base {
  :root { --bg: #F8FAFC; --surface: #FFFFFF; --border: #E2E8F0; --text: #0F172A; --primary: #3B82F6; --success: #22C55E; --warning: #F59E0B; }
  .dark { --bg: #0F172A; --surface: #1E293B; --border: #334155; --text: #F1F5F9; }
}
```

**vite.config.ts 增量**

```ts
import { defineConfig } from "vite"
import vue from "@vitejs/plugin-vue"
import path from "node:path"
export default defineConfig(async () => ({
  plugins: [vue()],
  resolve: { alias: { "@": path.resolve(__dirname, "./src") } },
  server: { port: 1420, strictPort: true },
}))
```

**tauri.conf.json 关键片段**

```json
{ "productName": "Prompt Modular Factory", "identifier": "com.pmf.tauri-app",
  "app": { "windows": [{ "title": "Prompt Modular Factory — Tauri", "width": 1600, "height": 1080, "minWidth": 1280, "minHeight": 720 }] },
  "bundle": { "resources": ["../docs/samplePrompt/**"] } }
```

### 4.3 操作步骤（执行顺序）

1. `bun add -d tailwindcss postcss autoprefixer && bunx tailwindcss init -p`
2. `bun add pinia && bun add -d vitest @vue/test-utils jsdom @types/node`
3. 按 `shadcn-vue` 官方 `npx shadcn-vue@latest init` 引入基础组件（或手工 `src/components/ui/*`）
4. 修改上述文件，`bun run build` 验证
5. 修改 `Cargo.toml` 加依赖，`cargo check` 验证
6. `bunx tauri dev` 冒烟：窗口弹出、主题按钮可切换
