## 4. 全局硬约束（所有施工文档共用，Code Review 必查）

1. `response_format` 只进 `extra_body`；一期不构造任何 `image` 字段；
2. invoke 参数一律 camelCase（`src/lib/db.ts` 踩坑）；
3. Key 明文不出内存：日志/事件/toast/localStorage 一律脱敏或占位；
4. 补货永不写 `batch.results`；后端永不直接调随机引擎；
5. 并发 1..=8 硬钳制；熔断 5 连败；磁盘水位 500MB。
