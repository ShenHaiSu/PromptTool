## 2. Cargo 依赖（精确到 feature）

```toml
reqwest = { version = "0.12", default-features = false, features = ["json", "rustls-tls"] }
tokio = { version = "1", features = ["full"] }
futures = "0.3"
```

- `default-features = false + rustls-tls`：不要 native-tls（Windows 施乐链问题少，rustls 更稳）。
- socks5 一期不支持：`reqwest::Proxy::all` 只接 `http(s)://`；若用户填 `socks5://`，校验层直接拒绝并提示“二期支持”（§3.4）。
- Tauri2 异步命令原生支持 `async fn`，无需额外 runtime 配置；`lib.rs` 的 `Builder` 不动。

## 3. `agnes.rs`：请求构造（逐字段施工）

### 3.1 Provider trait（给“协议 select”留扩展位）

```rust
pub trait ImageProvider: Send + Sync {
    fn name(&self) -> &'static str;              // "agnes"
    fn endpoint(&self, api_base: &str) -> String; // "{base}/v1/images/generations"
    fn build_text_to_image(&self, prompt: &str, size: &str, ratio: &str) -> serde_json::Value;
    fn parse_image_url(&self, body: &serde_json::Value) -> Result<String, String>;
}
pub struct AgnesProvider;
```

一期只注册 `AgnesProvider`；`protocol` 字段透传，前端 select 只有 `agnes` 一个 option，
后端 `match protocol { "agnes" => ..., other => Err("未知协议") }`。

### 3.2 文生图 body（必须与 `01 §4` 勘误一致）

```rust
fn build_text_to_image(&self, prompt: &str, size: &str, ratio: &str) -> serde_json::Value {
    serde_json::json!({
        "model": "agnes-image-2.5-flash",
        "prompt": prompt,
        "size": size,            // "1K"|"2K"|"3K"|"4K"，只做白名单校验，不映射像素
        "ratio": ratio,          // 8 种之一，默认 "1:1"
        "extra_body": { "response_format": "url" }
    })
}
```

硬性规则（写进单测断言，防回退）：

1. `response_format` 只许出现在 `extra_body` 内，顶层禁止出现该 key；
2. 一期禁止构造任何 `image` 字段（文生图）；图生图扩展方法签名预留但 `unimplemented!`：
   `fn build_image_to_image(...) -> ... { unimplemented!("一期不支持图生图") }`；
3. `model` 写死常量 `AGNES_MODEL: &str = "agnes-image-2.5-flash"`，不接受前端传入。

### 3.3 响应解析

```rust
fn parse_image_url(&self, body: &serde_json::Value) -> Result<String, String> {
    let url = body.pointer("/data/0/url").and_then(|v| v.as_str()).unwrap_or("");
    if url.is_empty() { return Err(format!("响应缺少 data[0].url：{}", truncate(body))); }
    if !(url.starts_with("https://") || url.starts_with("http://")) {
        return Err(format!("非法图片 URL：{}", mask(url)));
    }
    Ok(url.to_string())
}
```

- `b64_json` 一期不解析（`response_format=url` 下恒为空，`01` 已实测）；收到 `b64_json` 非空时记 warning 日志即可。
- 错误体解析：Agnes 错误形如 `{"error":{"message":...,"type":...,"code":...}}`，
  统一抽 `extract_agness_error(body) -> String`，401 映射“密钥无效”，400 映射原文 message，方便前端 toast。

### 3.4 发送函数（含超时 / 重试 / 代理，由 config 驱动）

```rust
pub async fn generate_one(
    client: &reqwest::Client,
    api_base: &str,
    api_key: &str,
    prompt: &str,
    size: &str,
    ratio: &str,
) -> Result<(String /*image_url*/, u128 /*elapsed_ms*/), IqError>
```

- 超时：`ClientBuilder::connect_timeout(15s).timeout(300s)`，client 按配置指纹缓存（§5），
  本函数只管发，不建 client。
- 重试：仅重试超时 / 连接失败 / 5xx，最多 2 次，退避 1s → 3s；400/401 直接返回（`IqError::Fatal` vs `Retryable` 区分）。
- `IqError` 枚举：`Fatal(String)` / `Retryable(String)` / `Cancelled`，供 B2 调度器决策：
  Fatal 不重试直接记失败，Retryable 走退避，Cancelled 不计入熔断。

### 3.5 单测清单（`agnes.rs #[cfg(test)]`，无网络纯逻辑）

## 4. `config.rs`：配置与密钥记住（用户已确认允许）

### 4.1 结构（serde camelCase，与前端 F1 镜像）

```rust
#[derive(Debug, Clone, Serialize, Deserialize)]
#[serde(rename_all = "camelCase")]
pub struct ImageQueueConfig {
    pub protocol: String,        // "agnes"，白名单
    pub loop_enabled: bool,
    pub loop_after_random: bool, // 为 true 时要求 loop_enabled 为 true（set 时钳制）
    pub api_base: String,        // 默认 https://apihub.agnes-ai.com，收尾去 "/"
    #[serde(skip_serializing)]   // 永不经 iq_get_config 外泄
    pub api_key: String,
    pub output_dir: String,      // 空 = 默认；相对 = 相对 data_dir；见 B2
    pub size: String,            // 1K/2K/3K/4K，默认 1K
    pub ratio: String,           // 8 种，默认 1:1
    pub concurrency: u8,         // 钳制 1..=8，默认 2
    pub proxy_on: bool,
    pub proxy_url: String,
    pub remember_key: bool,      // 是否落盘密钥
    pub connect_timeout_secs: u64, // 默认 15，范围 5..=60
    pub total_timeout_secs: u64,   // 默认 300，范围 60..=600
}
impl Default for ImageQueueConfig { /* 按上述默认值 */ }
```

### 4.2 校验函数 `validate(&self) -> Result<(), String>`（`iq_set_config` 入口调用）

1. `protocol == "agnes"`，否则 Err；
2. `api_base` 必须 `http(s)://` 开头，截尾 `/`；连通性不在此校验（`iq_test_connection` 做）；
3. `size ∈ {1K,2K,3K,4K}`，`ratio ∈ 8 种`；
4. `concurrency` 钳制到 1..=8（钳制后仍回写，前端会收到纠正值）；
5. `proxy_on == true` 时 `proxy_url` 必为 `http(s)://`，否则 Err（socks5 明确拒绝并提示二期）；
6. `loop_after_random && !loop_enabled` → 自动将 `loop_enabled` 置 true（并在返回值中告知前端，而非报错）；
7. 超时范围钳制。

### 4.3 持久化（记住输出路径 + 记住密钥都落这里）

- 非敏感配置（含 `output_dir`，用户要求“记住”）：`{data_dir}/image_queue.json`，
  `iq_set_config` 成功后原子写（复用 export.rs `atomic_write` 模式）；启动时 `setup` 中加载，
  缺文件即 Default。
- 敏感（`api_key` + `proxy_url`，仅当 `remember_key == true`）：
  `{data_dir}/image_queue.secrets.json`，内容为混淆串（XOR + base64，key 为本机固定盐 + 应用标识，
  防 casual 窥视，不防专业逆向——文档与代码注释必须如实写明，二期可换系统钥匙串）；
  `remember_key == false` 时若旧 secrets 文件存在则删除。
- `.gitignore` 加 `data/`（若尚未忽略）与 `*.secrets.json`；日志中 `api_key`/`proxy_url` 一律 `mask()`：
  前 3 + `***` + 后 2。
- 前端 `iq_get_config` 返回中 `apiKey` 字段：若内存有 key 返回 `"__SET__"` 占位（表示已设置），
  无 key 返回 `""`；前端据此显示“已设置/未设置”，不回显原文。`iq_set_config` 收到 `"__SET__"` 视为“保持原 key 不变”。

## 5. HTTP client 指纹缓存

```rust
#[derive(Hash, PartialEq, Eq)]
struct ClientFingerprint { api_base: String, proxy_on: bool, proxy_url: String,
    connect_secs: u64, total_secs: u64 }
```

- `ImageQueueState` 持 `client_cache: Mutex<HashMap<ClientFingerprint, Client>>`；
  `iq_set_config` 成功后不清旧 client（运行中任务继续用旧 client，新任务取新指纹），
  缓存上限 4 个，超限清最旧。避免每次任务重建连接池，也避免配置热切换中断运行中请求。
- 代理构造失败（URL 非法）→ `iq_set_config` 直接 Err，不污染缓存。

## 6. `iq_test_connection`（本层提供，B2 调度器复用 `generate_one`）

- 流程：取当前内存配置 → 用固定探针 prompt（`"a small glass cube on a white studio background"`，
  `size=1K ratio=1:1`）发一次 `generate_one` → 只解析到 image_url 即返回成功（含 `elapsedMs`），
  **不下载图片**（省带宽；下载链路单独由 B2 覆盖测试）。
- 返回：`{ ok: true, elapsedMs }` 或 `{ ok: false, stage: "dns|connect|auth|api|parse", message }`，
  `stage` 供 F1 面板针对性提示（auth→检查密钥，connect→检查代理/网络）。
- 超时：复用配置超时；前端按钮加 60s 倒计时 + 可取消（取消只关前端等待，后端请求自然结束，不污染状态）。
