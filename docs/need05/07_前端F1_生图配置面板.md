## 3. store 配置域（`src/stores/imageQueue.ts` 节选，本篇只写配置部分）

```ts
export const useImageQueueStore = defineStore('imageQueue', () => {
  const config = ref<ImageQueueConfig>({ ...IQ_DEFAULT_CONFIG })
  const testing = ref(false)
  const testResult = ref<{ ok: boolean; elapsedMs?: number; message?: string } | null>(null)
  const dirty = ref(false) // 表单值 ≠ 后端生效值时 true，顶部提示“未保存”

  async function loadConfig(): Promise<void> {
    const view = await iqGetConfig()
    config.value = { ...IQ_DEFAULT_CONFIG, ...viewToConfig(view) }
    dirty.value = false
  }
  async function saveConfig(): Promise<void> {
    const errs = validateIqConfig(config.value)
    if (errs.length) { push(errs[0], 'warning'); return }
    const view = await iqSetConfig(configToPayload(config.value)) // 含 "__SET__" 占位逻辑
    config.value = { ...config.value, ...viewToConfig(view) }      // 回写纠正值（钳制/concurrency/loop 联动）
    if (config.value.apiKey === '__SET__') config.value.apiKeyState = 'set'
    dirty.value = false
    push('生图配置已保存', 'success', 1500)
    persistLocalCache() // localStorage 只存非敏感（apiKey 永不进 localStorage）
  }
  async function testConnection(): Promise<void> { ... } // §5
  return { config, testing, testResult, dirty, loadConfig, saveConfig, testConnection }
})
```

- `localStorage` 缓存键 `pmf.imageQueue.config`：只存非敏感字段，启动时先填缓存再 `loadConfig` 覆盖，
  避免首屏空白；`apiKey` 绝不写 localStorage（即使 rememberKey，后端 secrets 文件是唯一落盘处）。
- `dirty` 计算：表单任一 input 事件置 true；`saveConfig` 成功 / `loadConfig` 后置 false。

## 4. `ImageQueueSettings.vue` 表单（11 项逐项施工，`data-testid` 即验收钩子）

布局：分组折叠（连接 / 画面 / 运行 / 网络），与现有 Tailwind 风格一致（`h-7 text-xs` 控件尺寸对齐 BatchFactory）。

| # | 控件 | testid | 细节 |
|---|---|---|---|
| 1 | 协议 select | `iq-protocol` | 仅 1 个 option + 右侧“文生图 / 2.5 Flash”说明；change 即 dirty |
| 2 | 循环生成 switch | `iq-loop` | checkbox 样式沿用 batch-nsfw-switch；打开时提示“队列见底自动补货” |
| 3 | 点击随机后循环 switch | `iq-loop-after-random` | `loopEnabled=false` 时 disabled + title“需先开启循环生成”；打开时若 loop 关则联动打开（与校验一致） |
| 4 | API 路径 input | `iq-api-base` | 文本；失焦去尾 `/`；右侧“重置默认”小按钮 |
| 5 | API 密钥 password input | `iq-api-key` | `type=password` + 眼睛切换；已设置显示 `__SET__` 占位文案“已设置（为保密不回显）”，聚焦即清空待重输；“记住密钥”checkbox（`iq-remember-key`，默认勾选，用户已确认允许） |
| 6 | 输出路径 input + 浏览按钮 | `iq-output-dir` / `iq-output-browse` | 空 = 默认 dataDir/output/images（placeholder 明示）；浏览调 `dialog.open({directory:true})`（capabilities 已有 `dialog:allow-open`，无需改权限）；选择后填绝对路径 |
| 7 | 分辨率 select | `iq-size` | 1K/2K/3K/4K；下方小字显示当前 ratio 下像素参考（查 IQ_PIXELS 表） |
| 8 | 比例 select | `iq-ratio` | 8 种；与 size 联动刷新像素提示 |
| 9 | 并发 select + 自定义 | `iq-concurrency` / `iq-concurrency-custom` | select 1–8 + “自定义”切数字 input（钳 1..8）；4K 时若 >2 出 amber 提示“4K 建议 ≤2” |
| 10 | 代理开关 | `iq-proxy-on` | checkbox |
| 11 | 代理地址 input | `iq-proxy-url` | placeholder `http://127.0.0.1:10808`；填 socks5:// 即时红字“本期仅支持 http/https” |

底部操作行：`iq-save` 保存、`iq-test` 测试连接（§5）、`iq-reset-default` 恢复默认（非敏感项，不清已记住的 key，需二次确认才清 key）。

## 5. 测试连接按钮状态机

- 点击 → `testing=true`，按钮 disabled 文案“测试中…（最长 60s）”+ 取消按钮（取消仅忽略结果，不中断后端）；
- 成功 → 绿 toast `连接正常（1K/1:1，xx.xs）` + `testResult` 展示；
- 失败 → 红 toast 按 `stage` 翻译：auth→“密钥无效，请检查 API 密钥”；connect→“连不上，先看代理开关/地址”；
  api→透传 message；parse→“网关返回异常，请稍后重试”。
