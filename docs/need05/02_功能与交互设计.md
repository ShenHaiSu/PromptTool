# 02 功能与交互设计：批量 / 循环无限生图

## 1. 目标与非目标

- 目标：在现有「批量工厂（prompt 批量）」旁新增「生图队列」模块：把随机引擎产出的英文终稿
  送往 Agnes 生图接口，支持**单次批量**与**循环无限生成**，可高度配置、可随时停止、可回放复现。
- 非目标：一期不做图生图/多图合成 UI（协议层预留 `extra_body.image` 透传，见 03）；
  不做图片编辑、放大、后处理。

## 2. 配置项（全部必填可配，持久化到本地）

| # | 配置项 | 控件 | 取值 / 默认 |
|---|---|---|---|
| 1 | 协议 | select | 仅 `agnes`（预留 `openai-compat` 扩展位）；切换协议即切换请求体 builder |
| 2 | 循环生成 | 是/否开关 | 默认否；开 = 任务完成后按策略自动补充新任务，直到手动停止 |
| 3 | 点击随机后循环 | 是/否开关 | 默认否；开 = 在「批量工厂」点随机生成的同时自动启动生图循环（§3） |
| 4 | API 路径 | 文本输入 | 默认 `https://apihub.agnes-ai.com`；允许自建网关/镜像站 |
| 5 | API 密钥 | 密码输入 | 默认空；仅内存持有，显式勾选才落盘（§5 安全） |
| 6 | 生图输出路径 | 路径输入 + 选择目录按钮 | 默认 `<data_dir>/output/images`；复用 export.rs 路径归一化规则 |
| 7 | 生图分辨率 | select | `1K 2K 3K 4K`，默认 `1K`（免费期建议默认 1K，2K 按需） |
| 8 | 生图比例 | select | `1:1 3:4 4:3 16:9 9:16 2:3 3:2 21:9`，默认 `1:1` |
| 9 | 并发数量 | select 1–8 + 自定义数字 | 默认 2；上限 8（一期），Rust 端信号量硬钳制 |
| 10 | 网络代理启用 | 是/否开关 | 默认否 |
| 11 | 网络代理地址 | 文本输入 | 如 `http://127.0.0.1:10808`；支持 `http/https`，`socks5h` 为二期 |

> 分辨率与比例用**两个独立 select**（用户明确要求），下发时组合为 `size + ratio`；
> 界面附注输出像素参考表（引 01 §2，不硬编码校验）。

## 3. 两种循环语义（核心定义）

- **循环生成（总开关）**：开启后，生图队列保持“饥饿补充”——每当运行中任务数 < 并发数，
  即从随机引擎取 1 条新 prompt（`randomAssembly(count=1)`，走现有去重/禁忌窗口）补入队列。
- **点击随机后循环（联动开关）**：开启后，「批量工厂」的随机/可控随机按钮在产出 prompt 的同时，
  把本次结果**整批入队**并启动循环（等价于：入队 + 打开总开关）。
  仅当总开关也开启时生效；总开关关闭时该开关置灰并提示。
- 停止条件（任一即停）：用户点停止 / 连续失败 ≥ 5 熔断 / 输出目录不可写 / 磁盘剩余 < 500MB。
  停止后队列保留，支持断点续跑。

## 4. 界面布局（与现有三栏一致，不破坏主布局）

- 位置：中间栏「批量工厂」下方新增 Tab（`Prompt 批量 | 生图队列`），或右侧栏顶部折叠区；
  推荐前者——prompt 与图片在同一心智流转，联动开关就近可见。
- 上区「生图配置」：§2 的 11 项表单 + 「测试连接」（发最小 1K 请求或仅鉴权探测，单独小脚本已验证链路）。
- 中区「队列」：任务行 = 缩略图 / 状态（排队/生成中/成功/失败）/ prompt 前 60 字 / 尺寸比例 / 耗时 / 重试·复制 prompt·打开文件·删除。
- 下区「运行条」：开始 / 停止 / 入队当前结果 / 清空已完成；进度 `成功/失败/排队中` + 并发占用指示。

## 5. 安全与隐私

- Key 默认只存内存；「记住密钥」需二次确认，落盘到 `data_dir` 下 `image_queue.secrets.json`（0600 权限思维，
  Windows 下设隐藏 + ACL 收紧），日志/截图一律打码。
- 代理地址同等对待；关闭代理开关后运行中任务继续用旧 client，新任务用新 client（client 按配置指纹缓存）。

## 6. 典型流程

1. 用户填 API 路径 + Key，点「测试连接」通过。
2. 设 `1K + 1:1`、并发 2，选中「循环生成」+「点击随机后循环」。
3. 回批量工厂点「随机生成 20 条」→ 20 条 prompt 入队并开循环；队列以并发 2 持续生成落盘。
4. 用户随时点停止；已落盘图片 + 同名 `.json`（prompt/IR hash/尺寸/耗时）保留，可回放。
