# 01 Agnes 生图协议调研结论（实测）

> 范围：`docs/need05/agnes-image-25-flash.md` + `scripts/probe_agnes.py` 实测。
> 结论以实测为准；与文档不一致处已标出。

## 1. 基础

- Endpoint：`POST {apiBase}/v1/images/generations`，默认 `apiBase = https://apihub.agnes-ai.com`。
- 请求头：`Authorization: Bearer <KEY>` + `Content-Type: application/json`。
- 模型：`agnes-image-2.5-flash`（与 2.1 Flash 参数、尺寸、计费兼容；当前全档位免费）。

## 2. 请求体（文生图最小集）

```json
{
  "model": "agnes-image-2.5-flash",
  "prompt": "<英文提示词>",
  "size": "1K",
  "ratio": "1:1",
  "extra_body": { "response_format": "url" }
}
```

- 必填：`model` / `prompt` / `size`。
- `size` 推荐档位：`1K` / `2K` / `3K` / `4K`（兼容 `1024x768` 旧写法，但会被标准化，不推荐）。
- `ratio` 可选，默认 `1:1`；支持 `1:1 3:4 4:3 16:9 9:16 2:3 3:2 21:9`。
- 输出格式只能走 `extra_body.response_format`：`url`（推荐，省带宽）/ `b64_json`。
  **禁止放顶层 `response_format`**；文生图 Base64 也可用顶层 `return_base64: true`。
- 输出尺寸参考（文档表，实测未逐项验证，逻辑层直接透传不硬编码）：

| Ratio | 1K | 2K |
|---|---|---|
| `1:1` | 1024x1024 | 2048x2048 |
| `16:9` | 1312x736 | 2624x1472 |
| `9:16` | 736x1312 | 1472x2624 |

## 3. 实测结果（2026-09-21，`probe_agnes.py`）

| 用例 | 请求 | 结果 |
|---|---|---|
| 文生图 URL | `size=1K ratio=1:1 extra_body.response_format=url` | ✅ `200`，约 11s；`data` 长度 1，`data[0]` 键为 `url / b64_json / revised_prompt`，`url` 为 `https://platform-outputs.agnes-ai.space/...` |
| 图生图字段位置 | `extra_body.image=["https://example.com/..."]` | ✅ 位置被识别：`400 image must be a public http(s) URL...`（错在 URL 不可访问，不在字段位置） |
| 图生图字段位置（反例） | 顶层 `image=[...]` | ❌ `400 upstream_error ... LLM Provider NOT provided`（顶层 `image` 不被识别） |

## 4. 文档勘误（重要，后端实现必须遵守）

1. 文档参数表称 `image: string[]` 为“顶层字段”——**错误**。实测证明图生图/多图合成必须用
   `extra_body.image: string[]`（与文档“重要说明”、全部 curl 示例一致）。
2. 图生图不需要 `tags: ["img2img"]`。
3. 输入图支持公共 HTTPS URL（需免登录直链）或 `data:image/png;base64,...` Data URI；
   不可访问的 URL 返回 400，不会静默文生图。

## 5. 给模块设计的约束

- 超时：单次生成 11s 级别，文档建议客户端超时 `60s–360s`。设计取：默认连接 15s、
  全程 300s 可配置；队列 worker 必须按任务独立超时 + 重试（仅重试网络/5xx，400 不重试）。
- 输出优先 `url`，由 Rust 后端下载后落盘；`b64_json` 仅作无公网回连兜底。
- `prompt` 来自本项目随机引擎（英文终稿 `finalPrompt`），模块只做透传 + 记录，不改写。
- Key 管理：脚本从 `../apikey.txt` 读取且只打印掩码；**设计文档与后续代码一律不得硬编码/提交 Key**。
