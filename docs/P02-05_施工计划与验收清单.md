## 3 分支与提交策略

```bash
git checkout -b feat/p02-topbar-svttk
# 按 T01→T09 粒度提交，每任务 1-3 commits
# 例：feat(styles): tokenize and add sv-ttk with fallback
#     feat(topbar): add TopPreviewBar with collapse/expand
#     feat(canvas): replace Listbox with chips + DnD + weight popover
git push -u origin feat/p02-topbar-svttk
# PR 自检：gpt-5-codex review → 人工 review → squash merge to main → tag v2.0
```

回滚：任一任务阻塞可 `git revert` 单任务 commits；`sv-ttk` 缺失自动回退，无需回滚分支。

## 4 风险与预案

| 风险 | 概率 | 影响 | 预案 |
|---|---|---|---|
| tkinter 拖拽体验差 | 中 | 中 | 降级为上移/下移按钮保留，拖拽作为增强，不阻塞发布 |
| sv-ttk 与现有 ttk 样式冲突 | 低 | 低 | `apply_style` 中 `style.configure` 覆盖顺序固定，sv-ttk 先、自定义后 |
| sash 持久化跨屏错位 | 低 | 低 | 存比例而非像素，恢复失败则忽略 |
| 旧测试硬依赖 `preview_text` | 高 | 低 | shim 转发，测试适配 0.3 天 |
| 窗口高度 900 在 768p 屏溢出 | 低 | 中 | `minsize 1100×650` 仍为 650，900 仅默认，启动时 `winfo_screenheight` 校验超限则用 860 |
