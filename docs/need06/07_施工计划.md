## 3. 风险与回滚

| 风险 | 缓解 |
|---|---|
| 嵌入算法 bug 导致图损坏 | 嵌入失败回退原图（`04` §2 `unwrap_or_else`）；§1 roundtrip 单测锁死；P1 先小批量验证 |
| 第三方工具剥离 `COM/iTXt`（如微信压缩转发） | 转发后的图视为外部图，`extract` 返回 `None`，前端 toast 而非报错 |
| `embed_meta` 误关导致新图无参数 | 开关状态在 F1 可见；`extract` 的 `None` 与“开关关闭”不可区分，验收时确认开关为开 |

回滚：`iq_set_config` 置 `embed_meta=false` 即回纯原图模式，无需发版；embed-only 无 sidecar 可回滚——如需恢复双写，按 `04` §2 被删段落的 git 历史恢复即可。
