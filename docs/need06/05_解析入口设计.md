# 05 解析入口设计：传入图片 → 解析生图参数

> 用户需求：设计一个入口，传入图片即可把生图参数解析出来。

## 1. 分层

```
纯函数 extract_embedded_meta(bytes, ext)   ← 与 embed_png/embed_jpg 对称，可单测
  ↑ 被 Tauri 命令 iq_read_image_meta 调用（读文件 + 调纯函数）
  ↑ 被前端 readImageMeta 调用（invoke）
```

另给“图反查入库”等后续功能留复用位：纯函数不碰 fs，任意字节源（剪贴板、拖拽、URL 下载）都可解析。

## 2. 纯函数

```rust
/// 返回与旧 sidecar 同构的 JSON（含 prompt/irHash/size/ratio/model/imageUrl/elapsedMs/createdAt/taskId）。
/// 无内嵌数据 → Ok(None)；格式损坏 → Err。
pub fn extract_embedded_meta(bytes: &[u8], ext: &str) -> Result<Option<serde_json::Value>, String>;
```

- PNG：遍历 chunk（`len + type + data + crc` 步进，`crc` 不校验只跳过）：找 `type == "iTXt"` 且 `data` 以 `PromptTool:Meta\x00\x00\x00\x00\x00` 开头 → 剩余部分按 UTF-8 → `serde_json::from_str`；
  - chunk 长度越界 → `Err("PNG chunk 越界")`；
  - 扫到 `IEND` 仍无命中 → `Ok(None)`；
- JPG：遍历 marker：找 `FF FE` 且 payload 以 `PMF1\x00` 开头 → 按 `(index, total)` 收集切片 → 集齐 `total` 片后按序拼接 → `from_str`；
  - 遇到 `SOS(FF DA)` 即停（后面是图像流，不再扫描）；
  - `index >= total` / `total == 0` → `Err("COM 分段头非法")`；
  - 扫完无命中 → `Ok(None)`；命中但缺片 → `Err("COM 分段缺失（index 去重后不足 total）")`；
- `ext` 非 `png/jpg` → `Ok(None)`（webp/gif/bmp 一期不支持嵌入）。

`serde_json::from_str` 失败 → `Err("内嵌 JSON 解析失败：{e}")`。

## 3. Tauri 命令（`queue.rs` 命令区新增，`lib.rs` 注册）

```rust
#[tauri::command]
pub fn iq_read_image_meta(
    file_path: String,   // 前端传 camelCase filePath
) -> Result<Option<serde_json::Value>, String> {
    // 1. 上限复用 MAX_IMAGE_BYTES：先 metadata 取 len 预检，超限 Err
    // 2. std::fs::read（命令为同步 fn，与 iq_remove 风格一致）
    // 3. ext = Path::extension（无扩展名 → Ok(None)；jpg/jpeg 归一为 jpg）
    // 4. extract_embedded_meta(&bytes, ext)
}
```

- 路径穿越：本命令只读用户已选/任务已落盘路径，前端传绝对路径；后端不做目录归一，只做 `fs::read`，失败原样返回 `io` 错误；
- 大小：`metadata` 超 `MAX_IMAGE_BYTES` 直接 `Err("文件超过 100MB 上限")`，不读入内存；
- 返回 `Ok(None)` 时前端 toast“该图无内嵌参数（可能为旧图/外部图）”，不算报错。

## 4. 前端（`src/lib/imageQueueApi.ts` + 调用方）

```ts
// imageQueueApi.ts
export async function readImageMeta(filePath: string): Promise<Record<string, unknown> | null> {
  return await invoke('iq_read_image_meta', { filePath });
}
```

- 首个调用方：`ImageTaskCard`（或 F2 队列视图行菜单“查看生图参数”）→ 弹窗展示 `prompt/size/ratio/model/createdAt`，附“复制 prompt”按钮；
- 后续可扩展“一键复用参数下单”（把解析出的 `prompt/size/ratio` 回填入队），本期只做展示 + 复制，不动入队链路。

## 5. 返回契约示例

```json
{
  "prompt": "a small glass cube on a white studio background",
  "irHash": null,
  "size": "1K",
  "ratio": "1:1",
  "model": "agnes-image-2.5-flash",
  "imageUrl": "https://platform-outputs.agnes-ai.space/x.png",
  "elapsedMs": 12345,
  "createdAt": 1720000000,
  "taskId": "uuid"
}
```

与旧 sidecar 字段一一对应，历史脚本可直接复用解析逻辑。
