# 04 落盘改造与配置：embed-only

> 用户决策：**embed-only**，不再写同名 `.json` sidecar。

## 1. `meta` 内容（与旧 sidecar 字段一致，`queue.rs:600-610` 原样沿用）

```rust
let meta = serde_json::json!({
    "prompt": task.prompt,
    "irHash": task.ir_hash,
    "size": task.size,
    "ratio": task.ratio,
    "model": AGNES_MODEL,
    "imageUrl": url,
    "elapsedMs": elapsed_ms,
    "createdAt": task.created_at,
    "taskId": task.id,
});
let meta_bytes = serde_json::to_string(&meta).unwrap_or_default().into_bytes(); // 紧凑串
```

字段不变保证 `05` 解析入口的返回契约与旧 sidecar 兼容；Key/代理明文不进图（只含上述 9 字段）。

## 2. `download_and_persist` 改造（`queue.rs:534-615`）

现状是“流式写盘”（避免大内存）。要改字节必须持有完整字节，改为**有界内存累积**（复用已有 `100MB` 守卫，峰值 ≤ 100MB + JSON 几 KB，可接受）：

```rust
// 不变：ensure_image_dir → check_disk_space → GET → 状态码/ct→ext/content-length 预检
// 改：不再边下边写，改为累积 Vec<u8>
let mut buf: Vec<u8> = Vec::new();
let mut total: u64 = 0;
while let Some(chunk) = stream.next().await {
    let bytes = chunk.map_err(|e| format!("下载中断：{}", e))?;
    total += bytes.len() as u64;
    if total > MAX_IMAGE_BYTES { return Err("图片超过 100MB 上限，已中止".into()); }
    buf.extend_from_slice(&bytes);
}
// 不变：魔数校验（对象从“流 head”变为完整原始字节，更严，行为兼容）
if !has_image_magic(&buf[..buf.len().min(16)]) {
    return Err("下载内容魔数校验失败（非 PNG/JPEG/GIF/WEBP/BMP）".into());
}
// 新增：嵌入（ext 仅 png/jpg 走嵌入，其余原样；失败回退原图）
let out: Vec<u8> = if cfg.embed_meta {
    match ext {
        "png" => embed_png(&buf, &meta_bytes).unwrap_or_else(|e| {
            eprintln!("[image-queue] png 嵌入失败，回退原图：{}", e); buf.clone()
        }),
        "jpg" => embed_jpg(&buf, &meta_bytes).unwrap_or_else(|e| {
            eprintln!("[image-queue] jpg 嵌入失败，回退原图：{}", e); buf.clone()
        }),
        _ => buf,
    }
} else { buf };
// 不变：写 .tmp → rename（把原来“流式写”换成一次性 write_all(&out)）
tokio::fs::write(&tmp_path, &out).await.map_err(|e| format!("io:写入失败：{}", e))?;
std::fs::rename(&tmp_path, &final_path).map_err(|e| format!("io:文件重命名失败：{}", e))?;
// 删除：sidecar 写盘分支（queue.rs:598-613 整段删除）
// 文件名/unique_filename_in/seq 逻辑不动
Ok(final_path.to_string_lossy().to_string())
```

注意：旧 `.tmp` 残留清理逻辑保留（超限/中断时删 `tmp_path`）。

## 3. 配置（`config.rs`）

```rust
#[serde(default = "default_true")]
pub embed_meta: bool, // 总开关，默认 true；false = 纯原图（应急回滚用）
```

- `Default` 实现、`view()`、`validate_and_normalize()` 均透传（bool 无需校验）；
- 旧 `image_queue.json` 缺字段时 `serde(default)` 回 `true`，行为 = 新默认；
- embed-only 下**不加** `keep_sidecar` 字段（用户已拍板不要 sidecar，不留半吊子开关）。

前端 F1（`ImageQueueSettings.vue`）加一个 checkbox `图片内嵌参数（embed_meta）` 即可，P2 做；后端先行时默认 true，前端无感。

## 5. 风险与回滚

- 嵌入失败 → 回退原图 + 任务仍成功（不断流、不熔断）；
- 线上异常 → `iq_set_config` 置 `embed_meta=false` 即回滚为纯原图，无需发版；
- 体积增量 = JSON 大小，对 1K–4K 图片可忽略。
