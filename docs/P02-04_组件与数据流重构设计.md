## 2 关键组件设计

### 2.1 TopPreviewBar

```python
class TopPreviewBar(ttk.Frame):
    def __init__(self, parent,
                 on_copy: Callable[[str], None],
                 on_export: Callable,
                 mono_font: tuple = ("Consolas", 11)):
        ...

    def update(self, ir: PromptIR, final_prompt: str, warnings: list[str]): ...
    def clear(self): ...

    # 内部
    # - _build_main_row: badge | prompt Label(单行省略) | actions(复制/导出/IR按钮)
    # - _build_ir_row: Text(height=4, wrap=NONE) 折叠区
    # - _toggle_expand / _toggle_ir / _on_copy / _copy_feedback
    # - bind(<Configure>, _update_wraplength)
```

- Prompt 单行省略：`tk.Label(max_width, wraplength, anchor=W)` 超长末尾 `… 展开▼`，展开后切 `tk.Text(height=3, wrap=WORD)`。
- Badge：`ttk.Label(style="Success.TLabel"/"Warning.TLabel")` 依 `warnings` 切换。
- 复制反馈：`card highlightbackground → success 350ms` + `MainWindow._show_toast`（全局队列）。

### 2.2 AssemblyCanvas

```python
class AssemblyCanvas(ttk.Frame):
    def __init__(self, parent,
                 on_changed: Callable[[list[SelectedItem], AssemblyConfig], None],
                 config: AssemblyConfig,
                 on_save: Callable[[bool], None] | None = None,
                 on_save_template: Callable | None = None):
        self.selected_items: list[SelectedItem] = []
        ...

    # 保留兼容 API（供 MainWindow/测试调用）
    def add_module(self, module: Module): ...
    def set_items(self, items: list[SelectedItem]): ...
    def apply_config(self, config: AssemblyConfig): ...
    def get_items(self) -> list[SelectedItem]: ...
    def get_locked_module_ids(self) -> set[str]: ...

    # 新增
    def has_items(self) -> bool: ...
    def _render_chips(self): ...          # 流式 pack chips
    def _on_drag_start(self, idx): ...
    def _on_drag_drop(self, from_idx, to_idx): ...
    def _on_chip_weight_click(self, idx): ...  # 弹 WeightPopover
    def _on_toggle_lock(self, idx): ...
    def _on_delete(self, idx): ...
```

Chip 结构（每行一个 `tk.Frame` + 内部 `ttk.Label`/`ttk.Button`）：

```
┌─ Chip Row ────────────────────────────────────────┐
│ [dim pill bg=DIM_COLORS[dk]]  display_name  w1.2  │  ← 点击 w1.2 弹 Popover
│                                    [🔒/🔓] [✕] │
└───────────────────────────────────────────────────┘
```

- 流式布局：`Canvas + ScrollableFrame` 垂直滚动，chips 依次 `pack(fill=X)`，支持 `MouseWheel`（`bind` 非 `bind_all`）。
- 拖拽：`bind(<Button-1>, _on_drag_start)` + `bind(<B1-Motion>, _show_ghost)` + `bind(<ButtonRelease-1>, _on_drop)`，ghost 为半透明 `Toplevel`。
- 权重 Popover：`tk.Toplevel(transient, grab_set, overrideredirect)` 内 `ttk.Spinbox(0.5~2.0 step 0.1)` + 确定，回车/失焦确认。
- 空状态：居中 `◈` + 文案 + `随机生成` 快捷按钮。

## 3 数据流

```
DimensionPanel --on_module_selected--> MainWindow._on_module_selected
  → AssemblyCanvas.add_module
    → _render_chips + _notify_changed(selected, config)
      → MainWindow._reassemble → assemble(selected, config) → (ir, final_prompt)
        → TopPreviewBar.update(ir, final_prompt, warnings)
        → StatusBar 已选数更新

AssemblyCanvas 拖拽/权重/锁定/删除 → 同上 _notify_changed 路径

BatchFactory 随机 → MainWindow._on_random(count, nsfw, partial)
  → random_assembly/partial_random_assembly → BatchFactory.update_batch
    → ScrollableFrame + BatchCard 分页渲染

BatchCard ★/↩ → MainWindow._on_batch_favorite/_on_batch_restore
  → AssemblyRepository.save / AssemblyCanvas.set_items

HistoryPanel 双击 → MainWindow._on_restore(id) → repository.load → canvas.set_items (含确认)
Template 应用 → MainWindow._on_template_apply → canvas.apply_config + _reassemble

TopBar 复制/导出 → clipboard / export_csv
```

`AssemblyConfig` 单一可信源：`MainWindow.assembly_config`，`AssemblyCanvas` 与 `TopBar` 仅持有引用或通过 `assembly_config_getter` 读取。

```python
def _build_layout(self):
    self.topbar = TopPreviewBar(self, on_copy=self._on_copy_preview,
                                on_export=self._on_export, mono_font=...)
    self.topbar.pack(fill=X, padx=8, pady=(8, 4))

    self.paned = ttk.PanedWindow(self, orient=HORIZONTAL)
    self.paned.pack(fill=BOTH, expand=True, padx=8, pady=4)

    self.dim_panel = DimensionPanel(self.paned, on_module_selected=self._on_module_selected,
                                    repos=self.repos)
    self.canvas = AssemblyCanvas(self.paned, on_changed=self._on_assembly_changed,
                                 config=self.assembly_config,
                                 on_save=self._on_save_assembly,
                                 on_save_template=self._on_save_template_menu)
    self.right = ttk.Frame(self.paned)
    self.batch_factory = BatchFactory(self.right, on_random=self._on_random,
                                      on_export=self._on_export,
                                      mono_font=..., assembly_config_getter=lambda: self.assembly_config,
                                      on_batch_favorite=self._on_batch_favorite,
                                      on_batch_restore=self._on_batch_restore)
    self.batch_factory.pack(fill=BOTH, expand=True, padx=2, pady=2)
    ttk.Separator(self.right, orient=HORIZONTAL).pack(fill=X, pady=4)
    self.history_panel = HistoryPanel(self.right, assembly_repo=..., template_repo=...,
                                      on_restore=self._on_restore,
                                      on_template_apply=self._on_template_apply)
    self.history_panel.pack(fill=BOTH, expand=True, padx=2, pady=2)

    self.paned.add(self.dim_panel, weight=30)
    self.paned.add(self.canvas, weight=38)
    self.paned.add(self.right, weight=32)

    self._restore_sash_positions()
    self._bind_shortcuts()
```

### 4.4 快捷键与持久化

```python
def _bind_shortcuts(self):
    self.bind("<Control-f>", lambda e: self.dim_panel.focus_search())
    self.bind("<Control-s>", lambda e: self._on_save_assembly(False))
    self.bind("<Control-c>", lambda e: self._on_copy_preview())
    self.bind("<Control-z>", lambda e: self.canvas.undo())  # 栈见 5.3
    self.bind("<Delete>", lambda e: self.canvas.delete_selected())

def _save_pmf_json(self):
    data = {"theme": self._theme, "geometry": self.geometry(),
            "sash": [self.paned.sashpos(i) for i in range(2)]}
    (DATA_DIR / "pmf.json").write_text(json.dumps(data, ensure_ascii=False, indent=2))
```

## 5 兼容与风险

| 风险 | 缓解 |
|---|---|
| 旧测试硬依赖 `PreviewPanel/Text` | 保留 `preview_panel.py` shim，`update_preview/update_batch` 转发至新组件，1 版本后删除 |
| `sv-ttk` 缺失 | `apply_style` try/except 回退 clam，功能不受影响 |
| 拖拽在 `tkinter` 上卡顿 | ghost 用轻量 `Toplevel(overrideredirect)`，仅重排 `selected_items`，不每帧 `assemble`，drop 时才 `notify` |
| sash 持久化跨分辨率错位 | 存储比例而非像素，恢复时 `sashpos = int(total * ratio)` |
