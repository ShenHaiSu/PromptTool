## 3. 无感升级六原则（贯穿 01–08，Code Review 必查）

1. **只加不改**：DB 用 `CREATE TABLE IF NOT EXISTS` + 新增列 `ALTER TABLE ... ADD COLUMN` 兼容；`ImageTask` 新增 `Option` 字段，老前端/测试反序列化不崩（serde `default`）。
2. **事件名冻结**：`image-queue://task-updated|stats|hungry|halted` 前缀与载荷只增字段不改名；需求1 的 hungry 仍复用 `HungryPayload{want}`。
3. **invoke 参数 camelCase**：沿用 `stores/imageQueue.ts` 约定；Rust 侧 `rename_all="camelCase"`。
4. **锁顺序**：`order → tasks`（queue.rs 头注释），新增计数器锁不得插队；临界区不跨 `await`。
5. **失败不伪造**：沿用降级策略——load 失败用缓存/空队列 + 轮询；写失败 toast 不谎报；熔断阈值 `MAX_CONSEC_FAIL=5`、磁盘水位 500MB、单图 100MB 不动。
6. **可回滚**：每需求独立 feature 开关 + 独立迁移；关开关即回现状行为（详见 08）。

## 5. 术语统一（后文通用）

- **并发量** = `config.concurrency_capped()`（1–8，默认 2）。
- **排队中** = `status==queued`；**等待列表** = `order` 中 queued 段；**起生成** = `Queued→Running` 原子标记成功并 `running+1` 之刻。
- **自动备料** = `loopEnabled`（运行中补货总开关；`autoRandomOnStart` 仅管“启动前备料”，本次不动其语义）。
- **主库** = `Default.db`/meta 库（`meta_schema.sql`）；**业务库** = 提示词库（`schema.sql`，按 `db_registry` 切换）。
