# 06 — 数据与接口契约

> 本文档为对码的唯一口径。所有 `invoke` 键为 **camelCase**（`pitfalls/01-invoke-arg-case.md`），DTO 为 `serde(rename_all="camelCase")`，错误以 `Result<T, String>` 透出为 `String`。

---

## 1. 存储（不改 Schema）

- 无新增表/列/索引。
- 批量回填仅 `UPDATE modules SET display_name=?1, updated_at=?2 WHERE id=?3`，`updated_at = chrono::Utc::now().timestamp()`。
- 维度与模块的 `is_deleted` 语义不变；回填前校验 `is_deleted=0`。

### 2.2 `TranslationUpdatePayload` / `TranslationUpdateReport`

```rust
#[derive(Debug, Clone, Serialize, Deserialize)]
#[serde(rename_all = "camelCase")]
pub struct TranslationUpdateItem {
    pub id: String,
    #[serde(rename = "displayName")]
    pub display_name: String,
}

#[derive(Debug, Clone, Serialize, Deserialize)]
#[serde(rename_all = "camelCase")]
pub struct TranslationUpdatePayload {
    pub dimension_id: String,              // Rust 侧为 dimension_id，invoke 键 dimensionId
    pub items: Vec<TranslationUpdateItem>,
}

#[derive(Debug, Clone, Serialize, Deserialize)]
#[serde(rename_all = "camelCase")]
pub struct TranslationUpdateReport {
    pub total_requested: i64,
    pub updated: i64,
    pub skipped: i64,
    pub warnings: Vec<String>,
    pub errors: Vec<String>,
}
```

### 2.3 命令签名

```rust
#[tauri::command]
pub fn db_batch_update_display_names(
    app: AppHandle,
    payload: TranslationUpdatePayload,
) -> Result<TranslationUpdateReport, String>

#[tauri::command]
pub fn db_batch_update_display_names_text(
    app: AppHandle,
    text: String,
    dimension_id: String,
) -> Result<TranslationUpdateReport, String> // 可选：解析文本直落库，复用前端解析或后端自解析
```

`lib.rs` 注册：

```rust
commands::translation::db_batch_update_display_names,
commands::translation::db_batch_update_display_names_text,
```

### 2.4 校验与事务

- `dimension_id` 空 → `Err("维度 id 不能为空")`。
- `items` 空 → `Err("无有效更新")`。
- `items.len() > 1000` → `Err("单次更新不超过 1000 条，请分批")`。
- 每项：`display_name.trim()` 空 → 跳过计 `skipped + errors`；`chars().count() > 500` 截断至 500 并计 `warnings`。
- 维度不存在/`is_deleted=1` → `Err("维度不存在或已删除")`。
- 模块 `dimension_id` 与 `payload.dimension_id` 不一致 → 跳过计 `errors`。
- `BEGIN IMMEDIATE` 包裹批量 `UPDATE`，异常 `ROLLBACK`。

## 3. 前端封装（`src/lib/db.ts`）

```ts
export type TranslationUpdateItem = {
  id: string
  displayName: string
}
export type TranslationUpdatePayload = {
  dimensionId: string
  items: TranslationUpdateItem[]
}
export type TranslationUpdateReport = {
  totalRequested: number
  updated: number
  skipped: number
  warnings: string[]
  errors: string[]
}

export async function dbBatchUpdateDisplayNames(
  payload: TranslationUpdatePayload
): Promise<TranslationUpdateReport> {
  return invoke<TranslationUpdateReport>('db_batch_update_display_names', {
    payload: {
      dimensionId: payload.dimensionId,
      items: payload.items.map(i => ({ id: i.id, displayName: i.displayName })),
    },
  })
}

export async function dbBatchUpdateDisplayNamesText(
  text: string,
  dimensionId: string
): Promise<TranslationUpdateReport> {
  return invoke<TranslationUpdateReport>('db_batch_update_display_names_text', {
    text,
    dimensionId,
  })
}
```

> `payload` 键必须为 `dimensionId`（camelCase），`items[].displayName` 亦然；`db.ts` 其余命令已遵循此约定。

## 5. 组件与状态

### 5.1 `src/components/DimensionTranslateDialog.vue`

```ts
const props = defineProps<{
  open: boolean
  dimension: Dimension | null
  modules: Module[]
}>()
const emit = defineEmits<{
  (e: 'update:open', v: boolean): void
  (e: 'applied', report: TranslationUpdateReport): void
}>()
```

Props 为受控形态，`DimensionPanel` 负责传入当前维度与 `filteredModules(dim.id)` 或全量 `modulesByDim[dim.id]`（见 5.3）。

### 5.2 `src/components/DimensionPanel.vue` 增量

- 新增状态：`showTranslateDialog: Ref<boolean>`, `translateTarget: Ref<{ dim: Dimension; modules: Module[] } | null>`, `contextMenu: Ref<{key:string;x:number;y:number;dim:Dimension}|null>`。
- 新增监听：`@contextmenu.prevent="onDimContextMenu($event, dim)"` 于维度头。
- 新增方法：`onDimContextMenu` / `closeContextMenu` / `onTranslateFromMenu`；维度头 `data-testid` 不变，菜单与对话框新增 `data-testid`（见 03/07）。

### 5.3 传入模块的口径

默认传入**当前维度全量** `modulesByDim[dim.id]`（便于整维度翻译）；若后续需要“仅已显示/已过滤子集”，再增 `scope: 'all'|'filtered'` 切换。v1 取 `all`。

### 5.4 事件

成功回填后：

```ts
emit('applied', report)
emit(LIBRARY_CHANGED, { source: 'dimension-panel', op: 'batch-update-display-names' })
push(`已更新 ${report.updated} 条中文描述`, 'success', 2000)
```

## 7. 错误码与文案（对外透出 `String` 的稳定前缀）

| 前缀/文案 | 场景 |
|-----------|------|
| `维度不存在或已删除` | `dimension_id` 校验失败 |
| `无有效更新` | `items` 为空 |
| `单次更新不超过 1000 条` | 限流 |
| `id {id} 不属于维度 {key}` | 维度归属校验 |
| `displayName 为空，已跳过` | 单项空值 |
| `JSON 解析失败:` | `db_batch_update_display_names_text` 文本解析失败 |
| `无法识别的 pmf-translation 格式` | 多块提取失败 |

前端对以上前缀做文案映射，Toast 与 Report 分级展示。
