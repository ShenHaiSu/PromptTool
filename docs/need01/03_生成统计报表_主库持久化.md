# 03 · 生成统计报表（主库持久化 + 浮层看板）

> 需求3｜改动域：`meta_schema.sql` 新表 + worker 落账钩子 + 查询命令 + `StatsReportDialog` 浮层 + 入口按钮

## 1. 记录什么（每一次生成一条账）

| 字段 | 来源 | 说明 |
|------|------|------|
| `task_id` | `ImageTask.id` | 队列任务 uuid，单发记 `single:<uuid>` |
| `status` | worker 终态 | `succeeded/failed/cancelled` 都记（报表分开统计） |
| `elapsed_ms` | worker 计时（已有 `elapsedMs`） | 含下载；单发同理 |
| `created_at` | 下单秒 | “生成次数/自然时间”的自然时间轴以 `finished_at` 为准 |
| `finished_at` | worker 结束秒 | 日×小时分组键 |
| `size/ratio` | 任务快照 | 由 `size_to_pixels()` 折算像素 |
| `pixels` | 后端折算 | 见 §2；存整数，报表直接 SUM |
| `filename/prompt_hash` | 落盘名 + `prompt_hash8` | 反查/去重凭据，不存全文 prompt |

失败也记账（`pixels=0`），“成功了多少”= `status=succeeded` 计数。

## 2. 像素折算（`size×ratio` → 约等于多少像素）

`SUPPORTED_SIZES` 仅 `1K/2K/3K/4K`（`agnes.rs:17`），按长边惯例：

```
base = {1K:1024, 2K:2048, 3K:3072, 4K:4096}
w,h = ratio_to_wh(ratio, base)  // 1:1→(b,b)；3:4→(3k,4k) 按比例缩放使长边=b；16:9 等同理
pixels = w*h
```

实现为 `queue.rs` 纯函数 `pixels_for(size,ratio) -> u64`（单测覆盖 4×8=32 组合）；未知档回 `0` 不崩。

## 3. 存哪里（跨数据库：主库，不在提示词库）

- 新表只进 `src-tauri/resources/meta_schema.sql`（主库 `Default.db`），**不动 `schema.sql`**，切换业务库不影响统计（需求原话“跨数据库/持久化”即此意）。
- 建表（`05` 有完整 SQL）：`generation_ledger(id, task_id UNIQUE, status, elapsed_ms, size, ratio, pixels, filename, prompt_hash, source[queue|single], created_at, finished_at)` + 索引 `idx_ledger_finished(finished_at)`、`idx_ledger_status`。
- 写入点：worker 终态处（`Succeeded/Failed/Cancelled` 落账，失败记 `pixels=0`）+ 单发保存处（`04`）。用 `INSERT OR IGNORE(task_id)` 防重试重复记；`retry_count` 消耗的中间重试不记账，只记终态一次。
- 主库句柄：复用 `migration::data_dir_for(app)` 定位后的 meta 连接（`commands/meta.rs/db.rs` 现有路径），不得新开业务库连接写 ledger。

## 4. 查什么（报表查询命令）

- `stats_ledger_summary{from,to} → {total, succeeded, failed, pixels, avgElapsedMs}`（看板头）。
- `stats_ledger_daily{from,to} → [{day, total, succeeded, pixels}]`（按天行）。
- `stats_ledger_hourly{day} → [{hour0..23, total, succeeded, pixels}]`（按小时柱）。
- 时区：按本机 `Local` 日切（与文件名 `Local` 一致）；`from/to` 传 `yyyy-MM-dd`，后端转秒级区间 `[00:00,次日00:00)`。

## 5. 浮层看板（入口与布局）

- **入口（定案）**：`ImageQueuePanel` 运行条 `iq-stats` 文本旁加 `button[data-testid=iq-stats-report]📊 报表`（主入口，离数据最近）；`StatusBar` 右侧加同功能小字入口（次入口，全局可达）。两者共用同一 Dialog。
- **组件**：新建 `src/components/StatsReportDialog.vue`（Teleport body，复用 `ImageTaskDetailDialog` 模式）：日期区间 input + “今天/近7天” 快捷 + 头部 4 卡（总数/成功/成功率/像素总量+平均耗时）+ 日表 + 小时柱（纯 CSS 高度条，不引图表库）。
- **空态/失败**：无数据给空态文案；主库不可用 toast + 显示内存回退（当日内存计数，标注“估算”）。

## 6. 不动点

- 队列内存 `StatsPayload` 口径不动；熔断/水位/100MB 上限不动；业务库零变更。
