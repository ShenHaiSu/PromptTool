# 07 · 验收标准与回归清单

> 判定口径：Given-When-Then；P0 必过，P1 抽查。测试数据用mock Agnes/小并发，避免烧 key。

## 1. 需求1 自动备料（P0）

- [ ] A1：并发=3，入队3条启动；当第1条 Running 后 2s 内，`hungry{want=2}` 触发且 queued 回到 3（`iq-stats` 文案见证）。
- [ ] A2：运行全程（除补货在途800ms）`queued ≥ concurrency`；停止后无新增 hungry。
- [ ] A3：`loopEnabled=关` 时行为同现状（仅饿死补货），无 top-up emit。
- [ ] A4：去重：补货随机到重复 prompt 只计 skipped，不崩不 toast 刷屏。

## 2. 需求2 文件名（P0）

- [ ] B1：入队即见 `expectedStem`（`image-task-filename-<id>` 非空，正则 `^\d{8}_\d{6}_\d{3}_[1234]K_[\d-]+_[0-9a-f]{8}$`）；成功后 `filename` 有 ext 且文件存在。
- [ ] B2：同 prompt 同秒双入队，落盘一为 `xxx.png` 一为 `xxx-1.png`，两 card 不一致。
- [ ] B3：反查五式全命中：全名 / 全小写 / 无 ext stem / `-1` 后缀名 / 绝对路径粘贴；乱串 toast“未找到”不崩；已 `clearFinished` 的提示“已清理”。
- [ ] B4：老版本任务（无新字段）反序列化不崩，卡片显示 `…` 占位。

## 3. 需求3 报表（P0 计账，P1 看板）

- [ ] C1：队列成功1次 → `generation_ledger` +1 行（`source=queue,status=succeeded,pixels>0,elapsed_ms>0`）；失败1次 → +1 行 `pixels=0`。
- [ ] C2：切换业务库（`db_registry`）后 ledger 行数不变（跨库证明）；重启 App 数据仍在（持久化证明）。
- [ ] C3：看板 `📊 报表`（运行条 + StatusBar 双入口）打开浮层；“今天” 日表= C1 行数，小時柱对应小时=1 其余 0；`summary.pixels` = 行 SUM。
- [ ] C4：`pixels_for` 32 组合单测全过；非法 size/ratio 回 0 不崩。

## 4. 需求4 单发（P0）

- [ ] D1：Tabs 第三位“手动单发”；生成后 `<img data-testid=single-shot-preview>` 出现，且输出目录文件数不变（内存证明）。
- [ ] D2：点保存 → 文件落盘命名合式 + ledger `source=single` +1；连点保存出 `-1` 后缀。
- [ ] D3：保存路径改非法值 toast 拦截不崩；空 prompt 点生成 toast 拦截。
- [ ] D4：队列运行中并行单发，两边计数互不污染；无密钥两边同拦截。

## 5. 回归红线（任一命中即打回）

- 状态机非法变迁放行 / 熔断5次不 halt / 磁盘<500MB仍写 / 100MB以上图片入库 / `order→tasks` 锁序反转 / 事件名前缀改名 / 业务库 schema 变更 / invoke 蛇形参数。
- `cargo test` + `vitest` 全绿；`vue-tsc --noEmit` 通过。
