# Need01 — 维度批量翻译 · 目录与总览

## 二、术语

| 术语 | 含义 |
|------|------|
| **片段 / Module** | `modules` 表的一行，核心字段 `contentEn`（英文原文）与 `displayName`（中文显示名） |
| **维度 / Dimension** | `dimensions` 表的一行，`key` 为机器键，`nameCn` 为中文名 |
| **回退截断** | `displayName` 为空时前端或入库以 `contentEn` 前 20 字符截断填充（`src-tauri/src/commands/batch.rs:178` 与 `segment.rs:291`） |
| **聚合提示词** | 按维度分片、每片携带 `[{id, contentEn}]` 的 LLM 指令文本，LLM 返回对应的 `{id → 中文}` 映射 |
| **分片 / Chunk** | 将维度内 `N` 个模块按固定尺寸（如 30）拆成 `ceil(N/30)` 片独立翻译 |
| **`pmf-translation` v1** | 本需求新增的翻译结果交换格式（JSON，见 05） |
| **回填 / Upsert** | 解析结果对 `modules.display_name` 的批量更新（按 `id` 定点更新） |

## 三、方案一句话

为**维度头右键**新增上下文菜单；在维度内**按 30（可切至 50）分片**生成**聚合翻译提示词**；用户投喂任意 LLM 后，将**多片结果粘贴回对话框**，前端**强校验**并在**选中子集**上执行**批量 `display_name` 回填**，事务落盘并触发 `library:changed` 刷新。

## 五、基线与非目标

- **基线复用**：`DimensionPanel.vue` / `library` / `need05Position` / `SegmentImportDialog` / `ModuleBatchDialog` 的对话框、定位、事件与测试套路（详见 01）。
- **非目标**：不做应用内直连 LLM API、不做自动翻译、不改 `contentEn`、不引入新的 `is_deleted` 语义、不碰 `assembly`/`template` 相关表。
- **破坏性约束**：维度键、模块 id 的大小写与唯一性沿用现有库；本需求不新增软删除维度/模块能力。
