# 05 · 数据模型与跨库迁移

> 三库变更总表：业务库零变更，主库加表，内存结构加字段。迁移全部幂等。

## 1. 业务库 `schema.sql`：不动

dimensions/modules/assemblies/templates/rules 均不加字段。报表只读业务库词条做随机，不写回。

## 2. 主库 `meta_schema.sql`：新增 `generation_ledger`

```sql
CREATE TABLE IF NOT EXISTS generation_ledger (
  id          TEXT PRIMARY KEY,
  task_id     TEXT NOT NULL UNIQUE,      -- 队列 uuid / single:<uuid>，防重试 double-count
  source      TEXT NOT NULL DEFAULT 'queue' CHECK (source IN ('queue','single')),
  status      TEXT NOT NULL CHECK (status IN ('succeeded','failed','cancelled')),
  elapsed_ms  INTEGER NOT NULL DEFAULT 0,
  size        TEXT NOT NULL DEFAULT '1K',
  ratio       TEXT NOT NULL DEFAULT '1:1',
  pixels      INTEGER NOT NULL DEFAULT 0,
  filename    TEXT,
  prompt_hash TEXT,
  created_at  INTEGER NOT NULL,          -- 下单秒
  finished_at INTEGER NOT NULL           -- 落账秒（报表分组键）
);
CREATE INDEX IF NOT EXISTS idx_ledger_finished ON generation_ledger(finished_at);
CREATE INDEX IF NOT EXISTS idx_ledger_status ON generation_ledger(status);
CREATE INDEX IF NOT EXISTS idx_ledger_source ON generation_ledger(source);
```

- 迁移：在 meta 打开处执行本文件（`FOREIGN KEYS=ON/WAL` 不变）；老 `Default.db` 自动补表，新库随建。
- 清理：暂不提供删除 API；`MAX 50万行` 软上限（超限 toast 提示但不删，由 08 二期定归档）。

## 3. 内存 `ImageTask`：加两字段（02）

```rust
#[serde(default)] pub expected_stem: Option<String>,
#[serde(default)] pub filename: Option<String>,
```

- `iq_list/task-updated` 透出；`iq_clear_finished` 清掉后反查即不可达（预期）。
- 单发不进 `tasks` map，无需此二字段（用 `iq_save_preview` 返回值展示）。
