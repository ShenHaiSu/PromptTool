# 07 — 施工计划与验收标准

> 结论先行：分 **3 个阶段 5 个任务**落地，沿用本仓 `vitest + tauri` 的单测与集成回归路径；以 **维度右键→分片提示词→粘贴多片→选择性回填→库刷新** 的全链路 E2E 为收口标准。

## 3. 各任务验收

### T1 — 右键菜单底座

- 右键维度头出现菜单，首项 `批量翻译（中文描述）` 可点击；空维度该项 `disabled`。
- `Escape` / 点击外部 / 滚动 / resize / 切维度 → 菜单关闭。
- 视口边缘右键，菜单不溢出（`calcMenuPos`）。
- 单测：`DimensionPanel.translate.test.ts` 覆盖 `contextmenu` → 菜单出现 → 点击触发 `update:open`。

### T2 — 聚合提示词与分片

- `translationPrompt.test.ts`：`chunkModules` 边界（0/30/31/1000）、`buildTranslationPrompt` 含 `dimensionKey/chunkId`、输出为合法 JSON 结构、`estimateTranslationTokens`。
- 对话框 Step1：`N=237, size=30 → P=8`；`size→50` 即时重算；复制本片/复制全部/下载均可验证（`navigator.clipboard` mock + `Blob` 断言）。

### T3 — 结果解析与预览

- `translationParse.test.ts`：单片/`多片拼接`/`含 fence`/`含解释文本`/`重复 id`/`扁平 map`/`空 zh`/`非本维度 id`/`超长截断` 九类用例。
- 对话框 Step2→Step3：粘贴多片 JSON → 统计 `blocks/uniqueIds/duplicate` → 分页预览 → 过滤器 → 行内编辑 → 选择（全选/取消/仅当前页）。

### T4 — 批量回填链路

- `translation.rs` 单测：正常 30 条更新、跨维度 id 跳过、`emptyZh` 跳过、超长截断、维度不存在、`>1000` 限流、事务回滚。
- E2E：对话框选中 5 条 → 应用 → `report.updated=5` → 面板对应 `module-row` 的 `displayName` 即时变中文 → `library.total` 不变。

## 6. 手工复测脚本

1. 准备维度 `pose` 内 65 条 `contentEn`（可用 `ModuleBatchDialog` 导入 65 行英文）。
2. 右键 `pose` → 批量翻译 → Step1 切 30/片，核对 `3 片`与每片 preview。
3. 依次将 3 片提示词投喂 LLM，收集 3 段 JSON（每段含 fence）。
4. 回到 Step2 一次性粘贴 3 段（含 fence 与空行）→ 解析并预览 → 核对 `65 唯一 id`。
5. 修改其中 2 行新中文 → 取消勾选 1 行 → 应用 → 核对 `updated=64`、报告与面板中文。
6. 再次粘贴含 1 个非本维度 id 的结果 → 核对该行置灰 `非本维度` 且默认不选。

## 8. 风险与回退

| 风险 | 缓解 |
|------|------|
| 分片提示词跨模型解析差异 | 输出格式强调“仅 JSON”，并在解析层宽容多形态 |
| 大粘贴解析卡顿 | 解析为同步纯函数，`N=2000` 仍 < 50ms；预览分页避免 DOM 爆炸 |
| 回填误覆盖 | 预览对比 + 选择性回填 + 报告留存；库层事务保证要么全提交要么回滚 |

回退：Revert `translation` 相关提交即可，`modules.display_name` 已更新的数据不受回退影响（需用户手动改回或用导出回滚）。
