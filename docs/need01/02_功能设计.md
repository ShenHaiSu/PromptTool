## 1. 设计目标与非目标

**目标：**

- 在**维度面板**语境下，为已选**单一维度**提供"粘贴 N 行 → 预览去重 → 一键批量创建词条"的闭环，操作不超过 3 步；
- 复用现有去重口径与存储约束，不引入新表/新迁移；
- 对 1~500 行规模保持流畅，无白屏/长阻塞。

**非目标：**

- 不替代 `SegmentImportDialog` 的跨维度 LLM 分段能力；
- 首版不做 CSV 多列解析、标签批量打标、从批量结果直接建模板等扩展。

## 2. 交互设计

### 2.1 入口

- **主入口：** 维度头部操作区新增按钮 `批量`（`data-testid="dim-batch-module-${dim.key}"`），与现有的 `+`（单条新建）并列；
- **次入口（可选）：** 维度空态/条目列表底部提供"批量粘贴"文字链，指向同一弹窗；
- **禁用态：** 当维度不存在或 `isDeleted` 时按钮隐藏（与现有 `+`/`✎` 一致）。

### 2.2 弹窗：`ModuleBatchDialog.vue`（新建）

**信息架构（上下分三区）：**

```
Header：批量新增 — {dimension.nameCn} / {dimension.key}    [✕]

[配置区]
  维度：{nameCn} / {key}（只读，来自入口维度）
  去重策略：○ 跳过重复（推荐）  ○ 覆盖更新（更新 displayName/weight/isNsfw/notes）
  权重/NSFW（统一应用于本批次新增行）： weight [slider + number 0.5~2.0]  NSFW [checkbox]

[粘贴区]
  文本域（textarea，min-h 160px，placeholder 见下）
  统计条：已粘贴 {有效行} 行 · 空行 {n} · 重复行 {n}（批次内）· 超长 {n}
  操作：[清空]  [导入文件 .txt（后置，可先隐藏）]

[预览区]（粘贴后自动生成，无需额外点击"解析"）
  表格/列表：行号 | contentEn（截断显示，hover 全文） | 状态（有效/批次内重复/已存在-跳过/已存在-覆盖/超长截断/空行忽略）
  筛选：全部 / 有效 / 重复 / 超长
  分页：当 > 50 行时分页或虚拟滚动（首版分页即可，复用 SegmentImportDialog 的分页模式）

Footer：
  [取消]  [仅校验]  [创建 {有效行} 条]（有效行为 0 时禁用）
  结果区（创建后）：成功 {created} · 更新 {updated} · 跳过 {skipped} · 失败 {failed} + 错误前 3 条展开
```

**文案：**

- `placeholder`：`每行一条英文片段，按回车分隔\n例如：\noversized white shirt\ncropped black tank top\nlace-trim silk camisole`
- 校验提示保持与现有 `segmentParse`/`segment.rs` 一致：超长 500 截断、空行丢弃。

### 2.3 状态与反馈

- 粘贴即本地解析（纯前端，无后端调用），预览表实时更新；
- 点击"创建"后按钮置 `loading`，后端返回后：
  - `push('已创建 x · 更新 y · 跳过 z', 'success')`；
  - 若有 `errors/warnings`，在结果区展开前 3 条；
  - 自动 `emit(LIBRARY_CHANGED)` 并 `refresh()` 维度面板；
- 失败/部分失败不关闭弹窗，允许修正后重试；完全成功可自动关闭或保持打开由用户决定（默认保持打开 1.5s 后自动关闭）。

## 3. 数据与校验规则

### 3.1 行解析规则（前端）

```ts
function parseBatchLines(raw: string, opts: { maxLines: number; maxLen: number }): {
  rows: Array<{ lineNo: number; raw: string; contentEn: string; status: 'ok'|'empty'|'duplicate_in_batch'|'too_long'|'duplicate_existing_hint' }>,
  stats: { total: number; valid: number; empty: number; dupInBatch: number; tooLong: number }
}
```

- 按 `/\r?\n/` 切行；
- 每行 `trim()`；空行 → `empty`（忽略，不计入有效）；
- `contentEn.length > 500` → `too_long`（前端标记为警告，后端截断至 500，与 `segment.rs:252` 对齐）；
- 批次内重复：以 `contentEn` 去重（是否区分大小写见 §3.3）；
- 超过 `maxLines`（默认 500）→ 截取前 500 行，提示"已截断，剩余请分批"。

### 3.2 去重策略（后端权威）

- 沿用 `db.rs: find_module_hit(conn, fmod, dimId)`：
  - 先按 `id` 命中（本场景无 `id`，等价于跳过）；
  - 再按 `(dimension_id, contentEn)` 精确匹配（大小写敏感，SQLite 默认 `=` 行为）；
- `mode === 'skip'`：命中则 `modulesSkipped++`，不写库；
- `mode === 'overwrite'`：命中则 `UPDATE modules SET content_en / display_name / weight / is_nsfw / notes / updated_at`（与 `segment.rs:334-338` 一致，`display_name` 取批次统一值或 `contentEn.slice(0,20)` 回退）。

### 3.3 大小写与空白

- **默认：** `contentEn` 以 `trim()` 后原样存储与匹配（大小写敏感），与 `segment.rs` 保持一致，避免与现有数据产生不一致；
- 可选增强（后置）：提供"忽略大小写去重"开关，若开启则后端以 `COLLATE NOCASE` 或前端归一化后匹配，需另行评估对现有 `find_module_hit` 的影响，首版不做。

### 3.4 字段派生

| 字段 | 来源 | 规则 |
|------|------|------|
| `dimensionId` | 入口维度 | 弹窗只读，不允许切换（保证"同维度"语义） |
| `contentEn` | 每行文本 | `trim()` 后非空，≤500，超长截断 |
| `displayName` | 派生 | `contentEn.slice(0, 20)`；若用户在配置区提供统一定位文案则覆盖（后置） |
| `weight` | 统一配置 | 默认 `1.0`，范围 `0.5~2.0`，步进 `0.1` |
| `isNsfw` | 统一配置 | 默认 `false` |
| `notes` | 暂无 | 首版不暴露，后续可加统一备注输入 |

## 4. 权限与边界

- 空维度、已删除维度不展示批量入口；
- 粘贴 0 有效行时"创建"禁用并提示"请先粘贴至少一行有效内容"；
- 单次 `valid` 超 500 时前端提示分批，后端亦做二次限流（见 §6）；
- `contentEn` 为空的行不入库，仅计数；
- 网络/DB 异常时回显 `String(err)`，不丢失已粘贴文本。

---

## 5. 与现有能力的协同

- 批量创建成功后复用既有刷新链路：`emit(LIBRARY_CHANGED)` → `DimensionPanel.refresh()` + `library.scheduleFetch()`（`App.vue:86-92`）；
- 不与 `SegmentImportDialog` 共用状态机，避免耦合；两者入口并存，用户按场景自选；
- 批量创建的词条立即可用于 `BatchFactory` 随机与 `AssemblyCanvas` 拼装，无需额外索引。

---

## 6. 埋点与可观测性（建议）

- 前端计数：`batch_lines_total / batch_lines_valid / batch_created / batch_skipped / batch_updated`（可仅在 `report` 中呈现，不强制上报）；
- 后端 `report.warnings` 透出截断、批次内重复等信息，前端在结果区展示。
