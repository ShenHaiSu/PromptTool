## 3. 手工验收步骤

| 步骤 | 操作 | 期望 |
|------|------|------|
| 3.1 | 在维度面板任选一维度（如 `top`），点“批量” | 弹窗打开，标题显示 `批量新增 — 上装 / top` |
| 3.2 | 粘贴含空行、重复行、超长行的 10 行文本，观察预览 | 统计条显示 `有效 n · 空行 m · 重复 k · 超长 j`，预览表行级状态色区分 |
| 3.3 | 去重策略选 `跳过`，点“创建 n 条” | Toast `已创建 a · 更新 0 · 跳过 b`，维度内新增 `a` 条，重复行未新增 |
| 3.4 | 再次粘贴相同 10 行，去重策略选 `覆盖更新`，改权重为 `1.5` | Toast `已创建 0 · 更新 c · 跳过 0`，已存在行的 `weight` 变为 `1.5` |
| 3.5 | 粘贴 500+ 行（粘贴 600 行） | 前端提示“已截断至 500 行”，后端 `warnings` 含截断提示 |
| 3.6 | 粘贴 0 有效行（全空行） | “创建”按钮禁用，提示“请先粘贴至少一行有效内容” |
| 3.7 | 创建后观察维度面板 | 条目数与计数自动更新，无需刷新页面 |
| 3.8 | 切换深色模式 | 预览表与状态色可辨，无文字不可见 |

## 5. 风险与回退

| 风险 | 缓解 |
|------|------|
| 500 行事务耗时 | 单事务内仅 `INSERT/UPDATE`，无跨表，无大 JSON 解析；500 行 <200ms 为常态，超时则分 2 批（后置） |
| 大小写去重争议 | 首版大小写敏感，与现有口径一致；后续可加开关，不改存量 |
| 粘贴大文本卡顿 | 前端解析为 O(n)，500 行无压力；预览用分页，避免一次性渲染 500 行 DOM |
| 与分段导入混淆 | 入口文案明确为“批量新增 — 同维度按行”，与“分段导入（跨维度 LLM）”区分 |

**回退：** 仅新增文件与 2 个命令，前端按钮可隐藏（feature flag 或直接注释入口），不影响存量；后端命令未调用则无副作用。
