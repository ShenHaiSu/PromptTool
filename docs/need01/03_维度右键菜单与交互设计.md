# 03 — 维度右键菜单与交互设计

> 结论先行：以**维度头 `contextmenu` 为唯一触发点**，菜单用 `Teleport + fixed + calcMenuPos` 视口自适应，首项“批量翻译（中文描述）”打开三步对话框；与既有单击/Ctrl 行为**正交不冲突**，与现有 Dialog 视觉与手势**完全对齐**。

---

## 1. 触发与冲突规则

### 1.1 触发点

- 仅在**维度头按钮**上监听：`[data-testid="dimension-header-{key}"]`。
- 事件：`@contextmenu.prevent`（右键），`@click` 仍走既有 `onDimHeaderClick`（折叠/Ctrl 禁用）。

### 1.2 互斥与阻断

| 交互 | 行为 | 备注 |
|------|------|------|
| 右键 | 打开菜单，`preventDefault` 阻断浏览器菜单 | 不触发折叠/禁用 |
| 左键单击 | 折叠/展开 | 不开菜单 |
| Ctrl/Cmd + 左键 | 维度禁用切换 | 不开菜单 |
| 菜单打开时再次右键 | 关闭旧菜单并在新坐标重开 | 以最后一次为准 |
| 搜索过滤后维度被隐藏 | 不可触发 | 与既有渲染一致 |

---

## 2. 菜单组件设计

### 2.1 挂载与定位

- 容器：`<Teleport to="body"><div fixed z-[70] ...>`，与 `selected-weight-popover` 同层策略。
- 定位：`calcMenuPos(clientX, clientY, MENU_W, MENU_H_EST, vw, vh)`，`MENU_W=200, MENU_H_EST≈96`，`GAP=8`。
- 尺寸：`w-52`，`rounded-md border bg-popover shadow-xl`，与项目 `Card` 一致。

### 2.2 菜单项（v1）

| 序号 | 文案 | data-testid | 可用条件 | 动作 |
|------|------|-------------|----------|------|
| ① | 批量翻译（中文描述） | `dim-ctx-translate-{key}` | 维度内 `modules.length > 0` | 打开 `DimensionTranslateDialog`，传入 `dimension + modules` |
| — | 分隔线 | — | — | 视觉分隔 |
| ② | 复制维度键名 | `dim-ctx-copy-key-{key}` | 总可用 | `navigator.clipboard.writeText(key)` + Toast |
| ③ | 复制维度中文名 | `dim-ctx-copy-name-{key}` | 总可用 | 同上 |

> §2.2 的 ②③ 为低成本预留，增强右键菜单的存在感与可测性；后续可增“导出该维度”等。

### 2.3 开关与可访问性

- 打开：`contextmenu` → `openMenu(key, {x,y}, dimension)`。
- 关闭：`Escape` / 点击菜单外 / 点击面板空白 / 滚动/窗口 resize / 维度切换。
- 复用 `weightPopover` 的文档级监听模式（`watch(active) → addEventListener`），收敛到同一 helpers。
- 键盘：菜单打开时↑/↓ 聚焦首项，Enter 触发，Escape 关闭（v1 可仅鼠标，键盘作为加分）。

### 2.4 测试锚点

```html
<div data-testid="dim-context-menu" data-dim-key="{key}" ...>
  <button data-testid="dim-ctx-translate-{key}">批量翻译（中文描述）</button>
</div>
```

- 断言：右键维度头 → 菜单出现；点击“批量翻译” → 对话框出现、菜单关闭。
- 空维度：`modules.length === 0` 时首项 `disabled` 并 `title="该维度暂无词条"`。

## 3. 翻译对话框交互（DimensionTranslateDialog）

### 3.1 形态与复用

- 复用 `SegmentImportDialog` 的**步骤条 + 固定高度可滚动内容区 + 底部操作区**布局。
- 尺寸：`max-w-3xl max-h-[86vh]`，步骤 `① 生成聚合提示词 → ② 粘贴 LLM 结果 → ③ 预览与回填`。
- 持久：`activeStep` 与分片配置写入 `localStorage`（`pmf:translate:chunkSize` / `activeStep`），关闭后重开保留上下文。

### 3.2 Step 1 — 生成聚合提示词

| 元素 | 说明 |
|------|------|
| 头部信息 | `维度 {nameCn / key} · {N} 条 · 分 {P} 片（{chunkSize}/片）`，附 `chunkSize` 切换（30 / 50）与“仅本维度”提示 |
| 分片列表 | 每片一行：`片 {i}/{P} — {size} 条 — 预估 {tokens} tokens` + 按钮：`复制本片` `预览本片` |
| 批量操作 | `复制全部 {P} 片`（片间 `---` 分隔，首行加总览） + `下载全部`（单 md 多段）+ `下载为多文件`（可选） |
| 指令预览 | 折叠 `Card` 展示首片全文（`pre whitespace-pre-wrap`），随分片切换更新 |
| 空态 | `N === 0` 时提示“该维度暂无词条，无需翻译”并禁用复制/下载 |

- 复制：`navigator.clipboard.writeText` + `push("已复制片 {i}")`；失败回退 `textarea + execCommand`。
- 下载：`Blob("text/markdown") + createObjectURL + a.click`，文件名 `pmf-translate-{key}-{YYYYMMDD-HHmmss}.md`。

### 3.3 Step 2 — 粘贴 LLM 结果

| 元素 | 说明 |
|------|------|
| 输入区 | `textarea` 占位“粘贴 LLM 返回的 JSON（支持一次贴多片、含 ```json fence、含多余解释）”` |
| 辅助 | `选择 .json/.txt` 文件（`FileReader` 读入并追加到输入区） + `清空` + `解析并预览 →` |
| 即时反馈 | 顶部 `Badge`：`已粘贴 {bytes} · 探测到 {blocks} 个 JSON 块`（基于 `extractJsonBlock` 多块提取） |
| 容错 | 支持用户把多片 LLM 输出**一次性全贴**（含每片独立 fence 段）；不支持的文本在解析后计入 `errors` 并引导“请贴 JSON” |

### 3.4 Step 3 — 预览与回填

| 元素 | 说明 |
|------|------|
| 统计条 | `共 {ids} 唯一 id · 本维度命中 {hit} · 非本维度 {unknown} · 重复 id {dup} · 空中文 {empty}` |
| 过滤 | `全部 / 待复核 / 非本维度 / 重复 / 空值` + 搜索（按 `contentEn/displayName/新中文`） |
| 分页 | `pageSize 20`，与 `ModuleBatchDialog` / `SegmentImportDialog` 一致的分页控件 |
| 行结构 | `checkbox + [id] + contentEn 截断 + → + 新中文（可编辑） + 原 displayName 灰显 + 状态 Badge + 警告 ⚠` |
| 批量选择 | `全选合法` / `取消全选` / `仅选当前页` / `反选`；默认**全选合法**，非法（非本维度/空中文）默认不选 |
| 操作 | `已选 {K} 条 — 应用到词库`（`disabled` 当 `K===0` 或 `applying`） + `返回修改` + `取消` |
| 报告区 | 成功后 `Card`：`成功 {updated} · 跳过 {skipped} · 错误 {errs}` + 前 3 条错误/警告展开 |

- 行内编辑：新中文可点击改为 `Input`，即时校验长度（1..500），失焦回写 `pendingMap`。
- 对比：`原中文（灰） → 新中文（强调）`，`contentEn` 用 `title` 气泡展示全量。

## 4. 状态机

```
closed
  —(右键维度头)→ menuOpen{key, pos, dimension}
  —(选 首项)→ dialogOpen{dimension, modules, chunkSize, activeStep=1}
             ├─ Step1: prompts[] 已生成（纯前端，无请求）
             ├─ Step2: rawResultText（粘贴）→ parse() → validation
             └─ Step3: pendingMap(id→新中文) + selection(Set<id>) → apply()
  —(Escape/点击外部/关闭按钮)→ closed
```

所有中间态保留在对话框组件内，关闭时**不清空** `rawResultText` 与 `pendingMap`（便于用户纠错重提），提供显式“清空重来”按钮。

---

## 5. 视觉与动效

- 菜单：`animate-in fade-in slide-in-from-top-1`，与项目 `radix-vue` 风格一致（无依赖亦可手写 `transition`）。
- 对话框：沿用 `SegmentImportDialog` 的 `fixed inset-0 bg-black/40` 遮罩，点击遮罩关闭（`@click.self`）。
- 按钮主次：主按钮 `default`（回填），次要 `outline`/`ghost`，与 `DimensionPanel` 一致。

---

## 6. 无障碍与空态

- 菜单项 `role="menuitem"`（如无 `radix` 可用 `button` 语义保证可点击）。
- 空维度、搜索无结果、`N > 500` 分片过多的提示与现有面板空态文案对齐。
- 复制/下载失败有 Toast，非阻塞。
