# 04 — 聚合提示词与分片策略设计

> 结论先行：按 **30 条/片（可切 50）**将维度内 `N` 条拆成 `ceil(N/30)` 个独立翻译任务；每片提示词携带 `dimensionKey/chunkId + [{id, contentEn}]`，LLM 仅回 `items: [{id, zh}]`；模板复用 `segmentPrompt.ts` 的**角色/任务/输出约束/输出格式/few-shot/输入**六段式，保证多模型下结果可解析。

---

## 1. 分片策略

### 1.1 切分算法

```ts
function chunkModules<T>(items: T[], size: number): T[][] {
  const out: T[][] = []
  for (let i = 0; i < items.length; i += size) out.push(items.slice(i, i + size))
  return out
}
```

- 输入：`modules: Module[]`（已按 `createdAt` 或 `displayName` 稳定排序，确保多次打开顺序一致）。
- 尺寸：`chunkSize ∈ {30, 50}`，默认 `30`，用户在 Step1 通过 `Select` 切换；切换后即时重算分片并更新统计与预览。
- 边界：`N = 0` 不生成提示词；`N ≤ size` 为 1 片；`N = 1000, size=30 → 34 片`。

### 1.2 分片元信息

| 字段 | 说明 |
|------|------|
| `chunkId` | `c01..cNN`（两位数，不足补零，便于用户与 LLM 对齐） |
| `totalChunks` | 总片数 `P` |
| `totalModules` | `N` |
| `dimensionKey` / `dimensionNameCn` | 维度标识与中文名，注入提示词 |
| `range` | 本片在总表中的 `offset + size`，如 `1-30 / 237` |

> 所有字段注入提示词头与 JSON 结构，确保多片结果可合并去重。

## 2. 提示词模板

### 2.1 六段式结构（对齐 `segmentPrompt.ts`）

```
# Role
# Task
# Dimensions（单维度上下文，含互斥说明）
# Output Constraints
# Output Format（pmf-translation v1）
# Few-shot Examples（1 完整示例）
# Input — Translate chunk cXX/P (M items)
```

### 2.2 模板全文（单片 `buildTranslationPrompt` 输入 → 文本）

```markdown
# Role
You are a professional translation assistant for a text-to-image prompt factory.

# Task
Translate each `contentEn` in the given chunk into concise, natural Chinese
`displayName` values. Return ONLY a JSON object conforming to Output Format.
No explanations, no markdown fences.

## 1. Context — Dimension
- dimensionKey: {key}
- dimensionNameCn: {nameCn}
- chunk: c{idx}/{total} (items {from}-{to} of {totalModules})
- Note: This is one of {total} chunks for this dimension. Translate only the items in this chunk.

Rules:
- Keep translations short (2-12 Chinese characters typical); preserve stylistic nuance (e.g. "oversized white shirt" → "宽松白衬衫").
- Do NOT repeat the English. Do NOT add explanations.

## 2. Output Constraints
- `zh` must be non-empty Chinese, length 1-500 (trimmed). Keep it inside the same semantic field as `contentEn`.
- Preserve `id` verbatim. Unknown ids will be ignored.
- Do NOT change `contentEn`. Translate only.
- If a phrase is ambiguous, choose the most common fashion/prompt sense.

## 3. Output Format (pmf-translation v1)
Return a single JSON object:

```json
{
  "format": "pmf-translation",
  "formatVersion": 1,
  "dimensionKey": "{key}",
  "chunkId": "c{idx}",
  "totalChunks": {total},
  "items": [
    { "id": "<moduleId>", "zh": "<中文显示名>" }
  ]
}
```

- `items` length must equal input item count ({size}).
- Do NOT wrap the JSON in ```json fences. Do NOT add text before/after.

## 4. Few-shot Example
Input chunk (dimensionKey=pose, 2 items):
[
  { "id": "m_pose_1", "contentEn": "standing with hands in pockets" },
  { "id": "m_pose_2", "contentEn": "sitting cross-legged on floor" }
]
Output:
{
  "format": "pmf-translation",
  "formatVersion": 1,
  "dimensionKey": "pose",
  "chunkId": "c01",
  "totalChunks": 1,
  "items": [
    { "id": "m_pose_1", "zh": "插兜站立" },
    { "id": "m_pose_2", "zh": "盘腿坐地" }
  ]
}

## 5. Input — Translate chunk c{idx}/{total} ({size} items):
[
  { "id": "{id_1}", "contentEn": "{contentEn_1}" },
  ...
]
Return ONLY the JSON object described above.
```

### 2.3 全量构建（`buildAllTranslationPrompts`）

- 对 `chunks[]` 逐片调用 `buildTranslationPrompt`，得到 `string[] prompts`（`P` 个）。
- 估算：`estimatePromptTokens(text)` 复用 `Math.ceil(len/4)`。
- 批量复制时片间以 `\n\n--- chunk cXX/P ---\n\n` 分隔，首行追加总览：

```
# PMF Translation — dimension {key} ({nameCn}) — {N} items in {P} chunks — chunkSize={size}
# Generated at {ISO8601}
```

## 3. 导出形态

| 操作 | 文件/剪贴板内容 | 文件名 |
|------|----------------|--------|
| 复制本片 | 单片提示词全文 | — |

| 下载多文件（可选） | 每片独立 md | `pmf-translate-{key}-c01-{ts}.md` … |

所有下载为 `text/markdown` Blob，复用 `SegmentImportDialog.onDownloadInstruction` 的 `createObjectURL + a.click` 路径。

## 4. 兼容与降级

- **Shorthand 输入**：分片构建不依赖后端 `dimensions` 动态表（翻译无需多维度对照），仅需当前维度；`buildDimensionTable` 不注入，避免 Prompt 过长。
- **大库提示**：当 `N > 200`（`library.isLarge` 阈值）或 `P > 10` 时，在 Step1 顶部追加 `> Note: Large chunk set (P chunks); keep each JSON self-contained and chunkId accurate.` 提示（与 `segmentPrompt:108` 同思路）。
- **token 预算**：单片 `30 * 平均 30 字符 + 模板 1.5k ≈ 2.5k tokens`，在 4k-8k 上下文下安全；50/片仍 < 4k。

## 5. 领域模块接口（前端）

```ts
// lib/translationPrompt.ts

export type TranslationChunk = {
  chunkId: string          // c01
  index: number            // 1-based
  total: number
  modules: Module[]
}

export type BuildTranslationPromptInput = {
  dimension: Dimension
  chunk: TranslationChunk
  totalModules: number
}

export function chunkModules(modules: Module[], size: number): TranslationChunk[]
export function buildTranslationPrompt(input: BuildTranslationPromptInput): string
export function buildAllTranslationPrompts(dimension: Dimension, modules: Module[], chunkSize: number): { prompts: string[], chunks: TranslationChunk[] }
export function estimateTranslationTokens(text: string): number  // wrap Math.ceil(len/4)
```

所有函数为纯函数，便于单测（见 07）。
