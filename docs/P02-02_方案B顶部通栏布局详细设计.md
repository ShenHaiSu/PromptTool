## 2 尺寸与响应式

### 2.1 窗口与断点

| 断点 | 窗口尺寸 | TopBar 高 | 左 | 中 | 右 | 适用 |
|---|---|---|---|---|---|---|
| S | 1100×650 (minsize) | 88 折叠 | 260 | 420 | 420 | 小屏/笔记本 |
| M | 1400×860 (默认) | 88/168 | 320 | 560 | 520 | 基准 |
| L | 1680×960 | 88/168 | 360 | 640 | 680 | 大屏 |
| XL | 1920×1080 | 88/168 | 380 | 760 | 780 | 2K |

`config.py` 新增：

```python
WINDOW_SIZE = "1400x900"  # +40px 给 TopBar
WINDOW_MIN_SIZE = (1100, 650)
TOPBAR_HEIGHT_COLLAPSED = 88
TOPBAR_HEIGHT_EXPANDED = 168
LAYOUT_WEIGHTS = {"left": 30, "center": 38, "right": 32}  # 现状 32:28:40 → 30:38:32
SIDEBAR_WIDTH = {"min": 260, "default": 320, "max": 420}
```

`PanedWindow` 三栏权重从 `32:28:40` 改为 `30:38:32`，把 8% 从左让给中栏；右栏加宽 80px 解决 `wraplength 520` 写死问题。

### 2.2 TopPreviewBar 内部尺寸

| 区域 | 高度 | 布局 |
|---|---|---|
| 主行 | 48px | `badge 120px | prompt 单行省略 flex | actions 160px` |
| IR 折叠区 | 0px（折叠）/ 80px（展开，含 4px 分隔线） | `JSON Text height=4` + `warnings 列表` |
| 容器 | 88px 折叠态 = 48 + 16 上下内边距 + 24 menu | `pack(fill=X)` 不参与 Paned 权重 |

Prompt 单行省略：`Label(anchor=W, justify=LEFT, wraplength=0 单行 + ellipsis)`，超长显示 `... 展开▼`，点击展开为 `Text(wrap=WORD, height=3)`。

### 2.3 响应式规则

- `TopBar.prompt_label.wraplength` 绑定 `TopBar.winfo_width() - badge - actions - 64`，`bind(<Configure>)` 自适应。
- `AssemblyCanvas` 内 `chips` 按 `wraplength = canvas_width - 48` 换行。
- `BatchCard.wraplength = card_width - 40`（修复现状 520 写死）。
- `PanedWindow` sash 位置持久化到 `data/pmf.json`（P02-04 中实现）。

## 3 组件状态机

### 3.1 TopPreviewBar 状态

```
stateDiagram-v2
  [*] --> Empty: 无已选
  Empty --> Filled: add/remove/reorder/weight
  Filled --> Warning: warnings 非空
  Warning --> Filled: 冲突解除
  Filled --> Expanded: 点击 </> / 展开▼
  Expanded --> Filled: 再次点击
  Warning --> Expanded: 展开看详情
  any --> Copied: 点击复制 → 绿边 350ms + Toast
```

| 状态 | prompt 显示 | badge | IR 区 | 操作 |
|---|---|---|---|---|
| Empty | `(空) — 从左侧双击添加` 灰字 | `无冲突 ✓` 绿 | 隐藏 | 复制/导出 disabled |
| Filled | 单行省略，可展开 | `无冲突` 绿 | 折叠 | 正常 |
| Warning | 同上 | `⚠ 1` 黄 + 文字 `套装互斥` | 折叠，展开后高亮 warnings | 同上 |
| Expanded | 3 行 Text 全文可选中 | 同上 | 80px Text 可复制 | 同上 |

### 3.2 AssemblyCanvas 状态

```
stateDiagram-v2
  [*] --> Empty: 0 项，显示空状态插画 + 引导文案
  Empty --> Populated: 左双击/历史回填
  Populated --> Dragging: 拖拽 chip
  Dragging --> Populated: drop 完成 → reorder + notify
  Populated --> WeightEdit: 点击 chip 权重区 → 弹 Popover(Spinbox 0.5~2.0 + 确定)
  WeightEdit --> Populated: 确定/失焦 → 更新 weight_override
  Populated --> Populated: 点 🔒 / x 删除
  Populated --> Empty: 清空全部
```

## 4 交互流

### 4.1 核心流：加词→调权重→预览→批量

```
左Tree双击 → main_window._on_module_selected
  → AssemblyCanvas.add_module(Module)
    → chips 流追加 + _notify_changed
      → MainWindow._reassemble(assemble(selected, config))
        → TopPreviewBar.update(ir, final_prompt, warnings)

Chip权重：点击权重标签 → WeightPopover(Spinbox) → confirm → update weight_override → notify

TopBar复制：TopBar._on_copy → clipboard + _show_toast + 绿边反馈
IR展开：TopBar._toggle_ir → height 0↔80 动画（after 10ms 递增）

批量：Right BatchFactory 设数量/勾选 → on_random → random_assembly → BatchFactory.update_batch
```

### 4.2 配置收敛（`... 设置`）

中栏头部 `… 设置` 按钮点击弹出 `Toplevel` 小面板：

```
┌─ 拼装设置 ──────────────┐
│ 分隔符: [", " ▼]       │
│ 权重括号: [√]          │
│ 排序: [维度顺序 ▼]     │
│ 模型: SD (只读)        │
│ [应用] [取消]          │
└────────────────────────┘
```

选项说明：`分隔符` 保留 `", " / " BREAK " / "\n"`；`排序` 显示中文 `维度顺序/自定义拖拽`，内部仍存 `dimensionOrder/customDragOrder`。

### 4.3 回填确认

`HistoryPanel` 双击/右键回填时：

```python
if canvas.has_items():
    if not messagebox.askyesno("回填确认", f"当前已选 {n} 项，将被覆盖为 {m} 项，是否继续？"):
        return
canvas.set_items(loaded)
```

批量 Card 的 `↩ 回填` 同样确认。

## 5 异常与空状态

| 场景 | 展示 |
|---|---|
| 中栏空 | 居中插画（用 `ttk.Label` 文字插画 `◈`）+ `从左侧双击添加词条` + `试试随机生成` 按钮 |
| 左搜索无结果 | `（无匹配）` + `清空搜索` 链接 |
| 右批量空 | `暂无批量结果 — 设置数量后点击随机生成` + 空插画 |
| 右历史空 | `暂无历史 — 保存方案后显示` |
| 预览空 | TopBar 灰字引导，不可复制 |
| 冲突 | badge 黄底 + TopBar 下 2px 黄边，warnings 在 IR 展开区红字 |

## 6 布局迁移策略

- 现状 `PreviewPanel` 一分为二：`TopPreviewBar`（预览+IR+复制/导出）+ `BatchFactory`（批量工厂，保留 `ScrollableFrame + BatchCard`）。
- `HistoryPanel` 保持 `Notebook 3 Tab`，但高度从 `~236px` 升至 `~328px`，`Treeview height` 从 `8` 改为 `动态 fill`。
- `MainWindow._build_layout` 从 `Paned(left, center, right_container)` 改为 `TopBar(pack top) + Paned(left, center, right)`，见 P02-04 diff。
