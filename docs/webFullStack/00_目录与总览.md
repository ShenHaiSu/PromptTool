## 核心约束（不可违背）

1. 服务端不存任何业务数据、不做身份验证。
2. 所有数据只在浏览器 `IndexedDB` + `localStorage`（仅主题/sash/几何等偏好）。
3. 跨设备/备份只靠用户手动导出/导入 JSON 文件。
4. `web-pure` 分支不合并回 `tauri`，不删除 `src-tauri/`（仅不再打包它）。

## 阶段划分（从零开始）

- 阶段一：工程基座（分支 + 去 Tauri + 纯 Web 跑通）
- 阶段二：存储层替换（IndexedDB 适配 + 种子数据）
- 阶段三：Tauri 能力降级（文件/剪贴板/多库/导出）
- 阶段四：界面交互还原（布局/对话框/快捷键/主题）
- 阶段五：导入导出与隐私（格式兼容 + 隐私文案）
- 阶段六：构建部署与验收（静态部署 + 回归）

每阶段结束都有可运行的 `bun run dev / bun run build`。
