# 09 阶段六 — 构建部署与验收

## 1. 构建部署

- `bun run build`（`vue-tsc --noEmit && vite build` 必须 EXIT:0）只产 `dist/`；`vite preview` 本地验。
- 部署：任意静态托管（Nginx/GH Pages/Netlify/Vercel/对象存储）， fallback 到 `index.html`（本应用无路由，实际不需要 rewrite）。
- 可选 PWA（本期不做，预留）：`vite-plugin-pwa` + IDB 数据不受 SW 影响说明。

## 2. 测试

- `npx vitest run`：engine/lib 解析器/stores/UI 测试全绿；Tauri 专属（`db.integration/DbManager`）删除或改走 IDB。
- 手工回归（映射 tauri 附录 F/V/P，抽核心）：
  - F：维度/词条 CRUD、拼装+规则、随机、批量虚拟化、历史/收藏/模板、翻译/生成/片段导入、规则管理、主题/快捷键/Toast/CSV/复制、导出导入。
  - V：三栏+Sash、暗色、Dialog 位置、`data-testid`。
  - P：500 卡首屏、IDB 读写无卡顿、`dist` 体积。
- 隐私验收：DevTools Network 无业务请求；Application 只出现 `pmf-web(IDB)+pmf:theme/pmf-sash/pmf-geometry(localStorage)`。

## 3. 交付

- `web-pure` 分支 `git add docs/webFullStack && git commit -m "docs(web-pure): 纯 Web 版施工手册00-09"`；打 tag `v3.0-web-pure`（可选）。
- 与 `tauri` 关系：并行维护、不合并；`src-tauri/` 保留备查。
