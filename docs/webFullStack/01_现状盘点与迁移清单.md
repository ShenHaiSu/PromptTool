## 2. 界面设计

- `src/App.vue`：无路由单页，`30:38:32` Flex 三栏（左维度/中批量/右历史）+ 2 条 Sash（`sash-left/sash-right`），`contain: layout paint`，`StatusBar` 底部（词库/导入/主题/DB 管理入口）。
- 设计系统：`src/assets/tokens.css` HSL 明暗变量 + shadcn-vue（`components/ui/*`），禁止硬编码颜色；`index.html` 首屏主题防 FOUC + `min-width 1280/min-height 720`；窗口 1600×1080。
- 对话框：`Teleport + z70 + need05Position.calcMenuPos`，`data-testid` 全覆盖（`main-layout/panel-left/panel-center/panel-right/sash-*/toasts/toast-*` 等）。

## 3. 前端方案

- `Vue 3.5 + Pinia 4 + Vite 6 + Tailwind 3 + TanStack Virtual + vue-draggable-plus`，`@ → src`，端口 1420，`bun run dev/build/preview`。
- stores 8 个：`assembly/batch/history/library/rules/dbRegistry/dimensionPanel/theme(+randomHistory)`；composables：`useSash/usePersist/useShortcuts/useToast/useVirtualList/useDragSort/useResizeObserver`。
- `src/lib/db.ts`（729 行）是全部 `invoke` 封装；`export.ts` 已是前端 Blob CSV（UTF-8 BOM）；`utils.ts/config.ts/libraryEvents.ts` 纯前端。

## 4. 交互标准

- 快捷键 `useShortcuts`：`Ctrl+F` 聚焦搜索、`Ctrl+S` 保存、`Ctrl+C` 复制、`Delete/Backspace` 删末项，输入框内不劫持（F 除外）。
- 主题：`pmf:theme/pmf-theme` 持久化 + 首屏脚本；Sash/几何：`pmf:sash/pmf-sash`、`pmf:geometry/pmf-geometry` + `beforeunload` + 768p 溢出保护。
- Toast 队列 MAX 5，溢出丢最旧，`error` 红边；全局错误 `app.config.errorHandler + window.onerror + unhandledrejection`。
- 右键菜单、维度禁用/折叠/搜索、`SaveDialog/PromptPreviewDialog` 二次确认均为纯前端交互。
