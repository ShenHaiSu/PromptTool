# 08 阶段五 — 导入导出与隐私（唯一迁移通道）

## 1. 格式（兼容 tauri 版）

`pmf-library` JSON v1，顶层：`{ format:'pmf-library', version:1, exported_at, dimensions[], modules[], tags[], module_tags[], rules[], templates[] }`。

- 去重合并规则（与 Rust 侧一致）：维度按 `key`、词条按 `id` 优先、回退 `dimensionKey+contentEn`、规则按 `id`/签名、标签按 `name`。
- 历史/拼装快照默认不随词库导出（避免臃肿），另设“完整备份（含历史/模板）”选项。

## 2. 交互

- 导出：`StatusBar「📚 词库」→ 导出 JSON/导出 CSV`，`<a download>` 直接下载；大文件（>50MB）前提示。
- 导入：同一入口 `选择文件 → 解析 → 预览计数（新增/覆盖/跳过）→ 二次确认 → 写 IDB → LIBRARY_CHANGED 刷新`。错误行宽容跳过并汇总（如 `pmf-fragments` 解析器已有行为）。
- 清空：设置里提供“清空本地数据”（二次确认 + 建议先导出）。

## 3. 隐私（写进 UI）

- 状态栏/设置页固定文案：“纯本地版：数据仅保存在本浏览器 IndexedDB，不上传、不鉴权；换浏览器/清数据会丢失，请定期导出备份。”
- 全仓禁止新增 `fetch/axios/WebSocket` 业务上报；`grep -rn "fetch(" src/lib src/stores` 应只剩测试/注释。
