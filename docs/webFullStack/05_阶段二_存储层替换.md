# 05 阶段二 — 存储层替换（IndexedDB 适配）

## 目标

`src/lib/db.idb.ts` 导出与 `db.ts` 同名函数（约 40 个，见 01§5），stores/components 只改 import 一行。

## 步骤

1. 新建 `src/lib/idb.ts`（Promise 封装）：`openDb(name, version, upgrade)`、`tx(stores, mode, fn)`、`getAll/put/del/count`，统一错误透出（供 Toast 显示）。
2. 新建 `src/lib/db.idb.ts`，逐函数对照 `commands/db.rs + batch.rs + segment.rs + translation.rs + rules.rs` 实现：
   - 维度/词条：CRUD + 软删除 + `getAllModulesGrouped/searchModules`（内存过滤即可，数据量 300-5000 条无需游标优化）。
   - 拼装/模板：`saveAssembly/saveAssemblyFromIr/listRecent/listFavorites/searchAssemblies/getAssemblyItems/loadSelectedItems/toggleFavorite/rename/softDelete` + 模板对称 4 函数，注意 `assembly_items.dimension_key` 非空、`template_items` 对称。
   - 批量/片段/翻译：`batchCreateModules_text/importSegments_text/batchUpdateDisplayNames_text` 直接复用 `segmentParse/translationParse/fragmentGenerateParse`（纯前端解析器不动），只把“落库”改写 IDB。
   - 规则：`list/create/update/delete/toggle` 全量 IDB 化。
   - `temp_carry` → `kv` store；`exportCsv/exportLibraryToDir/revealInExplorer/validateBusiness/registry/* /importLegacyDb` 在此层抛 `NotSupportedInWeb`（06 处理 UI）。
3. 新建 `src/lib/seed.ts`（14 维/311 条），`openDb` upgrade 后若空库则写入。
4. 切换 import：`App.vue/stores/*/*.vue` 把 `@/lib/db` 改为 `@/lib/db.idb`（建议 alias：先 `export * from './db.idb'` 覆盖 `db.ts`，后删 Tauri 文件）。
5. 冒烟：维度面板出现 14 维、词条可增删改、拼装可保存/收藏/回填；`vitest run src/lib src/engine src/stores` 回归。

## 验收

- `grep -rn "from '@tauri" src/` 为空；`db.ts` 无 `invoke`；刷新页面数据仍在（IDB 持久化）。
