# 04 阶段一 — 工程基座与分支策略（从零开始第 1 步）

## 前置

分支已建：`web-pure`（`git checkout -b web-pure`，基于 `tauri`）。本阶段结束标准：`bun run dev` 纯浏览器跑通、`bun run build` 只产出 `dist/`。

## 步骤

1. 锁定基线：`git -C . log --oneline -3` 确认在 `web-pure`；`git status --short` 干净。
2. 去 Tauri 化（只删调用，不删业务）：
   - `package.json`：删除 `@tauri-apps/api`、`@tauri-apps/plugin-dialog`、`@tauri-apps/plugin-opener`、`@tauri-apps/cli` 与 `tauri` script；保留 `dev/build/preview`。
   - `vite.config.ts`：删除 `TAURI_DEV_HOST`/hmr/1421 逻辑，保留 `port 1420 + @别名`；`server.watch.ignored` 去掉 `src-tauri`。
   - `src/lib/db.ts` 原文件保留为 `db.tauri.ts.bak`（不删除历史），新建 `db.idb.ts`（见 05）。
   - 全仓 `grep invoke\(@tauri` 确认只剩备份文件。
3. 保留设计系统：`src/assets/tokens.css`、`tailwind.config.js`、`index.html`（主题防闪 + 最小 1280×720）不动。
4. 冒烟：`bun install && bun run dev` 打开 `http://localhost:1420`，三栏空壳可渲染（数据为空属正常，阶段二补 seed）；`bun run build` 产出 `dist/index.html`。

## 不做的事

- 不改任何组件 UI、不改 `engine/*`、不改测试断言（失败的 Tauri 相关单测在本阶段允许跳过，阶段六统一修）。
