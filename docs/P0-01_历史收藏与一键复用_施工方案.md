## 1 背景与目标

### 1.1 现状痛点

- `assemblies` / `assembly_items` / `templates` 已在 `schema.sql:74~111` 建表，但全链路无写入、无读取，`Repository` 层仅有 `Dimension/Module/Tag/Rule` 四个仓储。
- 用户每次拼装仅能在右栏“实时预览”看到一次性结果，关闭即丢失，无法沉淀风格；批量随机结果仅内存 `PreviewPanel._batch_results`，导出后即失联。
- **批量结果区痛点（本次重点）：** `src/ui/preview_panel.py:48~73` 用单一 `tk.Text(batch_text)` 以 `--- #i ---\n{prompt}\n\n` 堆砌 1~500 条结果，① 无法快速区分/扫视 ② 无法对单条操作（复制需手动拖选）③ 无视觉层级 ④ 500 条时滚动与选中性能差 ⑤ 与“历史/收藏”无联动。
- 高频场景缺席：① 复用昨天的套装 ② 收藏本周 Top10 方案 ③ 把“分隔符/权重括号/排序”存为模板一键切换 ④ 随机 20 条后一键复制第 7 条去出图。

### 1.2 目标

- 单条拼装可 **保存为历史**，历史可 **收藏 ★ / 重命名 / 删除 / 一键回填中栏**。
- 批量随机结果可 **批量入库**（可选）。
- 拼装配置（`separator / use_weight_brackets / model_profile / sort_by` + 维度开关快照）可 **存为模板**，一键应用。
- **批量结果 Card 化：** 随机结果不再以 `Text` 直接堆砌，而是以 **独立 Card 列表** 呈现；**单击 Card 任意空白处（默认行为）即复制该条提示词全文到剪贴板**，并给予视觉反馈；Card 上提供快捷操作（复制/收藏/回填/查看 IR）。
- 全量幂等、可回滚、零破坏存量库。

### 1.3 非目标（本期不做）

- 云同步、多用户、服务端 API（留至 P2）。
- MJ/Flux 语法与负面提示词（P0-03 / P1-04）。
- 拖拽排序（P2-07，本期仅保留上移/下移，后续替换为 `Treeview DnD` 时兼容）。
- Card 虚拟化到 10k+ 条（本期上限 500 条，分页/懒加载已够用）。

## 3 总体方案

```
左栏(维度/条目) ──双击──▶ 中栏(已选拼装) ──_reassemble()──▶ 右栏(实时预览/IR)
                          │  [保存方案][收藏★]                │
                          │         │                         │
                          │   AssemblyRepository.save()       │  历史/收藏/模板 Tab
                          │         ▼                         │  ┌─────────────┐
                          └────► assemblies ──────────────────┼─▶│ 双击回填中栏│
                               assembly_items ─────────────────┘  │ 收藏/重命名 │
                               templates ──(config_json)────────▶│ 应用模板    │
                                                                 └─────────────┘
                                   ▲
                                   │  单条 Card ★收藏 → save()
                          右栏批量区 Card 流 ◀── random_assembly() ─┘
                          ┌─────────────────────────────┐
                          │ Card #1  [复制][★][↩]       │  ← 单击 Card 任意处 = 复制全文
                          │ prompt 全文 ...             │
                          │ chips: [face][top][pose]    │
                          ├─────────────────────────────┤
                          │ Card #2  ...                │
                          └─────────────────────────────┘
```

- 写路径：中栏“保存方案”→ `AssemblyRepository.save(selected, ir, final_prompt, config)` 原子写入 `assemblies + assembly_items`。
- 读路径：右栏历史/收藏列表 → `AssemblyRepository.list_*()` → 双击 → `load_assembly_items()` → `AssemblyPanel.set_items()` → `_reassemble()`。
- 模板：`TemplateRepository.save(name, config, cover_prompt)` 存 `AssemblyConfig` 快照 + 当前选中维度开关；应用时回写 `AssemblyPanel` 的 `sep/bracket/sort` 并触发 `_reassemble()`。
- **批量 Card 流：** `PreviewPanel.update_batch(results)` 不再向 `Text` 追加字符串，而是清空并批量创建 `BatchCard` 实例挂到 `ScrollableFrame`；每个 Card 持有 `ir/final_prompt/index`，默认 `bind("<Button-1>")` 即复制。

## 4 数据层设计

### 4.1 复用现有表，不改列（零破坏）

现有 DDL 已满足本期，无需 `ALTER`。仅补充查询索引与幂等迁移。

```sql
-- 幂等补充索引（若不存在）
CREATE INDEX IF NOT EXISTS idx_assemblies_favorite
    ON assemblies(is_favorite) WHERE is_deleted = 0;
CREATE INDEX IF NOT EXISTS idx_assemblies_created
    ON assemblies(created_at DESC) WHERE is_deleted = 0;
CREATE INDEX IF NOT EXISTS idx_templates_created
    ON templates(created_at DESC) WHERE is_deleted = 0;
-- 标题搜索（可选，LIKE 走全表亦可，量小）
-- 不建 FTS，本期历史 < 1k 条
```

> `DatabaseConnection._migrate()` 中追加上述 `CREATE INDEX IF NOT EXISTS` 幂等执行，保持存量库自动升级。

### 4.2 写入策略（双写快照）

- `assemblies.prompt_ir` 存 `PromptIR` 的 JSON 快照（含 `segments[{dim,text,weight,source_module_id}] + warnings`），用于历史展示不受 `modules` 后续改名/软删影响。
- `assembly_items` 存明细（`module_id/sort_order/weight_override/is_locked`），用于一键复用时精确回填。
- `templates.config_json` 存 `AssemblyConfig` + `enabled_dimension_keys`：

```json
{
  "assembly_config": {"separator": ", ", "use_weight_brackets": true, "model_profile": "sd", "sort_by": "dimensionOrder"},
  "enabled_dimension_keys": ["gender","ethnicity","height","body","face","top","bottom","shoes","accessories","pose","props","background","camera"],
  "version": 1
}
```

### 4.3 软删与收藏

- 删除 = `is_deleted=1`，列表默认 `WHERE is_deleted=0`。
- 收藏 = `is_favorite` 0/1 切换，列表支持 `WHERE is_favorite=1`。
- 历史默认按 `created_at DESC` 取最近 N 条（N=20/50/100 可配）。

## 6 Repository 设计

### 6.1 新增 `AssemblyRepository`

文件：`src/db/repository.py`（追加类，不改旧类）

```python
class AssemblyRepository:
    def __init__(self, conn: sqlite3.Connection): ...

    def save(self, title: str | None, ir: PromptIR, final_prompt: str,
             config: AssemblyConfig, items: list[SelectedItem]) -> str:
        """原子写入 assemblies + assembly_items，返回 assembly_id。事务内完成。"""

    def list_recent(self, limit: int = 20, offset: int = 0) -> list[Assembly]: ...
    def list_favorites(self, limit: int = 100) -> list[Assembly]: ...
    def search(self, keyword: str, limit: int = 50) -> list[Assembly]:
        """LIKE title/final_prompt/prompt_ir，量小不建 FTS。"""

    def get(self, assembly_id: str) -> Assembly | None: ...
    def get_items(self, assembly_id: str) -> list[AssemblyItemRow]: ...
    def load_selected_items(self, assembly_id: str) -> list[SelectedItem]:
        """JOIN modules/dimensions 还原 SelectedItem；已软删的 module 用快照占位并标记 [已失效]。"""

    def toggle_favorite(self, assembly_id: str) -> bool: ...
    def rename(self, assembly_id: str, title: str) -> None: ...
    def soft_delete(self, assembly_id: str) -> None: ...
    def soft_delete_many(self, ids: list[str]) -> int: ...

    def save_batch(self, rows: list[tuple[str|None, PromptIR, str, AssemblyConfig, list[SelectedItem]]]) -> list[str]:
        """批量随机结果一键入库（可选，复用 save 事务）。"""

    # 供 Card ★ 一键收藏便捷方法
    def save_from_ir(self, ir: PromptIR, final_prompt: str, config: AssemblyConfig,
                     is_favorite: bool = False, title: str | None = None) -> str:
        """由 BatchCard 直接保存单条，无需 SelectedItem 明细时用 ir 快照反推 assembly_items。"""
```

关键实现要点：

- `save()` 内 `BEGIN IMMEDIATE`，先 `INSERT assemblies`，再批量 `INSERT assembly_items`，`COMMIT`；异常 `ROLLBACK`。
- `prompt_ir_json = json.dumps({"segments":[...],"warnings":ir.warnings}, ensure_ascii=False)`。
- `title` 为空时自动生成 `f"{ymd} · {final_prompt[:30]}..."`。
- `load_selected_items()`：`SELECT ai.*, m.*, d.key`，若 `m.is_deleted=1` 或 `m is None`，则用 `ir` 快照构造占位 `Module(id=..., display_name="[已失效] ...", content_en=snapshot_text, dimension_key=...)`，并在返回的 `SelectedItem` 上打 `notes="[原条目已删除]"` 供 UI 黄条提示。

### 8.4 批量结果 Card 化专项（本次新增核心）

#### 8.4.1 设计目标

- **扫视效率：** 20~50 条时一眼区分编号/维度构成/警告；500 条时仍可快速滚动定位。
- **操作效率：** 单击即复制（Fitt's Law：整卡为热区），0 次拖选；高频操作（复制/收藏/回填）一键可达。
- **可扩展：** Card 复用于“历史 Card 视图”（二期），样式统一。
- **零依赖：** 仅 `tkinter/ttk`，不引入 `customtkinter` 等。

#### 8.4.2 视觉与信息架构

单个 `BatchCard`（`ttk.Frame` + `Frame` 卡片容器，`bg="#FFFFFF" bd=1 relief="solid"`）：

```
┌─ BatchCard ──────────────────────────────────────────┐
│ header:  #7   ·  6段  ·  ⚠ 1  ·  14:32:01      [复制] [★] [↩] [⋯] │
│ body:    prompt 全文（wrap, 3~5 行，超出…展开）                   │
│ chips:   [face] [top] [pose] [background]  (小圆角 Label)        │
│ warnings: ⚠ 已选全身套装，上装/下装将自动忽略（仅有警告时显示，黄底） │
└──────────────────────────────────────────────────────┘
  └─ hover: border="#3B82F6"  bg="#F8FAFC"
  └─ copied: border="#22C55E"  300ms 后回落 + Toast "已复制 #7"
  └─ nsfw: 右上角小徽标 "NSFW"
```

- 字段：
  - `header` 左：`#{index} · {len(ir.segments)}段 · {len(warnings)}警告 · {hh:mm:ss}`（时间可选，取 `created_at` 或本次生成序号）。
  - `body`：`final_prompt`（优先 `adapt_to_model` 结果，否则 `", ".join(s.text)`），`Label(wraplength=~520, justify="left")`，`font=MONO_FONT`。
  - `chips`：每个 `dimension_key` 一个小 `Label`，底色按维度映射（如 `face="#E0E7FF"`），字号 8。
  - `warnings`：有则黄底 `Label`，无则隐藏以节省高度。
- 尺寸：卡片高度自适应（80~140px），宽度随右栏自适应，卡间距 `pady=6`，圆角用 `Frame` 嵌套模拟（tkinter 无原生圆角，本期直角即可）。
- 样式集中在 `src/ui/styles.py` 新增 `CARD_*` 常量与 `style.configure("Card.TFrame")`。

#### 8.4.4 容器与性能（500 条不卡）

- **容器选型：** `Canvas + Scrollbar + ScrollableFrame`（经典 `canvas.create_window` 模式），而非直接 `Frame.pack` 500 个子项导致窗口句柄膨胀。
  - 结构：`batch_frame(LabelFrame)` 内 `ctrl 工具栏` + `canvas(Scrollabe)` + `ysb`；`canvas` 内 `inner = ttk.Frame(canvas)`，`canvas.create_window((0,0), window=inner, anchor="nw")`。
  - 滚动：`canvas.configure(scrollregion=canvas.bbox("all"))`，绑定 `<MouseWheel>`（Windows `delta/120`）与 `<Button-4/5>`（Linux）。
  - 高度：`canvas` 占满 `batch_frame` 剩余空间，`inner` 垂直堆叠 Card。
- **分页/懒加载（必做）：**
  - 首次 `update_batch(results)` 仅渲染前 `PAGE_SIZE=30` 张，底部显示 `已展示 30/200  [加载更多 30 条]` 按钮。
  - 点击“加载更多”或滚动至底部 80% 时 `after_idle` 增量追加 30 张，避免一次性创建 500 个 Frame 导致 UI 冻结（实测 500 Text 卡片约 600ms，分页后首屏 <120ms）。
  - `清空` 按钮一键销毁所有 Card 并 `seen.clear()`。
- **复用与销毁：** `update_batch` 先 `for w in inner.winfo_children(): w.destroy()`，再重建；批量生成时可复用 `BatchCard` 池（可选，二期）。
- **内存：** 500 条 `PromptIR` 仅存于 `PreviewPanel._batch_results`，不常驻 DB；Card 仅存 `final_prompt` 字符串与弱引用 `ir`。

#### 8.4.7 事件流（复制链路）

```
用户单击 Card #7
  → BatchCard._on_click(event)
    → self.clipboard_clear(); self.clipboard_append(self.final_prompt)  # 需 try/except TclError
    → self._flash_copied()  # border 绿 300ms
    → self._show_toast(f"已复制 #7")  # 顶部居中 1.2s

```

    items = list(self.assembly_panel.selected_items)

```python
# src/ui/batch_cards.py — BatchCard
class BatchCard(ttk.Frame):
    def __init__(self, parent, index, ir, final_prompt, on_copy, on_favorite, on_restore):
        super().__init__(parent, style="Card.TFrame", padding=8)
        self.final_prompt = final_prompt
        self.ir = ir
        self._build(index)
        # 整卡可点击复制（递归绑定子控件）
        self.bind("<Button-1>", self._on_copy)
        self._bind_recursive(self, "<Button-1>", self._on_copy)
        self.bind("<Enter>", lambda e: self.configure(cursor="hand2"))
        self.bind("<Button-3>", self._on_context_menu)

    def _on_copy(self, event=None):
        try:
            self.clipboard_clear()
            self.clipboard_append(self.final_prompt)
            self._flash_copied()  # 边框变绿 300ms
            self._show_toast(f"已复制 #{self.index}")
        except tk.TclError as e:
            messagebox.showinfo("复制", self.final_prompt)  # 降级
        return "break"  # 防止冒泡

# src/ui/preview_panel.py — 透传
def update_batch(self, results: list[PromptIR]):
    self._batch_results = results
    self.batch_list.set_results(results, self._config_ref)  # 内部做 final_prompt 适配与分页

def _on_card_favorite(self, ir: PromptIR, final_prompt: str):
    try:
        self.repos["assembly"].save_from_ir(ir, final_prompt, self.assembly_config, is_favorite=True)
        self.history_panel.refresh()
        self._show_toast("已收藏")
    except Exception as e:
        messagebox.showerror("错误", f"收藏失败: {e}")

def _on_card_restore(self, ir: PromptIR):
    items = self.repos["assembly"].ir_to_selected_items(ir)  # 或直接由 ir.segments 还原
    self.assembly_panel.set_items(items)
```

## 12 风险与回滚

| 风险 | 缓解 |
|---|---|
| 存量库无历史数据 | 幂等：空表即空列表，`list_recent` 返回 `[]`，UI 显示“暂无历史” |
| `module` 后续被软删导致复用失败 | 快照占位 + 黄条提示，不阻断回填 |
| 事务中途崩溃 | `assemblies` 与 `assembly_items` 同事务，失败整体回滚 |
| 历史膨胀 | 默认 `limit 50` 分页，`list_recent` 支持 `offset`，后续加“清空历史”批量软删 |
| 误触删除 | 软删 + 二次确认，可追加“回收站”查询 `is_deleted=1`（二期） |
| **500 Card 性能** | **分页 30 条/页 + `after_idle` 增量渲染 + Canvas 滚动，首屏 <120ms；500 条一次性创建改为懒加载** |
| **整卡点击误触** | **按钮上 `return "break"` 阻断冒泡；提供右键菜单与显式 [复制] 按钮双入口；可配置项 `CARD_CLICK_COPIES=True` 供用户关闭** |
| **剪贴板超长/权限** | **`TclError` 降级为弹窗展示文本；Windows 上超长分段提示** |

回滚：本方案仅增量写新表与新索引，删除 `history_panel.py / batch_cards.py / dialogs.py` 并回退 `main_window/assembly_panel/preview_panel` 改动即可回滚，无需数据迁移回滚；索引保留无害。Card 化回滚时恢复 `preview_panel.py` 的 `batch_text` Text 实现即可（保留分支备份）。

### 14.3 关键实现片段（Canvas 滚动模板）

```python
class ScrollableFrame(ttk.Frame):
    def __init__(self, parent):
        super().__init__(parent)
        self.canvas = tk.Canvas(self, highlightthickness=0)
        self.ysb = ttk.Scrollbar(self, orient="vertical", command=self.canvas.yview)
        self.canvas.configure(yscrollcommand=self.ysb.set)
        self.canvas.pack(side="left", fill="both", expand=True)
        self.ysb.pack(side="right", fill="y")
        self.inner = ttk.Frame(self.canvas)
        self._win = self.canvas.create_window((0,0), window=self.inner, anchor="nw")
        self.inner.bind("<Configure>", lambda e: self.canvas.configure(scrollregion=self.canvas.bbox("all")))
        self.canvas.bind("<Configure>", lambda e: self.canvas.itemconfig(self._win, width=e.width))
        self.canvas.bind_all("<MouseWheel>", self._on_mousewheel)

    def _on_mousewheel(self, event):
        # Windows: event.delta == ±120*n
        self.canvas.yview_scroll(int(-1*(event.delta/120)), "units")
```
