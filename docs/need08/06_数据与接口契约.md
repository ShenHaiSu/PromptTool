> 结论先行：前端新增 5 个函数 + 1 个 Dialog + 1 个 `db.ts` 封装；后端新增 1 个 Tauri 命令 + 1 个 DTO；事件复用 `LIBRARY_CHANGED` 仅新增 `op` 取值；testid 全量定稿于此，施工时禁止私自改名。

## 1. 前端契约（`DimensionPanel.vue`）

| 函数/状态 | 签名 | 说明 |

| `onToggleFromMenu` | `() => void` | 关菜单→取 fresh→`void onToggleDimension(fresh)`（复用 214-230） |

## 2. 前端契约（`src/lib/db.ts` 新增）

```ts
export type MigrateDimensionReport = {
  archive: Dimension   // 归档维度（含新 key）
  fresh: Dimension     // 新生空白维度
  moved: number        // 归档承接模块数
}
export async function dbMigrateDimension(args: { dimensionId: string }): Promise<MigrateDimensionReport> {
  // invoke 实参 camelCase 平铺（pitfalls/01-invoke-arg-case.md）：
  return invoke<MigrateDimensionReport>('db_migrate_dimension', { dimensionId: args.dimensionId })
}
```

- DTO 复用 `Dimension`（`engine/models.ts:12-24`），无需新前端类型；`archive.modules` 不返回（前端 `fetchAll` 重拉）。
- 错误透传 Rust `Err(String)`（中文人话，见 §3），前端 `catch → push('迁移失败: …', 'error')`。

## 3. 后端契约（`src-tauri/src/commands/db.rs` 新增）

```rust
// 请求（invoke 实参 camelCase）：{ dimensionId: String }
// 响应（serde rename_all="camelCase"）：{ archive: DimensionDto, fresh: DimensionDto, moved: i64 }
pub fn db_migrate_dimension(app: AppHandle, dimension_id: String) -> Result<MigrateReport, String>
```

错误表（定稿，前端原样展示）：

| 条件 | Err 文案 |
|------|----------|
| 源维度不存在/已删 | `维度 '{id}' 不存在或已删除`（与 `db_update_dimension:475` 同口径） |
| 存量模块数为 0 | `空维度无需迁移` |
| 后缀 10 次全撞 | `归档键名冲突，请重试` |
| 事务内任一 SQL 失败 | 透传 `e.to_string()`（含 UNIQUE 兜底） |

注册：`src-tauri/src/lib.rs invoke_handler` 追加 `commands::db::db_migrate_dimension`。

单测（Rust `#[cfg(test)]`，与 `db.rs:2313 create_dimension_duplicate_key` 并列）：

- `migrate_happy_path`：建维度+3 模块→迁移→断言归档 key 前缀+`moved==3`+新生 0 条+原 key 可查询到新生 id。
- `migrate_empty_rejected`：空维度→`Err(空维度无需迁移)`。
- `migrate_key_collision_retry`：预置 `{key}_bak_xxxxxx` 占位→迁移仍成功且 key 不同。
- `migrate_rollback`：mock 插入失败（`name_cn=''` 触发非空）→原维度 key 未变、无新生行。

## 4. 事件契约（`libraryEvents`）

```ts
emit(LIBRARY_CHANGED, { source: 'dimension-panel', op: 'enable-dimension' | 'disable-dimension' }) // 开关复用既有
emit(LIBRARY_CHANGED, { source: 'dimension-panel', op: 'clear-dimension' })   // 清空成功
emit(LIBRARY_CHANGED, { source: 'dimension-panel', op: 'clear-dimension-failed' }) // 清空中断（含部分删除）
emit(LIBRARY_CHANGED, { source: 'dimension-panel', op: 'migrate-dimension' }) // 迁移成功
```

- 监听方无需新增分支（现有 `scheduleFetch/fetchAll` 已订阅 `LIBRARY_CHANGED` 全量刷新）；`op` 仅用于日志与测试断言。
