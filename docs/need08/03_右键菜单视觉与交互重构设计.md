## 1. 模板改写（定稿 diff 意图）

现状（`DimensionPanel.vue:914-931`）4 项 1 线 → 目标 7 项 2 线：

```vue
<!-- 目标结构（伪代码，class 与现状对齐） -->
<div v-if="contextMenu" data-testid="dim-context-menu" ... role="menu" @click.stop>
  <!-- 上组：生产力 -->
  <button :data-testid="`dim-ctx-translate-${contextMenu.key}`" ... @click="onTranslateFromMenu">
    批量翻译（中文描述）</button>
  <button :data-testid="`dim-ctx-generate-${contextMenu.key}`" ... @click="onGenerateFromMenu">
    片段批量生成</button>  <!-- ★ 去 ✨，其余不变 -->
  <button :data-testid="`dim-ctx-toggle-${contextMenu.key}`" role="menuitem"
    class="flex w-full items-center rounded px-3 py-2 text-left text-sm hover:bg-accent"
    :title="contextMenu.dim.isEnabled ? '禁用后不参与可控随机' : '启用后恢复参与可控随机'"
    @click="onToggleFromMenu">
    {{ contextMenu.dim.isEnabled ? '禁用维度' : '启用维度' }}</button>
  <div class="my-1 border-t" />
  <!-- 中组：危险运维 -->
  <button :data-testid="`dim-ctx-clear-${contextMenu.key}`" role="menuitem"
    class="flex w-full items-center rounded px-3 py-2 text-left text-sm text-destructive hover:bg-accent disabled:opacity-50"
    :disabled="(modulesByDim[contextMenu.dim.id]?.length ?? 0) === 0"
    :title="(modulesByDim[contextMenu.dim.id]?.length ?? 0) === 0 ? '该维度暂无词条' : '删除本维度全部片段（不可恢复）'"
    @click="onClearFromMenu">清空维度内容…</button>
  <button :data-testid="`dim-ctx-migrate-${contextMenu.key}`" role="menuitem"
    class="flex w-full items-center rounded px-3 py-2 text-left text-sm text-destructive hover:bg-accent disabled:opacity-50"
    :disabled="(modulesByDim[contextMenu.dim.id]?.length ?? 0) === 0"
    :title="(modulesByDim[contextMenu.dim.id]?.length ?? 0) === 0 ? '空维度无需迁移' : '归档全部片段并重建空白维度'"
    @click="onMigrateFromMenu">迁移维度…</button>
  <div class="my-1 border-t" />
  <!-- 下组：复制 -->
  <button :data-testid="`dim-ctx-copy-key-${contextMenu.key}`" ...>复制维度键名</button>
  <button :data-testid="`dim-ctx-copy-name-${contextMenu.key}`" ...>复制维度中文名</button>

```

规范点：

- 去 ✨ 后“片段批量生成”为 6 个纯 CJK 字符，与“批量翻译（中文描述）”中英文混排高度一致，无需调 `leading`。
- 开关项用 `text-sm`（与翻译/生成同级），清空/迁移同样 `text-sm` 但叠加 `text-destructive`（`text-xs` 只保留给复制组，维持“功能 14px / 复制 12px”的既有层级）。
- `…` 为全角省略号 `…(U+2026)`，非三个半角点。
- 容器 `w-52` 不变；若“清空维度内容…”在 Windows 回退字体下换行，允许放宽到 `w-56`，以实测为准（`MENU_W` 同步，见 §3）。

## 2. 文案定稿（含禁用态）

| 项 | 启用态文案 | 禁用态 | title |
|----|-----------|--------|-------|
| 翻译 | 批量翻译（中文描述） | 空维度 `disabled` | `该维度暂无词条 / 批量翻译本维度中文描述`（既有不变） |
| 生成 | 片段批量生成 | 恒可用 | `按倾向为该维度批量生成新片段`（既有不变，去 ✨ 不改 title） |
| 开关 | `dim.isEnabled ? '禁用维度' : '启用维度'` | 恒可用 | 见 §1 |
| 清空 | 清空维度内容… | 空维度 `disabled` | 见 §1 |
| 迁移 | 迁移维度… | 空维度 `disabled` | 见 §1 |
| 复制键名/中文名 | 不变 | 恒可用 | 不变 |

Toast 口径（与既有 `push(msg, type, ms)` 对齐）：开关沿用 `已启用维度「X」/ 已禁用维度「X」，不参与可控随机`；清空成功 `已清空维度「X」，删除 N 条`；迁移成功 `已迁移 N 条到归档「archiveKey」，新生空白维度「X」可用`。

## 3. 定位与尺寸

- `src/lib/need05Position.ts:8-9`：`MENU_W 180 → 208`（与 `w-52=208px` 对齐，现状 180 偏小，底部翻转阈值偏乐观）、`MENU_H_EST 110 → 220`。
  - 估算：7 项 × ~36px = 252 + 2 线 × ~9px = 270，取 220 为“翻转触发下限”（宁早勿晚，`calcMenuPos` 只用它做溢出判断，不决定真实高度）；实测后可在 200-240 间微调，单测同步（`need05Position` 纯函数单测）。
- `Teleport to body + fixed z-[70]` 不变；清空/迁移的确认对话框另用 `z-40` 居中遮罩（与翻译/生成 Dialog 同层），因菜单已先关闭，无层级竞争。

## 4. 交互：打开 / 关闭 / 键盘（复用为主）

- 打开：`onDimContextMenu` 不变；新增项不引入新触发点。
- 关闭：`onDocClickForMenu / onDocKeydownForMenu(Esc) / onScrollOrResizeForMenu`（`DimensionPanel.vue:605-635`）原样复用；每个新动作入口首行 `closeContextMenu()`（开关/清空/迁移皆然，清空/迁移随后打开确认框）。
- 新增薄包装函数（只关菜单 + 委托，不写业务）：

```ts
function onToggleFromMenu(): void { const cur = contextMenu.value; if(!cur) return; closeContextMenu(); void onToggleDimension(cur.dim) }
function onClearFromMenu(): void { const cur = contextMenu.value; if(!cur) return; closeContextMenu(); openClearConfirm(cur.dim) }
function onMigrateFromMenu(): void { const cur = contextMenu.value; if(!cur) return; closeContextMenu(); openMigrateDialog(cur.dim) }
```

- 键盘（加分项，非阻塞）：菜单 `role=menu` 已有，既有实现无箭头导航；本期不补全键盘导航，但新增项必须可 `Tab` 聚焦（原生 `button` 默认满足）且 `Enter/Space` 可触发（原生满足）。`Esc` 关闭已覆盖。

## 5. 可访问性与回归约束

- 所有新增 `button` 带 `role="menuitem"`；清空/迁移加 `aria-label="清空维度XXX全部N条片段"`（动态，便于读屏与测试双保险）。
- 对比度：`text-destructive` 在浅/深色下均满足既有 token 约束，不自定义色值。
- 回归：`DimensionTranslate.test.ts / DimensionGenerate.test.ts` 中凡 `getByText('✨ 片段批量生成')` 改为 `'片段批量生成'`；顺序断言（翻译在生成前）保持；新增断言见 07（开关/清空/迁移三项存在性、空/非空禁用态、点击后菜单关闭）。
