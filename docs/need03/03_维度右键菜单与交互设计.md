## 3. Step1 — 倾向表单 + 拼接预览

表单字段（上）→ 生成预览（下）：

| 字段 | 控件 | 默认 | 持久键 | 说明 |
|------|------|------|--------|------|
| 期望倾向/风格 | `textarea data-testid=generate-tendency`，占位文案见 §6 | 空 | `pmf:generate:tendency` | ≤500 字，超长截断提示；支持多行 |
| 生成数量 | `select 10/20/30/50`（`data-testid=generate-count`） | 20 | `pmf:generate:count` | 即要求 LLM 返回的条数上限，>50 拒绝 |
| 示例条数 | `select 3/5/8`（`data-testid=generate-example-count`） | 5 | `pmf:generate:exampleCount` | 随机示例 K；维度存量 <K 则全取并注明 |
| 随机种子 | 只读文本 + `换一批`按钮（`data-testid=generate-reshuffle`） | `Date.now()%100000` | 不持久 | 换一批即重采样并更新种子显示 |
| 附已有清单避重 | `checkbox`（`data-testid=generate-exclude`） | on（存量>0 时） | `pmf:generate:excludeExisting` | on 时拼接「已有清单（前 30 条）+ 请勿重复」附录；存量 0 时禁用 |
| 倾向快捷 chips | 一行可选 chips（复古/街头/极简/户外/派对/职场…点击追加到 textarea） | — | 不持久 | 纯前端追加文本，不引入新语义 |

操作行：`[生成提示词]（data-testid=generate-build-btn)` → 生成后出现 `[复制全文]（generate-copy)` + `[下载 .md]（generate-download)` + token 预估（`estimateFragmentTokens=len/4`，与翻译一致）+ `[下一步 →]`。
预览区：`Card data-testid=generate-prompt-preview`，`max-h-64 overflow-auto`，`pre whitespace-pre-wrap text-xs`，与翻译 `translate-prompt-preview` 同样式。

空维度 Step1：表单全可用；示例区显示「该维度暂无词条，将使用内置示例」；已有清单 checkbox 禁用。

## 4. Step2 — 粘贴 LLM 结果

- 照抄翻译 Step2：`textarea data-testid=generate-result-textarea` + 文件选择（`.json/.txt`，`generate-result-file-input`）+ `清空` + 计数条（`已粘贴 N 字符 · 探测到约 M 个 contentEn 字段`）。

- 容错声明文案（照抄翻译口径并改格式名）：`支持一次粘贴：含 ```json fence、含多余解释、扁平数组、纯行文本（一行一条）`。

## 5. Step3 — 预览与入库

- 照抄翻译 Step3 + 批量对话框的并集：
  - 统计条（`data-testid=generate-stats`）：`共 N 条 · 可入库 M · 库内重复 D · 空行 E · 超长 T`。
  - 过滤器：`全部 / 待入库 / 库内重复 / 超长`（`data-testid=generate-filter`）+ 搜索框（id/英文/中文）。
  - 批量选择：`全选合法 / 取消全选 / 仅选当前页 / 反选` + `已选 X 条`。
  - 行：`checkbox（重复/空行禁用） + [contentEn 主] + [displayName 次] + 状态 pill（待入库/库内重复/超长已截断） + ⚠`，`data-testid=generate-row-${index}`，分页 50/页。
  - 入库选项行：`mode select（skip 去重跳过 / overwrite 覆盖同英文）` + `weight 默认 1.0（number 0.5–2.0 step 0.1)` + `isNsfw 默认 false（checkbox)`，作用于整批（透传 `batch` payload 顶层字段）。
  - `[应用到词库（X 条）]（generate-apply-btn)` + `[返回修改]` + `[清空重来]`；报告区 `generate-report`（`成功/跳过/请求 + warnings/errors 前 3 + 总数`），与翻译 `translate-report` 同构。

## 6. 文案（倾向占位与帮助，定稿）

- 倾向 textarea 占位：`例如：偏复古胶片感、80-90 年代港风，宽松廓形为主，多棉麻牛仔材质，少荧光色；避开已有基础款白衬衫……（≤500字，原样交给 LLM）`。
- Step1 帮助行（常驻小字）：`提示词会自动附上：格式要求、随机示例（K 条）、已有清单（可选）。倾向文本原样直通，仅做去围栏与截断，不改写语义。`
- 复制成功 Toast：`已复制生成提示词（约 N tokens），去任意 LLM 粘贴即可`；下载文件名见 04 §6。

## 7. 可访问性与回归约束

- 菜单项 `role=menuitem`，`Esc` 关闭、点击外部关闭、scroll/resize 关闭（沿用 `593-623` 监听组，只加不改）。
- 开合点击不受影响：`onDimHeaderClick` 的 `Ctrl+点击禁用 / 普通开合` 逻辑不动；`@contextmenu.prevent` 仍是唯一右键入口。
- `DimensionTranslate.test.ts` 不动；新增 `DimensionGenerate.test.ts` 断言：右键出第 4 项、空维度可点、倾向为空时 `生成提示词` 按钮 disabled 并提示、复制/下载/三步跳转可用。
