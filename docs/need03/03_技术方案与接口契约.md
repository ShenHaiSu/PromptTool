# Need03 · 技术方案与接口契约 — 单次少量的历史均匀随机

> **版本：** v1.0 — 2026-08-29  
> **前置：** `01_诊断与缺口分析.md` · `02_功能设计.md`

## 1. 总体选型

- **零后端、零 schema：** 仅改前端 `src/engine` + `src/stores`，不新增 Rust 命令、不改 `data/pmf.db`，与现有 `BatchFactory`/`AssemblyCanvas` 链路同构。
- **主辅双层：** 主层为模块级频率衰减（全局 `hits`），辅层为作用域分区滑动窗口（`recentByScope`），前者保长期均匀、后者保短期不撞车。
- **计算增量 <1ms：** 每次抽样仅多一次 `Map` 查 + 一次乘法，`ir.hash()` 已有；`maxAttempts` 从 `*10` 上调至 `*15` 以容纳窗口重试，不增加网络/IO。
- **持久化单 key：** `localStorage['pmf:randomHistory:v1']` 存 `hits+recentByScope+totalGenerations`，静默降级为内存态，跨会话不丢。
- **向后兼容：** 历史为空时 `effectiveWeight === weight`，行为与现版 1:1 一致；`ALPHA=0` 即可一键回退为纯随机。

## 3. 新增 — `src/engine/randomHistory.ts`

### 3.1 类型与常量

```ts
export const STORAGE_KEY = 'pmf:randomHistory:v1'
export const ALPHA = 1.0
export const WINDOW_SIZE = 20
export const MAX_SCOPES = 64
export const DECAY_EVERY = 100
export const DECAY_FACTOR = 0.95
export const HITS_PRUNE_THRESHOLD = 0.01
export const MAX_ATTEMPTS_FACTOR = 15

export type RandomHistoryState = {
  version: 1
  hits: Record<string, number>           // moduleId -> count
  recentByScope: Record<string, string[]> // scopeKey -> hash[]
  totalGenerations: number
  scopeAccessOrder: string[]              // LRU 顺序，队尾为最近
}

export function emptyHistory(): RandomHistoryState {
  return { version: 1, hits: {}, recentByScope: {}, totalGenerations: 0, scopeAccessOrder: [] }
}
```

### 3.2 作用域键

```ts
export function buildScopeKey(opts: {
  lockedIds?: string[] | Set<string>
  anchoredIds?: string[]
  enabledDimKeys: string[]
  allowNsfw: boolean
  mode: 'random' | 'partial'
}): string {
  const locked = [...(opts.lockedIds ?? [])].sort().join(',')
  const anchored = [...(opts.anchoredIds ?? [])].sort().join(',')
  const dims = [...opts.enabledDimKeys].sort().join(',')
  return `${opts.mode}|locked:${locked}|anchored:${anchored}|dims:${dims}|nsfw:${opts.allowNsfw ? 1 : 0}`
}
```

- `randomAssembly` 传 `lockedIds`，`partialRandomAssembly` 传 `anchoredIds`（`anchoredItems.map(m.id)`）；
- `enabledDimKeys` 取 `dimensions.filter(d=>d.isEnabled).map(d=>d.key)`；
- 字符串本身即 key，无需二次哈希，长度 <200。

### 3.3 权重矫正

```ts
export function effectiveWeight(rawWeight: number, moduleId: string, hits: Record<string, number>): number {
  const w = Number.isFinite(rawWeight) ? rawWeight : 1.0
  const clamped = Math.min(2.0, Math.max(0.1, w)) // 与现有 weight 钳制对齐
  const h = hits[moduleId] ?? 0
  return clamped / (1 + h * ALPHA)
}

export function effectiveWeightsForPool(
  pool: Array<{ id: string; weight: number }>,
  hits: Record<string, number>,
): number[] {
  return pool.map(m => effectiveWeight(m.weight, m.id, hits))
}
```

- `ALPHA=1.0` 时命中 1 次权重减半，命中 3 次权重为 1/4，长期自动拉平；
- 若 `sum(effective) <= 0` 则由 `weightedSample` 的现有均匀兜底分支接管。

### 3.4 窗口操作

```ts
export function isInWindow(hash: string, scopeKey: string, recentByScope: Record<string, string[]>): boolean {
  return (recentByScope[scopeKey] ?? []).includes(hash)
}

export function pushToWindow(
  hash: string,
  scopeKey: string,
  state: RandomHistoryState,
): void {
  const q = (state.recentByScope[scopeKey] ??= [])
  q.push(hash)
  if (q.length > WINDOW_SIZE) q.shift()
  // LRU
  state.scopeAccessOrder = state.scopeAccessOrder.filter(k => k !== scopeKey)
  state.scopeAccessOrder.push(scopeKey)
  if (Object.keys(state.recentByScope).length > MAX_SCOPES) {
    const evict = state.scopeAccessOrder.shift()!
    delete state.recentByScope[evict]
  }
}
```

### 3.5 记录与衰减

```ts
export function recordHit(state: RandomHistoryState, ir: import('./models').PromptIR): void {
  for (const seg of ir.segments) {
    state.hits[seg.sourceModuleId] = (state.hits[seg.sourceModuleId] ?? 0) + 1
  }
}

export function maybeDecay(state: RandomHistoryState): void {
  state.totalGenerations++
  if (state.totalGenerations % DECAY_EVERY !== 0) return
  for (const k of Object.keys(state.hits)) {
    const v = state.hits[k]! * DECAY_FACTOR
    if (v < HITS_PRUNE_THRESHOLD) delete state.hits[k]
    else state.hits[k] = v
  }
}
```

### 3.6 持久化

```ts
export function loadHistory(): RandomHistoryState {
  try {
    const raw = localStorage.getItem(STORAGE_KEY)
    if (!raw) return emptyHistory()
    const parsed = JSON.parse(raw)
    if (parsed.version !== 1) return emptyHistory()
    return {
      version: 1,
      hits: parsed.hits ?? {},
      recentByScope: parsed.recentByScope ?? {},
      totalGenerations: parsed.totalGenerations ?? 0,
      scopeAccessOrder: parsed.scopeAccessOrder ?? Object.keys(parsed.recentByScope ?? {}),
    }
  } catch { return emptyHistory() }
}

export function saveHistory(state: RandomHistoryState): void {
  try { localStorage.setItem(STORAGE_KEY, JSON.stringify(state)) } catch { /* 静默降级 */ }
}

export function clearHistory(): void {
  try { localStorage.removeItem(STORAGE_KEY) } catch {}
}
```

- 序列化后 <30KB（`hits ≤1000` + `recent ≤1280` hash），远低于 5MB；
- 多标签页以最后写入为准，不做 `storage` 事件同步，可接受。

## 4. 修改 — `src/engine/random.ts`

### 4.1 保持 `weightedSample` 签名不变

```ts
export function weightedSample<T>(pool: T[], weights: number[], k: number): T[] // 不变
```

调用方负责传入 `effectiveWeights`，函数内仍保留 `total<=0` 的均匀兜底与浮点 fallback。

### 4.2 `randomAssembly` 新签名（向后兼容）

```ts
export function randomAssembly(
  dimensions: Dimension[],
  modulesByDim: Record<string, Module[]>,
  lockedModuleIds: Set<string>,
  count: number,
  config: AssemblyConfig,
  allowNsfw?: boolean,
  history?: RandomHistoryState, // 新增可选，缺省即现行纯随机
): PromptIR[]
```

**关键改动点（`random.ts:27-74`）：**

1. 入口计算 `scopeKey = buildScopeKey({ lockedIds: [...lockedModuleIds], enabledDimKeys, allowNsfw, mode:'random' })`，`recentWindow = history?.recentByScope[scopeKey] ?? []`
2. `maxAttempts = count * MAX_ATTEMPTS_FACTOR`（15）
3. 循环内对 `pool` 计算 `effectiveWeights = effectiveWeightsForPool(pool, history?.hits ?? {})`，再 `weightedSample(pool, effectiveWeights, n)`
4. `assemble` 后 `h = ir.hash()`，依次：
   - `if (history && isInWindow(h, scopeKey, history.recentByScope)) continue`（辅）
   - `if (seen.has(h)) continue`（原批次内）
5. 成功后 `seen.add(h); results.push(ir); if(history){ recordHit(history,h); pushToWindow(h, scopeKey, history) }`
6. 循环结束 `if(history) maybeDecay(history)`（由调用方决定是否立即 `saveHistory`）

`n` 的 `0/1/2` 随机（`random.ts:58`）保持不变，不因历史而改。

### 4.3 `partialRandomAssembly` 新签名

```ts
export function partialRandomAssembly(
  dimensions: Dimension[],
  modulesByDim: Record<string, Module[]>,
  anchoredItems: SelectedItem[],
  count: number,
  config: AssemblyConfig,
  allowNsfw?: boolean,
  history?: RandomHistoryState,
): PromptIR[]
```

- `scopeKey` 使用 `anchoredIds = anchoredItems.map(it=>it.module.id)`，`mode:'partial'`；
- `gapDimensions` 的 `filterPoolByAnchor` 保持（`random.ts:142-164`）；
- `n` 的 `0/1` vs `0/1/2` 分支（`random.ts:124-125`）保持；
- 其余与 `randomAssembly` 的 1-6 步一致。

> **兼容性：** 既有调用 `randomAssembly(dims, map, locked, count, config, allowNsfw)` 仍可编译运行（`history` 可选），单测无需改动即通过；新能力由 `batch.ts` 注入历史时生效。

import { loadHistory, saveHistory, clearHistory, emptyHistory, type RandomHistoryState } from '@/engine/randomHistory'

export const useRandomHistoryStore = defineStore('randomHistory', () => {
  const state = ref<RandomHistoryState>(loadHistory())

  return { state, persist, clear }

## 6. 关键边界与校验

| 校验点 | 规则 |
|--------|------|
| `weight` 非 finite | `effectiveWeight` 中回落 `1.0` 再衰减 |
| `pool` 为空 | 按现有 `pool.length===0 continue` 跳过维度 |
| `sum(effective) <=0` | 走 `weightedSample` 的均匀兜底分支 |
| `count` 超可用组合数 | `maxAttempts` 耗尽即返回已得条数，不抛错 |
| `localStorage` 不可用/超限 | `try/catch` 静默降级为内存态 |
| `STORAGE_KEY` 版本升级 | `version !==1` 时丢弃回退 `emptyHistory()`，后续可加迁移 |
| 分区膨胀 | `MAX_SCOPES=64` + LRU 淘汰 |
| `hits` 膨胀 | 衰减+ `<0.01` 剪枝，条目数 `≤模块数` |

## 8. 性能与内存估算

| 项 | 估算 |
|----|------|
| `hits` 条目 | `≤ 模块数 ≈ 800~1000`，每条 `id(36)+number`，<15KB |
| `recentByScope` | `≤64*20` hash(32) + key(<200)，<20KB，JSON 总计 <30KB |
| 单次生成耗时增量 | `effectiveWeight` 遍历 `pool`（每维度 ≤30）+ `Set` 查，<0.5ms |
| 持久化耗时 | `JSON.stringify` + `localStorage.setItem` <2ms，仅成功时触发 |
| 衰减耗时 | 每 100 次遍历 `hits`（≤1000），<0.3ms |

## 9. 安全与兼容

- 不引入新依赖、不改 `Cargo.toml`/`capabilities`；
- 存储仅为匿名 `moduleId` 计数与 `hash`，无隐私数据；
- 旧数据不受影响，`localStorage` 的 `version` 字段保证可迁移；
- `ALPHA=0` 或 `history=undefined` 即可一键回退为现行纯随机。

## 10. 备选与舍弃

- **历史 Set / 洗牌袋作主：** 锁定可变时分区爆炸/重建成本高，已舍弃作主，仅保留窗口作辅；
- **种子随机（seedrandom）：** 可复现但与“历史均匀”的目标正交，且需改 `AssemblyConfig` 透传 `seed`，本需求不引入；
- **距离过滤（汉明距离）：** 计算重、阈值难定，留作后置增强。
