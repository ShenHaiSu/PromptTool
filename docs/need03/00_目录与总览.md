# Need03 — 维度片段 LLM 批量生成器 · 目录与总览

> **需求**：在维度开合头右键菜单新增「片段批量生成」入口；点击拉起 Dialog，用户填写期望倾向/风格后，程序自动拼接格式要求 + 随机示例片段，输出一段可直接投喂任意 LLM 的完整提示词；LLM 返回带可识别结构的新片段文本，粘贴回对话框解析预览后批量入库 `modules`。
> **一句话方案**：复用 Need01 三步对话框链路与 `batch` 同维度批量入库通道，新增一个纯前端提示词组合器（倾向直通 + 格式约束 + DB 随机示例），零 Rust 变更、零表结构迁移。

- **输出路径**：`docs/need03/`（本目录）
- **版本**：v1.0 — 2026-09-10
- **状态**：已施工并验收（2026-09-10）：前端 376 例 + 后端 48 例双绿，`vue-tsc` 干净
- **上游引用**：`docs/need01/`（右键菜单与三步对话框母版）、`docs/need02/`（IR/规则术语）、`docs/pitfalls/01-invoke-arg-case.md`（invoke 大小写铁律）

## 二、术语

| 术语 | 含义 |
|------|------|
| **维度 / Dimension** | `dimensions` 表的一行，`key` 为机器键，`nameCn` 为中文名 |
| **片段 / Module** | `modules` 表的一行，核心字段 `contentEn`（英文原文）与 `displayName`（中文显示名）；本仓库无独立 `fragments` 表，片段即模块 |
| **倾向 / Preference** | 用户在 Dialog 中填写的自由文本：期望新片段的风格、题材、时代、材质、情绪等偏好，原样直通进提示词（做长度与注记 sanitization，不做语义改写） |
| **组合器 / Composer** | 纯前端函数，把「倾向 + 格式要求 + 随机示例 + 已有清单」拼成一段完整 LLM 提示词 |
| **`pmf-fragments` v1** | 本需求新增的生成结果交换格式（JSON 主格式 + 纯行文本 fallback，见 05） |
| **随机示例** | 从该维度 DB 已有词条中随机抽取的 K 条 `contentEn`，作为 few-shot 示例；维度为空时用内置 few-shot |
| **回填 / 入库** | 解析结果经 `db_batch_create_modules` 批量新建模块（按 `contentEn` 去重，`skip/overwrite` 双模式） |

## 四、基线与非目标

- **基线复用**：`DimensionPanel.vue` 右键菜单、`DimensionTranslateDialog.vue` 三步对话框、`translationPrompt.ts` 拼接范式、`moduleBatch.ts + batch.rs` 同维度批量入库、`library` store + `LIBRARY_CHANGED` 刷新、`need05Position.calcMenuPos`。
- **非目标**：不做应用内直连 LLM API、不做自动生成、不做跨维度一次生成、不新增 Rust 命令、不新增 DB 表/字段、不改 `contentEn` 唯一性语义、不碰 `assembly`/`template`/`rules` 表。
- **破坏性约束**：沿用 `find_module_hit` 去重口径（`id` 精确或同维度 `content_en` 精确匹配，大小写敏感）；本需求不引入模糊去重。
