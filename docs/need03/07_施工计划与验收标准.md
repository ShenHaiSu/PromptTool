## 2. 验收标准

### 行为（`DimensionGenerate.test.ts`，至少 8 例）

1. 维度头右键菜单含第 4 项 `dim-ctx-generate-${key}`。
2. 空维度点击可拉起 Dialog（与翻译禁用形成对照断言）。
3. 倾向为空时 `generate-build-btn` disabled + 提示。
4. 填写倾向后生成预览含 `<user_preference>`、维度 key、`pmf-fragments` 字样且不含 ```` ``` ````。
5. `换一批` 改变示例区内容（种子变化）。
6. 粘贴含 fence JSON 可解析并跳 Step3；纯行文本可解析。
7. 库内重复行默认不勾选且 pill 为黄；`skip` 入库后报告 `modulesSkipped≥1`（用测试库）。
8. 三步步骤条可直接切换；`Esc`/外部点击关闭。

### 单测

- `fragmentGeneratePrompt.test.ts` ≥10 例（见 04 §6）。
- `fragmentGenerateParse.test.ts` ≥12 例（见 05 §6）。
- 全量：前端 `vitest` + 后端 `cargo test` 双绿（对照 need02 `329/48` 基线，不得新增失败）。

### 手工（评审演示脚本）

1. 右键 `top` 维度 → `✨ 片段批量生成` → 倾向填「复古胶片港风」→ 数量 20 → 生成 → 复制。
2. 投喂任意 LLM → 粘贴返回 → 解析 → Step3 见 20 行待入库 → 全选 → `skip` 入库 → 报告成功 20。
3. 维度面板 `top` 展开见新条目；同样文本再跑一次 → 预览全黄 `库内重复` → 入库报告跳过。
