## 1. 输入形态（Step2 粘贴物，按优先级探测）

`detectFragmentFormat(text): 'json' | 'lines' | 'unknown'`（`src/lib/fragmentGenerateParse.ts`，新建）：

1. 去 ```` ``` ```` 围栏 + trim 后以 `{` 开头 → 试 `extractJsonBlock`（平衡大括号+字符串感知，照抄 `translationParse.extractTranslationJsonBlocks`），含 `"contentEn"` 或 `"format":"pmf-fragments"` 即 `json`。
2. 否则按行切分，非空行 ≥1 且每行不含 `{`/`}` → `lines`（纯行 fallback：一行一条英文，可附 `| 中文` 或 ` — 中文` 后缀，见 §2）。
3. 其余 → `unknown`（Step3 空态：`未能识别格式，请确认 LLM 返回了 JSON 或一行一条文本`，附 `[返回 Step1 复制提示词]` 快捷按钮）。

## 2. `pmf-fragments v1`（主格式，定稿）

```json
{
  "format": "pmf-fragments",
  "formatVersion": 1,
  "dimensionKey": "top",
  "count": 20,
  "items": [
    { "contentEn": "slub cotton henley, sand", "displayName": "砂色亨利衫" },
    { "contentEn": "mohair cardigan, lilac", "displayName": "" }
  ]
}
```

- 兼容（解析侧必须全部接受，校验后归一）：
  - 顶层扁平数组 `[{contentEn,…}]`（无外壳）→ `dimensionKey` 取 Dialog 当前维度；
  - 字段别名：`contentEn | content_en | en | text` → 英文；`displayName | display_name | zh | nameCn | name_cn | value` → 中文；`weight | isNsfw` 直通；
  - `format` 缺失但含 `items/contentEn` → 视为本格式（`warnings` 记 `缺失 format 声明，已按 pmf-fragments 解析`）；
  - `count` 与实际条数不一致 → 只警告不拒绝。
- 纯行 fallback 行格式：`英文 [|/—/： 中文]`，如 `slub cotton henley, sand | 砂色亨利衫`；无分隔符则整行作英文、中文空。
- 上限：解析后超过 `GENERATE_MAX_ITEMS=50` 只取前 50 并 `warnings` 注明（与拼接 `count≤50` 对齐；后端 500 上限不受影响）。

## 3. 校验（`validateFragmentBatch(items, dimension, existing)`）

逐条（`contentEn` trim 后）：

| 状态 | 条件 | 预览行为 |
|------|------|----------|
| `ok`（待入库） | 非空、`≤500`（超长截断+`too_long` 警告位）、批内英文大小写不敏感去重首见 | 默认勾选 |
| `duplicate_in_batch` | 批内英文归一（`toLowerCase().trim()` + 连续空白压单）重复 | 不勾选，pill 灰 |
| `duplicate_in_db` | 与 `existing`（当前维度 `modulesByDim`）归一重复 | 不勾选，pill 黄，注「库内已有」 |
| `empty` | 空行 | 不勾选，不计数入库 |
| `too_long`（叠加位） | `contentEn` 或 `displayName` 超 500 已截断 | 保持 `ok` 可勾选，行附 ⚠ |

- 行类型 `ParsedFragmentRow = {index, contentEn, displayName, status, warnings[], selected}`；`selected` 默认 `status==='ok'`。
- 统计 `stats={total, valid, dupBatch, dupDb, empty, tooLong}`，供 Step3 统计条与过滤器。

## 4. 入库调用（复用，不新增）

- `toBatchCreatePayload(rows, dimension, opts)` → `{dimId: dimension.id, items: selectedOk.map({contentEn, displayName: zh||null, weight: opts.weight, isNsfw: opts.isNsfw, notes: 'pmf-generate '+date}), mode: opts.mode, weight, isNsfw}`。
  - `notes` 打标来源（便于将来按来源过滤；`batch.rs` `notes` 上限 500，前缀短可忽略截断）。
  - `displayName` 空 → 传 `null`（后端按 `contentEn` 前 20 字回退，`batch.rs:178`）。
- 调用 `dbBatchCreateModules(payload)`（`src/lib/db.ts:512+`）；`>0` 成功后 `emit(LIBRARY_CHANGED)`（经 `libraryEvents.ts` → `fetchAll`），Dialog 显示报告（`modulesCreated/modulesUpdated/modulesSkipped/duplicate_in_batch/errors/warnings`，与 `batch.rs BatchCreateReport` 同构）。
- 失败（抛错）→ 报告区红字 + Toast，不清空已选；成功 → 报告区绿字 + `[完成并关闭]` 按钮（`data-testid=generate-done-btn`）。

## 5. 与 `batch` 后端语义的对齐（只读约束，不改后端）

- `mode=skip`：库内重复（`find_module_hit` 精确匹配）计 `modulesSkipped`；`mode=overwrite`：覆盖 `content_en/display_name/weight/is_nsfw/notes` 计 `modulesUpdated`。Dialog 默认 `skip`，并在选项旁注「精确英文去重，大小写敏感以后端为准」。
- 后端 `content_en` 去重大小写敏感 vs 前端预览归一大小写不敏感：预览 `duplicate_in_db` 是「预警」（归一），后端是「终局」（精确）——文案必须区分（`可能重复（归一）` vs 报告 `跳过 N（精确命中）`），不得混为一谈。

## 6. 单测要点（`fragmentGenerateParse.test.ts`）

- 含 fence + 前后解释的 JSON 可提；扁平数组可提；别名字段可归一；纯行（含 `|` 中文后缀）可提。
- 批内大小写重复判 `duplicate_in_batch`；库内归一重复判 `duplicate_in_db`；超 500 截断且 `too_long`。
- 超 50 条截断 50 + warnings；`count` 不一致只警告。
- `toBatchCreatePayload` 空中文传 `null`、notes 打标、`mode/weight/isNsfw` 透传。
