# Need03 — 06 数据与接口契约

> **结论先行**：本需求零 DB 迁移、零 Rust 新增。契约只锁定前端 3 模块的 TS 类型、localStorage 键、`invoke` 复用点的参数形态与 `data-testid` 命名，保证「对着写代码的唯一口径」。

---

## 1. 无迁移声明

- `src-tauri/resources/schema.sql` 与 `meta_schema.sql` 不动；不新增表/字段/索引。
- 复用表语义：`modules(content_en NOT NULL, display_name, weight DEFAULT 1.0, is_enabled 1, is_nsfw 0)`；`displayName` 空 → 后端 `contentEn` 前 20 字回退（`batch.rs:178`）。

## 2. 前端新类型（`fragmentGeneratePrompt.ts` / `fragmentGenerateParse.ts`）

```ts
// prompt
export type GenerateBuildInput = {
  dimension: Dimension
  existing: Module[]
  tendency: string
  count: number
  exampleCount: number
  seed: number
  excludeExisting: boolean
}
// parse
export type FragmentRowStatus = 'ok' | 'duplicate_in_batch' | 'duplicate_in_db' | 'empty' | 'error'
export type ParsedFragmentRow = {
  index: number
  contentEn: string
  displayName: string
  status: FragmentRowStatus
  tooLong: boolean
  warnings: string[]
  selected: boolean
}
export type ParsedFragmentBatch = {
  kind: 'json' | 'lines'
  rows: ParsedFragmentRow[]
  stats: { total: number; valid: number; dupBatch: number; dupDb: number; empty: number; tooLong: number }
  warnings: string[]
  errors: string[]
}
export type GenerateImportOptions = { mode: 'skip' | 'overwrite'; weight: number; isNsfw: boolean }
```

- 常量：`GENERATE_MAX_ITEMS=50`，`GENERATE_TENDENCY_MAX_LEN=500`，`GENERATE_EXISTING_LIST_LIMIT=30`，`TRANSLATION` 侧常量不动。
- localStorage：`pmf:generate:tendency/count/exampleCount/excludeExisting/activeStep`（与 `pmf:translate:*` 对称；`seed` 不持久）。

## 3. `invoke` 复用点（只读引用，参数以现有 `db.ts` 为准）

- `dbBatchCreateModules(payload: {dimId, items, mode, weight?, isNsfw?})` → `invoke('db_batch_create_modules', …)`（`src/lib/db.ts:512+`，后端 `batch.rs:267`）。**大小写铁律**：`invoke` 第一个参数 camelCase，payload 键按 `db.ts` 现有封装原样透传；施工前重读 `docs/pitfalls/01-invoke-arg-case.md`，禁止手拼蛇形键。
- `dbGetDimensions()`（采样不需要——`existing` 由父组件 `modulesByDim` 传入；Dialog 内不直查库，刷新走 `LIBRARY_CHANGED` → `useLibraryStore.fetchAll()`）。

## 4. 组件契约（`DimensionGenerateDialog.vue`）

```ts
defineProps<{ open: boolean; dimension: Dimension | null; modules: Module[] }>()
defineEmits<{ (e: 'update:open', v: boolean): void; (e: 'imported'): void }>()
```

- 父（`DimensionPanel.vue`）：`generateTarget: {dim, modules} | null` + `showGenerateDialog`；菜单项 testid `dim-ctx-generate-${key}`；`MENU_H_EST 80→110`。
- Dialog testid 清单：`generate-dialog/close/tendency/count/example-count/reshuffle/exclude/build-btn/copy/download/prompt-preview/result-textarea/result-file-input/parse-btn/validate-btn/stats/filter/row-${i}/row-checkbox-${i}/apply-btn/report/done-btn`（与翻译 `translate-*` 一一对称）。

## 5. 交换格式（`pmf-fragments v1`，冻结）

见 05 §2。冻结规则：`format="pmf-fragments", formatVersion=1`；解析器向前兼容（未知字段忽略、别名字段归一）；模板 (§04) 与解析 (§05) 的字段名以本节 §2 类型为准，冲突时以本文件为准。

## 6. 决策记录

- 复制回退照抄 `segmentPrompt.copyInstructionPrompt`（`clipboard.writeText` + `textarea+execCommand`），不新建 `lib/clipboard.ts`（避免顺手重构扩大 blast radius）。
- 预览分页 50/页（与 `ModuleBatchDialog.pageSize=50` 一致，不与翻译 Step3 的 20 混用——翻译是按 id 行，生成是按条行，50 更合适）。
