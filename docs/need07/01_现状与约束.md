# 01 现状与约束：两异常复现 + 5 处同类隐患

## 1. 当前链路（实测代码位置）

- 数据目录：`migration.rs:90 data_dir_for` = `current_exe().parent()/data`（注释明示不用 `executable_dir()`，因 Tauri v2 Windows 报 `Not supported`）。
- 业务库归一：`business.rs:27 normalize_business_path` → 存在则 `abs.canonicalize()`（§55-57），不存在则父目录 `canonicalize`（§62）。
- 导出归一：`export.rs:34 normalize_export_dir` 同构（§58-63）。
- 生图输出归一：`queue.rs:401 normalize_image_dir_for`（`""→{data}/output/images`，相对拼 `data_dir`，绝对直用；注意它**只做 lexical，不 canonicalize**）。
- 打开目录：`export.rs:191 db_reveal_in_explorer` 手调 `explorer`；前端 `ImageQueuePanel.vue:45-48 onOpenOutput`、`LibraryDialog.vue:117 onOpenDir`、`DbManagerDrawer.vue:97,108` 直接展示 `row.path`。
- 注册表：`meta_schema.sql: db_registry(path UNIQUE COLLATE NOCASE)` + `app_settings(foreground_path)`；`meta.rs:342 db_get_active_info` 直返 `path` 字符串。

## 2. 异常1复现：`\\?\D:\Program Files\...\luoli.db`

1. 用户在 `Program Files\Prompt Modular Factory\data\luoli.db` 建库/切库 → `normalize_business_path` 走 `abs.exists()==true` 分支 → `canonicalize()`。
2. Windows 下 `canonicalize` 语义 = 返回 verbatim 路径 `\\?\D:\...`（绕过 MAX_PATH、固定大小写），存入 `db_registry.path` + `foreground_path`。
3. `DbManagerDrawer` 原样展示 → 用户看到 `\\?\D:\...`。
4. 附带伤害：`business.rs:651 wasForeground` 用 `to_ascii_lowercase()` 直比，`\\?\` 与普通路径比较永远不等 → 前台判定抖动；`NOCASE UNIQUE` 对 `\\?\` vs 普通路径视为**不同行** → 同一文件可重复注册。

## 3. 异常2复现：默认输出只开 `Documents`

1. `iq.config.outputDir == ""`（默认，未配置）→ `ImageQueuePanel.vue:46` 取占位 `'<data_dir>/output/images'` → `dbRevealInExplorer("<data_dir>/output/images>")`。
2. 后端 `db_reveal_in_explorer` 无归一：`PathBuf::from("<data_dir>/output/images")` 为相对路径、`exists()==false`，直接 `Command::new("explorer").arg(相对路径)`。
3. Explorer 对非法/相对参数的兜底 = 打开 `Documents` 库。于是"配了绝对路径能开、空就开错"。
4. 深层缺失：打开链路没复用 `normalize_image_dir_for`（后者懂 `""→{data}/output/images`），也没 `create_dir_all` 保活。

## 5. 环境硬约束（Windows 特有，测试必须覆盖）

1. `Program Files` 默认非管理员**不可写**；`current_exe()/data` 在此场景必然 `create_dir_all` 失败。
2. `Documents` 可能被 OneDrive 重定向（含空格/中文/超长），`document_dir()` 可能为 `None`（域策略）→ 必须有二级回退。
3. `MAX_PATH 260`：`Program Files + 中文别名 + 时间戳文件名` 易超长，存储用普通路径、打开用脱壳路径、必要时保留 `\\?\` 只给 Win32 直调（本次仅日志/水位用）。
4. Tauri `app.path().executable_dir()` Windows 不可用（已证），`app_data_dir/document_dir` 可用但单元测试无 `AppHandle` → 中枢必须拆**纯函数（可测）+ 薄适配层（需 AppHandle）**。
