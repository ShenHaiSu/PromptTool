# 02 路径规范与数据目录设计（方案B核心决策）

## 1. 设计目标

- 老用户：升级后库不丢、前台不错乱、输出目录不搬家、展示变干净（无感）。
- 新用户（`Program Files` 非管理员首装）：首启可用，不再弹"请用管理员运行"。
- 全平台：同一套"存储/展示/比较"规则，Windows/macOS/Linux 行为一致。

## 2. 数据目录决策：双 base + 可写探测回退（不硬迁）

保留 `exe/data` 为**便携主目录**（老用户资产全在那，硬迁风险最大），新增**系统回退目录**：

```
resolve_data_dir(app):
  1. exe_dir/data（data_dir_for 现逻辑）
     → 尝试 create_dir_all + 写探针 .pmf_write_probe.tmp
     → 成功：用它（覆盖 95% 老用户 + 开发期 target/debug）
  2. 失败（Program Files 非管理员 / 只读介质）：
     → app.path().app_data_dir()/PMF（Windows %APPDATA%/com.pmf.tauri-app）
     → create + 探针，成功则用它，并在 setup 日志 + 探针命令中标明 activeBase
  3. 若旧 %APPDATA%/pmf.db 存在且新位置无 Default.db：复用既有 migrate_legacy_db（backup API）搬一次
```

- `Default.db` 永远跟随 `active data_dir`；`AppState.default_db` 存解析后的绝对路径（脱壳）。
- 新增 `path_get_bases` 把 `exeDir/dataDir/activeBase/writable` 暴露给前端探针（验收用）。

为什么不用"一刀切迁 AppData"：老用户 `exe/data` 下已有 `Default.db + N 个业务库 + output/images`，整目录搬迁的中断窗口和失败面远大于回退方案；回退方案只有**写不动的新环境**才走新路径，天然无感。

## 3. 存储 / 展示 / 比较三规则（全仓统一）

| 维度 | 规则 | 说明 |
|---|---|---|
| 存储（入库/落盘/配置） | 普通绝对路径，无 `\\?\` 前缀，Windows 盘符大写（`D:\...`），分隔符 `\` | `canonicalize` 后必过 `strip_verbatim`；相对输入先拼 base 再 lexical |
| 展示（前端/日志/报错） | `display_path = strip_verbatim + to_string_lossy` | `\\?\UNC\server\share → \\server\share` 特殊处理；日志一律用它 |
| 比较（前台判定/去重） | `norm_key = strip_verbatim → to_lowercase（Windows）/ 原样（Unix）→ 统一 / 为分隔` | 替换 `business.rs:651` 的裸 `to_ascii_lowercase` 直比；注册表查重用它预查 |

`strip_verbatim` 规则（手写，零依赖）：

```
"\\?\UNC\server\share\a" → "\\server\share\a"
"\\?\D:\a"              → "D:\a"
"\\?\GLOBALROOT\..."    → 原样（罕见，不动）
其他                     → 原样
```

## 4. 目录总表（新默认值 + 老值保留策略）

| 用途 | 新默认值（空配置/新安装） | 老值处理 |
|---|---|---|
| `Default.db` | `active data_dir/Default.db` | 原地；只洗 `\\?\`（`04`） |
| 业务库（相对输入） | 相对 `active data_dir`（strip `data/` 前缀兼容保留） | 已存绝对路径只洗前缀，不搬文件 |
| 生图输出 | `Documents/Prompt Modular Factory/images`（`document_dir()` 有）；`None` 则回退 `active data_dir/output/images` | 若 `outputDir==""` 但老默认 `data/output/images` **存在文件** → 继续用老默认，并在设置页 hint"旧默认位置（已保留）"；仅当老默认不存在/为空才用新默认 |
| 词库导出 | `Documents/Prompt Modular Factory/exports`，回退 `active data_dir/output` | 同上：`exportDir` 为空且老 `data/output` 有文件 → 保留老默认 |
| 缩略图/缓存/tmp | `active data_dir` 下不动（避免 Documents 污染） | 不动 |

OneDrive/中文/空格：新默认路径一律走 `create_dir_all + 探针`，`reveal` 前保活；`document_dir()==None` 时走回退分支并在探针中标明。

## 5. 非目标（本次不做）

- 不改 `.db` 表结构（只加 `app_settings` 版本键，不动 `db_registry` 列）。
- 不搬运用户图片/业务库文件本体（只洗路径字符串 + 改默认解析）。
- 不引入 `dirs/directories` 等新 crate。
