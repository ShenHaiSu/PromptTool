## 4. 全局硬约束（本系列 Code Review 必查）

1. 入库/返给前端的路径**永不含 `\\?\` 前缀**（`\\?\UNC\` 一并处理）；
2. 打开目录前**保证目录存在**（`create_dir_all`），不存在不直接丢给 `explorer`；
3. `explorer /select` 必须拆成**两个参数**（动词与路径分离），禁止拼成一个字符串；
4. 老用户默认输出目录有文件时**不搬迁**，只洗前缀；新默认值只用于新安装/空配置；
5. 迁移前必备份 `Default.db`（`.bak-<ts>`），迁移幂等可重入，失败回滚不断服。
