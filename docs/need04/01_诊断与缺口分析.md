## 1. 需求复述

> 1. **删除常驻预览顶栏**：将 `TopBar` 的 88/168px 预览条收纳为维度面板上方的一个按钮，点击拉起 Dialog，在 Dialog 内完成 IR 审阅、提示词全文预览与导出；
> 2. **删除拼装画布、增强维度面板**：`AssemblyCanvas` 功能弱却占据中区黄金位，删除该模块；将能力增强并入 `DimensionPanel`，支持双模切换——**浏览模式**（现状：展示筛选后的可选项，已选项高亮）与**已选模式**（无视维度分组，已选词条作一级 Card 平铺；小字标注所属维度；浅底色按维度区分）；
> 3. **黄金位重排**：正中黄金位交给 `BatchFactory` 独占；右侧整栏交给 `HistoryPanel` 的历史/收藏/模板。

约束：纯前端交互重排，不改 Rust 后端、不改 `data/pmf.db` schema、不改随机/历史引擎与导出列定义。

## 2. 现有布局盘点

### 2.1 顶层 `src/App.vue`

```
TopBar :prompt="assembly.finalPrompt" :warnings="assembly.warnings" :ir="assembly.ir"
div[data-testid="main-layout"] flex min-h-0 flex-1
  section[data-testid="panel-left"]   width: leftPct   (leftFrac 0.30)
    header h-9 "维度面板 / Tree + 搜索 + NSFW"
    DimensionPanel
  div[data-testid="sash-left"]  拖拽 leftFrac/centerFrac
  section[data-testid="panel-center"] width: centerPct (centerFrac 0.38)
    AssemblyCanvas
  div[data-testid="sash-right"] 拖拽 centerFrac
  section[data-testid="panel-right"] flex-1  (right = 1 - left - center ≈ 0.32)
    BatchFactory (border-b + h-[400px] 虚拟化)
    HistoryPanel (border-t + flex-1)
StatusBar  dimCount/moduleCount/已选/历史/收藏/model + 词库/分段/数据库/主题
BusinessDbOnboardingDialog / DbManagerDrawer / LibraryDialog / SegmentImportDialog / toasts
```

- `useSash`：`leftFrac/centerFrac` 双分数，`load()` 读 `localStorage pmf:sash`，`setFracs` 约束每栏 `12%~65%` 且 `left+center<0.92`，`watch` 持久化；`App.vue:133-172` 另有 `pointermove/pointerup` 的 sash 拖拽与 `contain: layout paint`。
- `usePersist::persistGeometry()` 在 `App.vue:176` 挂载时调用，`beforeunload` 存 `pmf:geometry`；主题 `useThemeStore` 独立持久化 `pmf:theme`。
- 启动链路 `App.vue:174-226`：`persistGeometry` → 监听 `LIBRARY_CHANGED` → `dbRegistry.fetchActiveInfo/fetchList` → onboarding 分支 → `dbGetDimensions/dbGetAllModulesGrouped` → `library.fetchAll` → `dbGetTempCarry` 回填画布 → `history.fetchAll`。

**判定：** 布局为典型的"顶栏 + 三栏 + 底栏"，`TopBar` 常驻 88px（折叠）/168px（展开）占据首屏纵向黄金；中区 `AssemblyCanvas` 虽为拼装核心但仅做 chips 流式展示，纵向利用率低；右栏 `BatchFactory(h-[400px] 固定) + HistoryPanel(flex-1)` 互相挤压，两者均需独立滚动。

## 3. 约束与复用

- **不改后端：** Rust `src-tauri` 与 `data/pmf.db` 保持；预览导出仍走前端 `exportSingleCsv`，批量 CSV 仍走 `exportBatchCsv`。
- **状态同源：** `assembly.selectedItems/config/ir/finalPrompt` 为唯一真相源，维度面板双模与预览 Dialog 均为其视图；不引入新 store。
- **色板同源：** `DIM_COLORS` 为唯一维色来源，浅底色以其 `hex + alpha` 派生，不新增硬编码色值。
- **持久化同源：** `pmf:sash` 复用，`pmf:dimPanelMode` 新增（`browse|selected`），`pmf:geometry/pmf:theme` 不动。
- **无障碍与测试同源：** `data-testid` 体系保持，新增 `preview-trigger/preview-dialog/*` 与 `dim-mode-*` 前缀；`Tauri v2 invoke` 键名约束 `pitfalls/01-invoke-arg-case.md` 本次不涉及。
