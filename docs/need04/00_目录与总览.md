## 1. 背景与诉求

本次为纯前端交互重排，不改 Rust 后端、不改 `data/pmf.db` schema、不改批量随机与历史均匀引擎。

| 诉求 | 一句话 |
|------|--------|
| 1. 预览顶栏收纳 | 删除 `TopBar` 常驻的 88/168px 预览条，收纳为维度面板上方的一个按钮，点击拉起 Dialog 完成 IR 审阅 + 全文预览 + 导出 |
| 2. 画布下线、维度面板增强 | 删除占据中区黄金位的 `AssemblyCanvas`，将其能力增强并入 `DimensionPanel`；维度面板支持双模切换：**浏览模式**（现状筛选+已选高亮）与 **已选模式**（无视维度分组、已选项作一级 Card 平铺，浅底色按维度区分、小字标注维度） |
| 3. 黄金位重排 | 正中黄金位交给 `BatchFactory`；右侧整栏交给 `HistoryPanel` 的历史/收藏/模板三 Tab |

等价表述：从 `TopBar(预览) + 左Dim + 中Canvas + 右(Batch+History)` 的三栏一顶，改为 `左Dim(双模+预览入口) + 中Batch + 右History` 的两栏一悬浮预览。

## 4. 核心设计决策摘要

| 决策 | 选择 | 原因 |
|------|------|------|
| 预览载体 | 新建 `PromptPreviewDialog.vue`，按钮置于维度面板标题栏右侧 | 顶栏 88px 常驻对画布/批量均是浪费；按钮就近维度面板符合"选词 → 预览"心智；Dialog 复用 `TopBar` 已有 IR/复制/导出逻辑，改动面最小 |
| 画布下线策略 | 删除 `AssemblyCanvas.vue` 文件，能力平移至 `DimensionPanel` 的已选模式 | 画布仅做 chips 流式+权重/锁定/拖拽/设置/保存，与维度面板的"已选高亮"语义重叠；合并不引入新 store，复用 `assembly.selectedItems` |
| 双模切换控件 | 维度面板工具行下的 SegmentedControl：`浏览` / `已选 N`（N=已选数） | 比独立 Tab 更省高度；与维度面板的搜索/NSFW 同处工具区，视线不跳；`N` 徽标提供已选规模的常驻反馈 |
| 已选卡片视觉 | 浅底色 `dimColor(key) + 8% 透明度`（light）/ `16%`（dark），左 3px 色条 + 右小字维度标签 | 满足"浅背景区分维度 + 小字标注维度"诉求；色板复用 `src/lib/utils.ts:DIM_COLORS`，不新增色值；深色模式用更高透明度保证可辨 |
| 中区归属 | `BatchFactory` 独占中区，移除其 `border-b` 与 `h-[400px]` 固定高度，改为 `flex-1` 自适应 | 黄金位此前被弱画布占据是最大浪费；批量虚拟化列表在更高容器内可展示更多条，减少滚动 |
| 右栏归属 | `HistoryPanel` 独占右栏，移除其外层 `border-t`，高度由 `flex-1` 接管 | 右栏此前与批量挤压导致两者均需滚动；独占后历史/收藏/模板的列表高度翻倍 |
| Sash 默认值 | `left 0.28, center 0.42, right 0.30` | 左栏略收窄（维度面板双模后信息密度更高）、中区放大至黄金位、右栏与左栏对称；仍满足 `12%~65%` 与 `left+center<0.92` 约束 |

## 6. 非目标与后续

**首版不做：**
- 不改 `TopBar.vue` 以外的主题/Token 体系（`assets/tokens.css` 仅追加必要的浅底色变量，可选）
- 不新增后端命令、不改 `export.ts` 的 CSV 列定义
- 不做可视化拖拽跨面板（如从维度面板拖入批量卡片）
- 不做画布的"撤销/重做"栈（可后置为 `assembly` 的历史栈）

**后续可选增强：**
- 已选模式的按维度分组折叠（在平铺与分组间再加一档）
- 预览 Dialog 内的"按维度着色"的 Prompt 高亮（与浅底色同色系）
- 维度面板的虚拟化（维度 >50 或词条 >2000 时）
- 黄金位的可切换（批量 ↔ 历史的左右互换记忆）
