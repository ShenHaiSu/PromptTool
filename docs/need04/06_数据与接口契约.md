# Need04-06 — 数据与接口契约

## 一、TS 契约（增量，无破坏）

### 1.1 `src/engine/models.ts`：不动

```ts
export interface Dimension {
  id: string; key: string; nameCn: string; nameEn: string;
  sortOrder: number; isMultiSelect: boolean; isEnabled: boolean;
  icon?: string | null; createdAt?: number; updatedAt?: number; isDeleted?: boolean;
}
```

`sortOrder` 语义重申：数字越小越靠前；新建默认 `max+1`（`db.dimensions.ts:117-141`）；允许手工调整为任意整数（含 `0` 与负数，排序只比大小）。

### 1.2 `src/engine/assembly.ts`：新增 1 个导出函数，0 个破坏性签名变更

```ts
export function buildDimOrderMap(dims: Dimension[]): Record<string, number>
export function sortByOrder(items: SelectedItem[], mode: string, dimOrderMap?: Record<string, number>): SelectedItem[]
export function assemble(selected: SelectedItem[], config: AssemblyConfig, rules?: EngineRule[], dimOrderMap?: Record<string, number>): { ir: PromptIR; finalPrompt: string }
```

调用约定：生产代码必须传 `dimOrderMap`（`random` 现算、`assembly` 自取）；单测/脚本可省略（回退 `DIM_ORDER`）。

### 1.3 `src/stores/library.ts`：新增 1 个派生状态

```ts
const dimOrderMap = computed<Record<string, number>>(() =>
  Object.fromEntries(dimensions.value.map((d) => [d.key, d.sortOrder])),
)
// return 中新增 dimOrderMap（key 形如 { top: 6, bottom: 7, my_style: 0 }）
```

### 1.4 `src/stores/assembly.ts` / `batch.ts`：签名不变

`reassemble()`、`setSelected` 等保持零参/原参；`batch.generate/generatePartial` 保持 `(dimensions, modulesByDim, lockedIds/anchored, count, config, allowNsfw)`。

## 二、DB 契约（无迁移）

- `dimensions.sortOrder`：`DimRow.sortOrder: number`（`db.rows.ts:8`），`dbGetDimensions` 升序返回（`db.dimensions.ts:12`）。
- 新建：`resolvedSort = sortOrder ?? max+1`（`db.dimensions.ts:141`）；导入：缺省 `nextSort++`（`db.library.ts:159-178`）。
- `seed-data.ts:35-48` 14 维 `1..14` 为初始值；`seed.ts` 幂等，非空不重写。
- 本需求不新增表、不新增列、不写 `migration`。

## 三、排序契约（一句话）

`finalPrompt` 与 `ir.segments` 顺序恒等（`assemble` 先 `ordered` 再 `new PromptIR(ordered…)`，`assembly.ts:43-56`）；`sortBy='dimensionOrder'` 时顺序 `= ORDER BY sortOrder ASC`（未知键沉底）；`sortBy='customDragOrder'` 时顺序 `= 输入序`。
