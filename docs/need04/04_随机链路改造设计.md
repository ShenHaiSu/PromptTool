## 四、性能

`buildDimOrderMap` 为 `O(D)`（`D` = 维度数，十级），每条候选 IR 建一次；`count ≤ 500` 时最多 `500 × MAX_ATTEMPTS_FACTOR` 次，可提到循环外建一次（推荐）：

```ts
const dimOrderMap = buildDimOrderMap(dimensions) // 移到 while 之前
```

文档示例为最小 diff 写在循环内，施工时请提到循环外。本质无性能风险。
