## 5. 风险与回退

| 风险 | 缓解 |
|------|------|
| 已选卡片浅底色在低对比度显示器下区分度不足 | `dark` 用 16% alpha 提升对比；色条 `border-l-4` 不透明兜底；必要时在卡片右上角增加维度 `Badge` |
| `dimensionOrder` 下拖拽与 IR 顺序不一致导致困惑 | 保留手柄但 toast 提示"当前为维度顺序，拖拽将在自定义拖拽后生效"；或在该模式下禁用拖拽并 tooltip 说明 |
| Preview Dialog 在 720p 下纵向溢出 | `max-h-[min(78vh,720px)]` + 内区分区 `max-h-[28vh]/[22vh]` + `overflow-auto`，小屏可滚动 |
| 旧用户 `pmf:sash=[0.30,0.38]` 与新默认值 `[0.28,0.42]` 的冲突 | `load()` 优先读存储，仅新用户或清空存储后生效新默认值；已持久化用户不受影响 |
| `TopBar.vue/AssemblyCanvas.vue` 删除后存量 import 残留导致编译失败 | `App.vue` 与测试的 import 同步清理；`grep -r "TopBar\|AssemblyCanvas"` 全量检查 |
| 画布单测删除导致覆盖率下降 | 关键用例已迁入 `DimensionPanel.selected.test.ts` 与 `PromptPreviewDialog.test.ts`，覆盖权重/锁定/拖拽/设置等 |

**回退：** 本需求仅改前端 5~6 个文件与 1 个 composable 默认值，不改 Rust 与 DB；回退时恢复 `App.vue` 的 `TopBar/AssemblyCanvas` 挂载、`useSash` 默认值 `[0.30,0.38]`、`DimensionPanel` 的单模形态与 `BatchFactory/HistoryPanel` 的固定高度即可，`pmf:dimPanelMode` 单 key 可直接 `localStorage.removeItem` 清理。
