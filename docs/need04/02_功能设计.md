## 1. 设计目标与非目标

**目标：**

- 删除 `TopBar` 常驻预览条，收纳为维度面板标题栏右侧的"预览"按钮，点击拉起 Dialog 完成 IR 审阅、全文预览、复制与导出；
- 删除 `AssemblyCanvas` 中区模块，将权重/锁定/拖拽/清空/设置/保存等能力并入 `DimensionPanel` 的已选模式；
- `DimensionPanel` 支持双模切换：**浏览模式**（现状筛选+已选高亮，默认）与**已选模式**（无视维度分组，已选作一级 Card 平铺，浅底色按维度区分，小字标注维度）；
- 正中黄金位交由 `BatchFactory` 独占，右侧整栏交由 `HistoryPanel` 的历史/收藏/模板独占，提升两者可视高度与滚动体验。

**非目标：**

- 不改 Rust 后端、不改 `data/pmf.db` schema、不改 `export.ts` 的 CSV 列定义与批量随机引擎；
- 不引入新的拖拽跨面板（如从维度面板拖入批量卡片）；
- 不做画布的撤销/重做栈（可后置为 `assembly` 的历史栈）；
- 首版不做维度面板虚拟化（维度 >50 时可后置）。

## 3. 维度面板双模（核心）

### 3.1 标题栏与预览入口

**位置：** `panel-left` 的 `h-9` 标题栏内，右侧新增预览按钮（与原"Tree + 搜索 + NSFW"副标题并列或替换其右侧）。

**按钮：**

- `data-testid="preview-trigger"`
- 文案：`👁 预览 · N`（`N = assembly.selectedItems.length`），`N=0` 时文案 `👁 预览` 且按钮 `variant="ghost"` 弱化；`N>0` 时 `variant="outline"` 或 `secondary` 强调。
- 徽标：已选数 `N` 以 `Badge` 或按钮内小圆点呈现，`N>0` 时可见。
- 行为：点击 `previewOpen = true` 拉起 `PromptPreviewDialog`；`N=0` 时仍可打开（展示空态与引导）。
- 辅助：`title="审阅 IR、分段与冲突，复制/导出当前 Prompt"`。

**标题栏布局（左 → 右）：**

```
[维度面板] [Tree + 搜索 + NSFW 副标题 — 可在窄宽度下隐藏]  [👁 预览 · N]
```

窄宽度（<320px）时副标题自动隐藏（`hidden lg:inline`），仅保留标题与预览按钮。

### 3.2 工具行（两态共用）

**位置：** 标题栏下方，`border-b px-3 py-2` 容器内，纵向 `gap-2`。

- **搜索：** `Input[data-testid="dimension-search"]` 占满宽，`placeholder="搜索 维度/条目…"`，`v-model="keyword"`，`h-8`。
- **第二行：** `维度 {{ filteredDimensions.length }} / {{ dimensions.length }}`（浏览模式）或 `已选 {{ selectedItems.length }}`（已选模式）+ 右侧 `+ 新建维度` + `NSFW 开/关 · count`。
  - 浏览模式：显示维度计数；
  - 已选模式：显示已选计数，且 `NSFW` 按钮可弱化或隐藏（已选不受 NSFW 过滤影响，已选项无论 NSFW 均展示）。

**注意：** 搜索框在两模式下均保留；已选模式下搜索用于过滤已选卡片（按 `displayName/contentEn/dimensionKey`），而非过滤维度。

### 3.3 模式切换 SegmentedControl

**位置：** 工具行下方，`px-2 py-1.5 border-b` 或 `px-3` 容器内。

- **控件：** 双按钮等分，`data-testid="dim-mode-browse"` / `data-testid="dim-mode-selected"`。
- **文案：**
  - 浏览：`浏览`（或 `浏览 · M`，M=过滤后维度数，可选）
  - 已选：`已选 · N`（N=已选数，必显）
- **状态：** 当前模式 `variant="default"`（实底），另一 `variant="ghost"`；或用 `bg-accent` 选中态。
- **持久化：** 切换即 `localStorage.setItem('pmf:dimPanelMode', mode)`，初始化 `localStorage.getItem('pmf:dimPanelMode') ?? 'browse'`。
- **空态引导：** 已选模式且 `N=0` 时，切换按钮旁可出现轻提示"暂无已选 — 去浏览模式添加"。

### 3.4 浏览模式（Mode A — 默认）

**定义：** 现状 `DimensionPanel` 的 Tree 形态，保持不变，仅做两处微调：

1. **已选高亮保持：** `isSelected(m.id)` 时 `module-row` 加 `bg-primary/10` 与 `Badge 已选`，与现状一致。
2. **交互保持：** 单击/双击 `onAdd`（单选维度互斥替换）、`+ / 批量 / ✎` 维度操作、`✎ / ✕` 词条操作、折叠 `expandedKeys`、关键词与 NSFW 过滤，均不变。

**列表容器：** `ScrollArea flex-1`，`p-2 space-y-1`，空态 `dimension-empty` 与 `loading` 保持。

**数据：** `filteredDimensions / filteredModules(dimId)` 逻辑不变。

### 3.5 已选模式（Mode B — 新增）

**定义：** 无视维度分组，将 `assembly.selectedItems` 作一级 Card 平铺；每卡标注所属维度（小字），浅底色按维度区分。

#### 3.5.1 顶部操作行

已选模式的列表上方（`ScrollArea` 之前或之内顶部）增加操作行：

```
[已选 N 项]  [… 设置]  [清空已选]
```

- `N` 为 `assembly.selectedItems.length`；
- `… 设置` 复用画布的设置弹层（`assembly-settings-panel` 内 `setting-separator/setting-brackets/setting-sortBy`），点击 `showSettings=!showSettings` 弹出 `w-64` 弹层；
- `清空已选`：`data-testid="selected-clear-btn"`，`variant="ghost"`，`N=0` 时 `disabled`；点击二次确认（`window.confirm("清空全部已选？")`）后 `assembly.clear()`。
- 另：`复制 Prompt` 可作为第三按钮（或收纳进预览 Dialog，本设计建议保留在已选模式顶部，便于不打开 Dialog 即可复制）。

#### 3.5.2 卡片流

- **容器：** `VueDraggable v-model="draggableItems"`（`draggableItems` computed 绑定 `assembly.selectedItems`，`set` 时 `assembly.setSelected`），外层 `flex flex-col gap-2 p-2` 或 `flex flex-wrap gap-2`（本设计推荐纵向 `flex-col`，每卡独占一行，便于展示维度标注与操作）。
- **拖拽：** `handle=".drag-handle"`，`animation 150 / ghost opacity-40 / chosen ring-1 ring-primary`，与画布一致；`@end="onDragEnd"`（空实现，v-model 已同步）。
- **排序语义：** `assembly.config.sortBy === 'customDragOrder'` 时拖拽顺序即 IR 顺序；`dimensionOrder` 时拖拽仅改变展示顺序的提示（或禁用拖拽，本设计建议保留拖拽但提示"当前为维度顺序，拖拽将在切换为自定义拖拽后生效"）。

#### 3.5.3 单卡设计 `SelectedPromptCard`

每卡 `data-testid="selected-card"` + `data-module-id`，结构：

```
┌─────────────────────────────────────────────────────┐
│ ⋮⋮  ●  词条显示名                    w1.2  🔒/🔓  ✕ │
│      小字维度标签  top / 上装  · 权重/NSFW 提示      │
└─────────────────────────────────────────────────────┘
```

- **外层：** `rounded-md border px-3 py-2.5 shadow-sm hover:shadow`，背景为浅维色（见 §6），左 3px 色条 `border-l-4` 或 `before` 伪元素，色值为 `dimColor(dimensionKey)`。
- **第一行：**
  - `drag-handle`：`⋮⋮`，`cursor-grab text-muted-foreground hover:text-foreground`；
  - 色点：`h-2 w-2 rounded-full`，`background: dimColor(key)`，`title=dimensionKey`；
  - 名称：`truncate font-medium text-sm`，`title=contentEn`；
  - 权重 pill：`data-testid="selected-weight-btn"`，`rounded bg-muted px-1.5 py-0.5 font-mono text-[11px]`，点击 `openWeightPopover(moduleId, current)` 弹出 `chip-weight-popover`（复用画布的 slider+input+confirm/cancel）；
  - 锁定：`data-testid="selected-lock-btn"`，`🔒/🔓`；
  - 移除：`data-testid="selected-remove-btn"`，`✕`；
- **第二行（小字标注）：**
  - `text-xs text-muted-foreground`，`维度名Cn / key`（如 `上装 / top`），若 `dimensionKey` 为空则显示 `未分类`；
  - 可选：`w1.2` 权重提示、NSFW 点 `bg-red-500`；
- **浅底色：** `background: dimColor(key) + alpha`，light `08`（8%）、dark `16%`（或 `0.08/0.16` rgba），`border-color` 为同色更深一级或 `border-border`。

**权重 Popover：** 复用 `AssemblyCanvas` 的 `chip-weight-popover`（`weight-slider/weight-input/weight-cancel/weight-confirm`），`activeWeightId/draftWeight` 本地态，确认后 `assembly.updateWeight(id, v===1?null:v)`，取消仅关弹层。

#### 3.5.4 已选模式的搜索过滤

- 关键词 `keyword` 复用：过滤已选卡片，匹配 `displayName/contentEn/dimensionKey/nameCn`；
- `filteredSelected = selectedItems.filter(m => kw 命中)`；
- NSFW 开关在已选模式下不生效（已选项无论 NSFW 均展示，符合"已选即所见"）。

#### 3.5.5 已选模式的空态

```
┌───────────────────────────────┐
│           ◈                 │
│        暂无已选               │
│  去浏览模式双击添加词条       │
│  或试试批量工厂的随机生成     │
└───────────────────────────────┘
```

`data-testid="selected-empty"`，与画布 `assembly-empty` 文案同源但收敛为维度面板内。

## 4. 预览 Dialog

### 4.1 触发与关闭

- **触发：** 维度面板标题栏 `preview-trigger` 点击 → `previewOpen=true`。
- **关闭：** 遮罩点击（`@click.self`）、`Esc`、右上角 `✕`、底部"关闭"按钮。
- **层级：** `fixed inset-0 z-50 bg-black/40` 遮罩 + 居中 `Card w-[min(720px,92vw)] max-h-[min(78vh,720px)] flex flex-col`。
- **焦点：** 打开时聚焦 Dialog 内首个可交互元素；`Esc` 关闭。

### 4.2 内容分区

Dialog 内纵向三区（`flex flex-col min-h-0`）：

#### A. 标题行

```
[👁 预览 · N 已选]          [复制] [导出] [✕]
```

- 左：标题 + 已选计数 `Badge`；
- 右：`复制`（`data-testid="preview-copy-btn"`）、`导出`（`data-testid="preview-export-btn"`）、关闭 `✕`；
- 复制/导出在 `isEmpty`（`!finalPrompt`）时 `disabled` 并 `title="暂无可复制/导出内容"`。

#### B. Prompt 全文预览

- **容器：** `rounded-md border bg-muted/30 p-3 max-h-[28vh] overflow-auto`
- **空态：** `data-testid="preview-empty"`，`暂无拼装 — 从左侧添加词条后此处实时预览`，`text-muted-foreground`；
- **有值：** `data-testid="preview-prompt"`，`font-mono text-sm whitespace-pre-wrap break-words`，`title=prompt`，支持 `展开/折叠`（可选，长文 >400 字时默认折叠为 4 行，按钮 `data-testid="preview-expand-btn"`）。
- **计数：** 右下角 `{{ prompt.length }} 字符 · {{ ir.segments.length }} 段`（可选）。

#### C. IR 审阅区

- **标题行：** `PromptIR — 中间表示` + `显示/隐藏 IR` 切换（`data-testid="preview-ir-toggle"`，`showIr` 本地态）；
- **IR JSON：** `data-testid="preview-ir-json"`，`pre font-mono text-xs bg-muted p-2 rounded overflow-auto max-h-[22vh]`，内容 `JSON.stringify({segments,warnings}, null, 2)`；
- **Warnings：**
  - 有警告：`data-testid="preview-warnings"`，`bg-amber-50 dark:bg-amber-950 p-2 rounded`，`ul list-disc` 逐条展示；
  - 无警告：`text-xs text-muted-foreground`，`无警告 · IR 已就绪`；
  - 折叠态（`showIr=false`）：仅展示 `warnings.join('；')` 的单行 `truncate`（`data-testid="preview-warnings-collapsed"`）。
- **Segments 列表（可选增强）：** 在 JSON 之外，以 `Badge` 流展示各 `segment.dimensionKey:text:weight`，色点 `dimColor`，便于视觉审阅（可选，首版可仅 JSON）。

### 4.3 复制与导出行为

- **复制：** `onCopy` 复用 `TopBar` 的 `navigator.clipboard.writeText(prompt)` + textarea fallback + `push('已复制到剪贴板', 'success')`；空 prompt 时 `push('暂无可复制的 Prompt', 'warning')`。
- **导出：** `onExport` 复用 `exportSingleCsv(ir, prompt)`；无 IR 时构造 `fakeIr`（单段 `text=prompt`）兜底；成功 `push('已导出 CSV', 'success')`；空 prompt 时 `warning`。
- **IR 复制（可选）：** 在 IR JSON 右上角提供"复制 IR"按钮，复制 `irJson` 文本。

## 7. 视觉与样式

### 7.1 色板与浅底色

- **维色：** 复用 `src/lib/utils.ts:DIM_COLORS` 14 维，不新增硬编码；
- **浅底色：** `dimColor(key)` 的 `hex` 加 alpha：
  - Light：`08`（`#RRGGBB14`，约 8%）或 `rgba(hex, 0.08)`；
  - Dark：`28`（约 16%）或 `rgba(hex, 0.16)`；
  - 实现：前端 `hexToRgba(dimColor(key), isDark?0.16:0.08)` 或 Tailwind `bg-[...]` arbitrary；
- **左色条：** `border-l-4` 或 `w-1 rounded-full`，`background: dimColor(key)`，不透明；
- **小字维度标签：** `text-xs text-muted-foreground`，`font-mono` 或 `font-normal`，`key` 部分 `opacity-70`。

### 7.2 排版与间距

- 标题栏 `h-9 px-3`、工具行 `px-3 py-2 gap-2`、模式切换 `px-2 py-1.5`、列表 `p-2 gap-1/2`，与现状一致；
- 已选卡片 `px-3 py-2.5 gap-1.5`，卡间距 `gap-2`；
- Dialog `p-4 gap-3`，Prompt 区 `p-3`，IR 区 `p-2`。

### 7.3 深色模式

- 浅底色在 `dark` 下用更高 alpha（16%）保证可辨；
- 文字 `text-foreground / text-muted-foreground` 保持；
- 弹层 `bg-popover border shadow-xl` 保持。

## 8. 状态与数据流

```
assembly.selectedItems/config/ir/finalPrompt (Pinia, 唯一真相源)
  ├─ DimensionPanel 浏览模式: isSelected 高亮 + onAdd
  ├─ DimensionPanel 已选模式:  SelectedPromptCard 流 + 权重/锁定/移除/拖拽/清空/设置
  ├─ PromptPreviewDialog:      prompt/warnings/ir 的只读审阅 + 复制/导出
  ├─ BatchFactory:             随机生成/虚拟化（不直连 selectedItems，仅经 generatePartial 锚定）
  └─ HistoryPanel:             保存/回填/收藏/模板（经 history store）
```

- **Keyword 搜索：** `keyword` 为 `DimensionPanel` 本地 `ref`，两模式共用；浏览模式过滤维度/条目，已选模式过滤已选卡片。
- **NSFW：** `allowNsfw` 本地 `ref`，浏览模式过滤条目，已选模式不生效。
- **模式：** `dimPanelMode: 'browse' | 'selected'` 本地 `ref`，`watch` 持久化 `pmf:dimPanelMode`。
- **预览开关：** `previewOpen: boolean` 本地 `ref`，不持久化。
- **Sash：** `leftFrac/centerFrac` 由 `useSash` 管理，默认改为 `0.28/0.42`（见 `03`）。

## 9. 交互时序

### 9.1 选词 → 预览 → 导出

1. 用户在浏览模式双击条目 → `assembly.addModule` → 该条目高亮 `已选`，预览按钮计数 `N` 更新，`StatusBar 已选` 同步；
2. 点击预览按钮 → Dialog 展示全文 + IR + warnings；
3. 在 Dialog 内复制或导出（或在已选模式顶部直接复制）；
4. 需要调整权重/锁定：切已选模式 → 点 `w1.2` 改权重 / `🔒` 切换锁定 / 拖拽排序 / `✕` 移除；
5. 需要保存方案：在已选模式或预览 Dialog 内（可选）提供"保存方案/另存为模板"入口（首版可仍经 `AssemblyCanvas` 原入口迁移至维度面板已选模式顶部，或保留经 `HistoryPanel` 的保存链路）。

### 9.2 已选模式的保存入口

首版提供两种其一（建议 A）：

- **A. 已选模式顶部：** `保存方案`（`assembly-save-btn`）+ `★ 收藏并保存` + `另存为模板`（复用 `SaveDialog` 两例），与画布头部一致；
- **B. 仅预览 Dialog 内：** 将保存入口收纳进 Dialog，减少已选模式顶部拥挤；已选模式仅保留清空与设置。

本设计按 **A** 描述，B 作为降级备选。

## 10. 边界与空态

| 场景 | 表现 |
|------|------|
| 浏览模式无匹配维度 | `dimension-empty`：`无匹配维度 — 清空搜索` |
| 浏览模式某维度无可显示条目 | `（该维度暂无可显示条目）` |
| 已选模式 `N=0` | `selected-empty`：◈ + `暂无已选 — 去浏览模式双击添加` |
| 已选模式搜索无命中 | `无匹配已选项 — 清空搜索` |
| 预览 Dialog 空 Prompt | `preview-empty`：`暂无拼装 — 从左侧添加词条后此处实时预览`，复制/导出 disabled |
| 权重 Popover 越界 | `absolute z-20`，必要时 `right-0` 避免溢出视口 |
| 拖拽在 `dimensionOrder` 模式 | 保留手柄，提示"当前为维度顺序，拖拽将在自定义拖拽后生效"（toast 或 tooltip） |
